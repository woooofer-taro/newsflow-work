Cisco、エージェント型コラボレーション体験の新機能を発表

新しいアップデートにより、仕事、職場、顧客体験のあらゆる場面で、人、デジタルのチームメイト、企業のコンテキストが結び付けられる

ニュースの要約

  • Ciscoは、Webexを進化させ、デジタルのチームメイトと人が、コラボレーション全体にわたってシームレスに働けるようにする。これにより、何が重要かを理解し、仕事を前に進められるようになる。
  • Claude Managed Agentsで構築された「Webex内のClaude」により、チームは、共有された企業のコンテキストを使ってデータを分析し、コンテンツを生成し、作業を実行できる。すべての作業はWebexを離れることなく行える。
  • Intelligent Workplace Experiencesは、安全なネットワーキング、コラボレーション技術、物理的なスペースを統合し、職場にいる人々にとってより魅力的で包括的な体験を生み出す。
  • Webex AI Agentプラットフォーム向けの全く新しいエージェント型ハーネス「Dialog」は、分断された対話を継続的な顧客との関係に変え、問題が解決されるまで顧客に代わって作業を続ける。

テキサス州オースティン、2026年10月7日 /PRNewswire/ -- WebexOne 2026 -- Cisco（NASDAQ: CSCO）は本日、人とエージェントの協働のあり方を変える、エージェント型コラボレーションの革新を発表した。このアプローチは、AI時代の仕事の3つの相互に関連する側面、すなわち人の働き方、職場の適応の仕方、そして企業が顧客と関わる方法に対応するものである。

組織は重大な課題に直面している。労働力が進化する中で、チームは、デジタルのチームメイトの可能性を引き出し、同時に人の手が必要な仕事の効果を最大化する方法を必要としている。Ciscoは、会話、物理的なワークスペース、顧客との接点を共有されたコンテキストに統合している。これにより、AIは受け身のチャットボットから、複雑な仕事を前に進めるデジタルのチームメイトへと変わる。

「仕事の次の時代とは、昨日のツールにチャットボットを取り付けることではありません」と、Ciscoの社長兼最高製品責任者であるJeetu Patelは述べた。「それは、AIエージェントが人やチームと並んで働き、their ワークスペースに深く組み込まれ、安全で信頼できる基盤の上で協働することです。人とエージェントが同じコンテキストを共有すれば、仕事は止まらず、顧客との関係もより強くなります。」

人とAIエージェントが共に働くための新しいWebex

Ciscoは、企業のAIを、受け身でプロンプトに基づくアシスタントから、仕事の流れの中で直接関与する、能動的なデジタルのチームメイトへと進化させている。新機能は以下のとおり。

  • Claude Managed Agents｜Webex内のインテリジェントなチームメイトと複数段階のアクション：近日中に、共有されたチームのコンテキストを、より深い分析、戦略的な提言、承認済みエージェント間での連携したアクションへと変えられるようになる。
  • チームと共に働く新しいAIエージェント：協働型のAIエージェントを、スペース、会議、通話に直接招待し、Webexおよびサードパーティのアプリケーションをまたいで複雑な複数段階の作業を実行させることができる。例えば、チームメンバーはWebexのスペースで分析エージェントを@メンションして利用統計を取得させ、その後、プレゼンテーションエージェントに、それらの数値を反映するようPowerPointのデッキを更新させることができる。
  • OpenAI dots｜豊富なコンテキストと個人向けインテリジェンス：Webex Suite Model Context Protocol（MCP）統合により、Webexのコンテキストがdotsに直接取り込まれる。将来的には、dotsはWebex内で常時稼働する個人向けエージェントとしても利用できるようになる。
  • 企業の信頼のために構築：Ciscoは、ID、セキュリティ、ガバナンス、可視性を統合し、組織がAIがアクセスできるもの、実行できること、そしてその振る舞いを管理できるようにする。

AI時代の新しい職場

人の手が必要な、重要な判断、戦略的な整合、関係構築といった、エージェント時代の重要な場面を支えるため、今日の職場は、感知し、推論し、行動する、インテリジェントなエコシステムにならなければならない。Intelligent Workplace Experiencesを通じて、Ciscoは、安全なネットワーキング、コラボレーションデバイス、デジタル体験の保証、物理的なスペースを、単一のアーキテクチャに統合している。Cisco Cloud Controlで管理されるこの基盤により、組織は完璧なオフィス環境を構築し、ITオペレーションを効率化し、物理的なスペースと技術全体で効率化を進めるための実用的なインサイトを得られる。新しい革新は以下のとおり。

  • ITおよび施設のためのビジュアルプランニング：Workplace Designerは、Ciscoのビジュアルプランニング体験を、個々の部屋から職場全体へと拡張し、ネットワーキング、コラボレーション、ワークプレイスインテリジェンスにまたがる。例えば、住所を入力すると、オーダーメイドの設計図を生成し、チームが判断を整合させ、導入に備えられるようにする。これにより、より簡単で優れた従業員体験が実現する。
  • 職場の障害をより迅速に特定し解決：Experience Metricsを職場にも拡張することで、ITは単純な接続アラートを超えて、問題が正確にどこで発生し、従業員にどう影響しているかを明らかにできる。ネットワークとデバイスの保証を、フロアプラン、Wi-Fiのカバレッジ、在室状況と関連付けることで、ITチームはビジネスへの影響に基づいて問題に優先順位を付け、トラブルシューティングを行い、より迅速に修復し、信頼性の高い職場体験を確保できる。
  • スペースとキャパシティ計画の最適化：Cisco Cloud Control内のWorkplace Insightsは、複数の拠点やフロアにわたって物理的なオフィスがどのように利用されているかを、明確で統一された形で提供する。時間の経過とともに活動パターンを追跡し、予約済みのスペースと実際の在室状況を比較することで、ワークプレイスのリーダーは、単発のスナップショットを超えて判断し、不動産投資を適正化し、人々が日々どのように協働しているかに合わせて環境を調整できる。

Ciscoはまた、コラボレーションデバイスのオペレーティングシステムであるRoomOS 27を発表した。物理的なスペースにおけるAIの新時代に向けて構築されたRoomOS 27は、AI、プラットフォームの選択肢、インテリジェントな管理の面で職場体験を進化させ、スペースがコンテキストを理解し、状況に適応し、さらに行動を起こせるようにする。主な内容は以下のとおり。

広告

  • 包括的な相互運用性：Googleとの新たなパートナーシップにより、Ciscoのデバイスは、Google Meetの全機能をネイティブにサポートするようになり、Webex、Microsoft Teams、Zoomに加わる。これにより、Ciscoは最もオープンなコラボレーションハードウェアとなる。顧客は、Ciscoのデバイスのインテリジェンスと管理機能を維持したまま、好みの会議環境とAI環境を自由に選択できる。
  • エッジでの高度なAI：Collaboration Devices上の新しいCisco AI Assistantは、部屋の中での自然言語による対話を可能にする。さらに知能が向上し、AI Assistantは32言語で対応できるようになった。例えば、部屋が暑すぎるという発言があれば、自動的に温度を調整し、ブラインドを下げる。
  • インテリジェントな職場管理：RoomOS 27およびCisco Cloud Controlの新しいインテリジェンスにより、ワークスペースを最適化できる。Workspace Advisor、Smart Room Assurance、Divisible Rooms、Splunkおよびエージェント連携により、ITは、スペースがどのように使われているかをより詳細に把握し、新しい方法で大規模に調査、運用し、継続的に改善できる。

RoomOS 27は11月に提供開始予定であり、仕事が行われる場所にインテリジェンスをもたらす。これにより、職場は人にとってより自然になり、ITにとって安全に保護、管理、改善しやすくなる。

Cisco Ceiling Speaker Proは、完全に統合され、IPで接続された会議スペースに向けたCiscoのビジョンを完成させるものである。どこから参加しても、すべての声が明瞭かつ自然に届くようにする。Ciscoのカメラ、マイク、ルームデバイスと同じインテリジェントなシステムに統合され、AIを使ってスペース全体の音声を適応させるため、小さな声も自然に届く。ネットワークから中央管理に直接接続されるCeiling Speaker Proは、複雑な複数ベンダーの音声構成を、導入と拡張が簡単な単一のイーサネットケーブルに置き換える。
