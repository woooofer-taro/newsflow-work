F5、OracleがAI時代のアプリケーションセキュリティで協業 - The Fast Mode

F5, Oracle Collaborate on Application Security for the AI Era - The Fast Mode
F5 発表2026-11-02 13:00発表

F5とOracleは、次世代のWebアプリケーション&API保護（WAAP）を、Oracle Cloud Infrastructure（OCI）上でアプリケーションを稼働させている顧客に提供することを目的とした、計画中の協業を発表した。両社の法的拘束力のない覚書（MOU）のもとで、この計画中の協業は、組織が重要なアプリケーションとAPIを高度な攻撃から保護し、運用の複雑さを軽減し、継続的なイノベーションを支え、専門的なセキュリティ人材への依存を減らすことに役立つと見込まれている。

この協業は、次の主要な利点を支援することを目的としている:

Protect critical applications and APIs against sophisticated attacks: F5の実績あるWebアプリケーションおよびAPI保護技術により、専門的なセキュリティ人材を必要とせずに、組織が高度な脅威に対処することに役立つと見込まれている。

Simplify security operations: アプリケーションおよびAPI保護を提供し、運用の複雑さを増すことなく、チームが使い慣れたクラウド環境内でワークロードを保護することに役立つと見込まれている。

Kp Papamiltiadis, senior vice president, global partnerships, Oracle

サイバー脅威が進化するなか、顧客には運用の複雑さを増すことなく脅威の進化に追随するアプリケーションおよびAPI保護が必要である。我々は、F5のアプリケーションセキュリティの専門知識をOCIに持ち込み、Oracleのクラウドインフラストラクチャとサポートを基盤として、顧客が重要なアプリケーションとAPIを保護し、セキュリティ運用を簡素化することに役立てる計画である。

John Maddison, chief marketing officer, F5

AIを活用した攻撃は、企業がパッチを適用するよりも速く脆弱性を発見して悪用しうる。OracleとF5は、AIランタイム防御をクラウドチームにとっての解決策と捉えており、チームが修復に追いつくまで、露出したシステムを守る仮想パッチを可能にする。F5のアプリケーションセキュリティ技術のOCIへの計画中の統合を通じて、我々はセキュリティ、アプリケーション、プラットフォームの各チームに、運用上の摩擦を増やすことなく、F5による次世代ソリューションで重要なワークロードを保護するための、実績があり分かりやすい方法を提供する意向である。
