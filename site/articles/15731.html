VMware vCenterの重大な欠陥により認証バイパスが可能に

Critical flaw in VMware vCenter allows authentication bypass
Network World2026-11-20 07:00報道

Broadcom は、vCenter の修正は「ITIL の手法において緊急変更に該当する」と述べている。

Broadcom は複数の製品のバグに対するパッチをリリースした。そのうちの 1 つ、VMware vCenter の認証バイパスの脆弱性を修正するものは、深刻度が 10 段階中 9.8 と評価されている。

同社のアドバイザリは、CVE-2026-123890 として追跡されているこの欠陥を「VMware Directory Service における認証バイパスの脆弱性」と説明しており、ネットワークアクセスを持つ脅威アクターがシステムへの不正アクセスを得られる可能性があるとしている。また、回避策はないとしている。即時のパッチ適用を推奨している。

Broadcom は修正済みの vCenter バージョン 9.1.1.0200、9.0.2.0200、および 8.0 U3m を提供している。v7.0 を実行している顧客は、延長サポート契約がある場合にのみパッチを入手できる。VMware Cloud Foundation 5.x の修正済みバージョンは 5.2.5 である。

同じく影響を受ける VMware Telco Cloud Platform and Infrastructure を使用している顧客は、修正手順について KB463116 を参照すべきである。

残りの 4 件は次のとおりである。深刻度 8.1（Important）の SDDC Manager の SQL インジェクションの脆弱性（CVE-2026-123891）、7.2（Important）の SDDC Manager の認証済みコマンドインジェクションの脆弱性（CVE-2026-123892）、6.7（Moderate）の SDDC Manager のローカル権限昇格の脆弱性（CVE-2026-123893）、そして同じく 6.7 と評価されている VMware Tools SAML Token Signature Bypass の脆弱性（CVE-2026-123894）である。いずれにも回避策はない。

Broadcom は、5 件すべてのバグに関する追加情報を提供する補足の FAQ を公開しており、その中で次のように述べている。「[アドバイザリ] に「fixed」として記載されているバージョンより前の、VMware vCenter、SDDC Manager、または VMware Tools for Windows のいずれかのバージョンを実行している場合、影響を受けます。これには、スタンドアロンで展開された vCenter および SDDC Manager、ならびに VMware Cloud Foundation、VMware vSphere Foundation、VMware Telco Cloud Platform、VMware Telco Cloud Infrastructure の一部として展開されたもの、さらに Windows 仮想マシンにインストールされた VMware Tools が含まれます。」
