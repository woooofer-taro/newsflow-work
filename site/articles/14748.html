エージェント型AIにはより強固で確実なネットワーク基盤が求められる

Agentic AI demands a stronger, more assured network foundation
Cisco Blogs2026-11-10 07:00報道

エージェント型AIには、より強力で保証されたネットワーク基盤が求められる - Cisco Blogs

2026年は、ネットワークに求められる要件を絶えず書き換え続けている。Mythos GPT-5.6 Sol のようなフロンティアモデルが新たな脆弱性を急速に発見している。世界各国の政府はポスト量子暗号の義務化を加速させている。そして AgenticOps は、ビジョンから NetOps の日常的な必需品へと変わった。技術の変化がマシンの速度で進む中、透明性を確立し、信頼を支え、自律的な運用を可能にするために、ネットワークにはより強力な基盤が必要である。

先週の Partner Summit で、私たちは Cisco のセキュアネットワーキングと AgenticOps の機能を前進させる数多くの主要なイノベーションを発表した。本日は、あらゆる規模の IT チームがエージェント時代にネットワークをどのように拡張し保護できるかを、さらに掘り下げる。ライブで見たいか。Cisco Live Melbourne の、GM の Joe Vaccaro と Michael Dickman によるキーノート詳細解説「Trusted, Scalable, and Assured: Designing Resilient Networks for the Agentic Enterprise」をご覧いただきたい。

Cisco Live Melbourne 2027 で見られるハイライトの概要は次のとおり。

  • 信頼できる自律運用のための ThousandEyes インテリジェンス： インテリジェントなネットワークテレメトリへのシームレスなアクセスにより、新しいアクセスポイントをオンボードした瞬間から、ネットワークの問題をより早く特定できるようにする。
  • アプリケーション向け Experience Metrics： その豊富なアシュアランスとアプリのテレメトリを接続し、ネットワークを継続的に調査してパフォーマンスを最適化する。
  • ネットワーキング向け Agentic Actions： 現在限定提供中の Actions は、深い推論、エージェントの透明性、信頼によって自律ループを閉じる。
  • ネットワーキングプラットフォーム向けの新しい Model Context Protocol（MCP）サーバー： クラウドおよびオンプレミスのネットワークにまたがるネットワークインテリジェンスにアクセスするための標準化された方法を提供し、カスタムのトラブルシューティングやワークフローを構築しやすくする。
  • ワイヤレスネットワーク全体にわたるポスト量子暗号： 業界初のオーバーザエアおよびセキュアブート機能が、Wi-Fi ネットワークを将来の量子の脅威から守る。
  • Live Protect の拡張： 新たに発見された脆弱性に対する検証済みのシールドを提供する Live Protect が、Cisco Smart Switches、ワイヤレスコントローラーとゲートウェイ、Secure Routers で利用可能になった。

エージェンティックループを1000倍良くする

Cisco と Omdia による1,000人の IT およびネットワーク運用のリーダーを対象とした最近の調査では、回答者の51%が、本番環境で NetOps のプロセスやタスクに対処するためにすでにエージェント型AIを使用していることがわかった。そして84%が、12か月以内にAI主導の運用モデルに到達すると予想している。

これは私たちにとって驚きではない。技術がこれほど急速に進化する中、先行し続けるにはマシン速度の能力が必要である。しかし、Joe Vaccaro が先週適切に指摘したように、「より大きな自律性には、可視性と制御が伴わなければならない」。

Cisco Cloud Control は AgenticOps の拠点であるが、この新しい運用モデルの中心にあるのはエージェンティックループである。エージェンティックループとは、ネットワークのシグナルを信頼できる成果に変える明確なプロセスである。エージェントが問題を感知し、その原因を診断し、修復を準備し、提案された変更を検証し、お客様が定義した制御の範囲内でそれをデプロイする。

その信頼を築く次のステップは ThousandEyes から来る。私たちは現在、すべての Wi-Fi 6E および Wi-Fi 7 アクセスポイントに、システムの中核的な一部として ThousandEyes エージェントと合成テストを含めている。追加ライセンスも追加の手順もない。新しいアクセスポイントの電源を入れた瞬間から、プラットフォームが自動的にエージェントをプロビジョニングし、重要なサービスを検出し、テストをインテリジェントにデプロイする。ワンクリックで、あなたのエージェンティックループは Thousand 倍良くなる。

*キャプション – ThousandEyes インテリジェンスは、対象となる Cisco Networking Essentials ライセンスに自動的にデプロイされて含まれるようになり、より強力なエージェント機能を支える。*

この強力なテレメトリが、エージェンティックループ全体にわたる信頼できるアクションを支える。この新しいデータを原動力として、私たちは Experience Metrics をアプリケーションパフォーマンスにまで拡張し、複雑なネットワーク全体にわたるエクスペリエンス管理の水準を引き上げている。今すぐ Experience Metrics のベータにサインアップしてほしい。

そして、これらすべてのインサイトは Agentic Actions に集約される。これは Cloud Control 内の単一のビューで、AIエージェント、深い推論、Cisco Workflows を組み合わせ、エージェンティックループ全体にわたるすべてのアクション、推奨事項、結果をオペレーターが確認できるようにする。さらに、自律的なアクションをどのように実行するかを選択できる制御も備えて構築されている。ベータにサインアップして、ご自身で確かめてほしい。

インフラストラクチャ自体に信頼を組み込む

AIが脅威の状況を加速させ、組織がAIエージェントを導入するにつれ、セキュリティチームは追いつこうと奔走している。これらのリスクを増大させるのが、ポスト量子コンピューティングという迫り来る脅威であり、「今収集して後で復号する」型の攻撃を可能にする。幸いなことに、CISO と CIO はすでに、すぐに役立つ戦略的資産を手にしている。それがネットワークである。

ネットワークはトラフィックが移動する際にそれを見ており、常に存在するプラットフォームとして、新たなリスクを特定し、アプリケーションやネットワークリソースへのアクセスを制限し、修正が進められている間にインフラストラクチャを防御できる。11月のセキュアネットワーキングに関する私たちの発表は、ネットワーキングチームとセキュリティチームが可能な限り信頼できるプラットフォーム上で運用できるように、ネットワークに組み込まれたセキュリティ機能を継続的に改善するという私たちのコミットメントを示している。

業界初のワイヤレス量子レジリエンス

まず、Cisco はポスト量子保護を Wi-Fi 7、ワイヤレスコントローラー、Campus Gateways に拡大している。これらの強化には、ポスト量子対応の Secure Boot と、サポートされるプラットフォームでのオーバーザエア暗号化を含む PQC 対応の通信が含まれる。これらの機能は、お客様が暗号要件の変化や将来の量子の脅威に向けてワイヤレスインフラストラクチャを準備するのを支援する。

私は、新しい Cisco Wireless CW9176ISEC に個人的に期待している。これは、量子レジリエント機能を備えた業界初の Wi-Fi 7 アクセスポイントである。CW9176ISEC は、NSA が更新した耐量子アルゴリズム群である CNSA 2.0 に準拠した量子安全機能を備えた最初のアクセスポイントである。2027年1月1日以降、すべての新しい国家安全保障システムの導入は CNSA 2.0 に準拠しなければならず、配備済みの機器は2030年末までに移行を完了することが目標とされている。

それに加えて、Cisco Wireless 9800 Series Wireless Controllers と Campus Gateways も、CW9176ISEC と同じ量子レジリエントなセキュリティ機能を備えるよう刷新されている。また、私たちは Qualcomm Technologies、Microsoft、Intel と提携し、PQC over the air（OTA）による量子安全なエンタープライズワイヤレスの先駆けとなることを目指している。1月から Cisco の Wi-Fi 7 アクセスポイントのポートフォリオ全体で利用可能となるこの機能は、ネットワークインフラストラクチャ、オペレーティングシステム、ノートPCやモバイルデバイスなどのクライアントハードウェアにわたって、量子安全な通信をもたらす。

ワイヤレスとルーティングへの Live Protect の拡張

最後に、私たちはキャンパスおよびブランチのポートフォリオ全体で Live Protect のサポートを引き続き展開している。Live Protect は、お客様が通常のアップデートプロセスを通じて恒久的な修正をテストしデプロイしている間、新たに公開された脆弱性へのエクスポージャーを減らすのに役立つ。私たちは現在、Cisco が提供し Cisco が検証したランタイムの Vulnerability Shields を、Smart Switches から、サポートされるワイヤレスコントローラー、Campus Gateways、Secure Routers へと拡張している。これにより、シールドを適用するために即時のアップグレードや再起動を必要とせず、より多くのネットワークインフラストラクチャにわたって保護が加わる。

Cisco Live Melbourne でさらに詳しく

エージェント時代には、チームが信頼できるネットワークが必要である。それは、AIエージェントに信頼できるインサイトを与え、アクションを人が制御できるようにし、インフラストラクチャ自体にセキュリティを組み込むネットワークである。Cisco Live Melbourne で、私たちはより豊富なネットワークとアプリケーションの可視性、量子レジリエントなワイヤレス機能、キャンパスおよびブランチネットワークのより多くの部分にわたる Live Protect のカバレッジによって、その基盤を前進させている。キーノート詳細解説をライブ配信またはオンデマンドで視聴してこれらのイノベーションの実際の動作を確認し、継続的な更新については Enterprise Networking の Linkedin ニュースレターを購読してほしい。
