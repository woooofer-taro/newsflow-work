Dell と Microsoft、企業がデータ管理の強化を求める中でプライベートAIを推進

Dell and Microsoft drive private AI as enterprises seek greater data control
Network World2026-11-20 07:00報道

ベンダー各社が Microsoft Azure Local と Foundry Local を Dell PowerEdge サーバーおよび Nvidia アクセラレーションと統合、データセンター向けに提供

Dell Technologies と Microsoft は、企業が AI モデルをデータの近くで実行し、パブリッククラウドサービスへの依存を減らし、機密情報の管理を維持できるよう設計された新しいインフラストラクチャ製品群で、プライベートクラウドのパートナーシップを拡大する。

この発表は Microsoft の Ignite カンファレンスで行われ、Dell の AI Factory with Nvidia イニシアチブを Dell Private Cloud 環境に拡張するものである。Dell によると、これは特に機密性の高い企業情報、規制要件、データレジデンシー制限を扱う組織の間で、社内に展開する AI 推論へ向かう業界の動きが強まっていることも反映している。

拡張された製品は、Dell Private Cloud、Microsoft Azure Local、Microsoft Foundry Local、Nvidia アクセラレーションを組み合わせたものである。両社によると、その目的は、負荷の高い AI ワークロードを自社のデータセンターおよびファイアウォールの内側に展開するための統合インフラストラクチャを組織に提供することである。

拡張されたプラットフォームの中心的な構成要素は、Nvidia の HGX アクセラレーテッドコンピューティングプラットフォームを中核に構築された Dell の PowerEdge XE9780 サーバーである。このシステムは、大規模な AI ワークロードに必要な高密度のコンピュートリソースを提供しつつ、Dell の既存のプライベートクラウドインフラストラクチャおよび管理機能と統合するよう設計されている。

Microsoft はまた、Azure Local のサポートを Nvidia HGX B300 システムにも拡張しており、従来のパブリッククラウド環境の外で AI ワークロードを実行するための追加のハードウェアの選択肢を顧客に提供する。

このプラットフォームは、異なる役割を担う 2 つの Microsoft テクノロジーを組み合わせている。1 つ目は Azure Local で、顧客が管理する環境で Azure サービスを実行するためのインフラストラクチャと管理基盤を提供する。Nvidia HGX B300 システムへのサポート拡張により、企業はより負荷の高い AI アプリケーション向けのアクセラレーテッドコンピューティングハードウェアを利用できるようになる。

2 つ目のテクノロジーは Microsoft Foundry Local で、組織がプロンプトやデータを外部のクラウドベースの AI サービスに送信するのではなく、社内システム上で AI モデルを実行できるようにする。これは、独自のビジネスデータ、社内文書、運用データを扱う推論ワークロードに特に関連する。

Dell によると、この構成により、顧客は Microsoft Foundry Local モデルを Dell Private Cloud のコンピュートおよびストレージシステム上で直接実行できる。一元化された監視、セキュリティ、ガバナンス機能もアーキテクチャに組み込まれている。

このシステムは、Dell の Automation Platform とブループリント駆動の自動化を使用して、デプロイと継続的な管理を簡素化する。

コストもこのイニシアチブの背景にあるもう 1 つの主要な検討事項である。企業が実験的な AI プロジェクトから持続的な本番デプロイへ移行するにつれ、クラウドベースの API を通じて AI を利用する経済性は、ますますコストがかかるようになりうる。

Dell は、Signal65 と Futurum Group が実施した、The Economics of Agentic AI と題する 2026 年 9 月の分析を引用している。それによると、Dell AI Factory インフラストラクチャ上でエージェント型 AI を展開する組織は、クラウド API ベースの利用モデルと比較して、2 年間で総所有コストを最大 90% 削減できる可能性があることがわかった。この分析ではまた、一部の構成では 2〜3 か月で損益分岐点に達しうることもわかった。

ベンダー各社は、この発表が、企業がハイパースケールクラウドプロバイダーのみに依存する代替手段を求める中で、プライベートクラウドインフラストラクチャの重要性が高まっていることも強調していると述べた。

AI モデルをローカルで実行することには、規制遵守は言うまでもなく、データ主権、セキュリティ、レイテンシ、運用管理に関する潜在的な利点がある。Dell は、同社の Private Cloud プラットフォームは、従来の 3 層インフラストラクチャと比較して Day 2 のインフラストラクチャ運用時間を 66% 削減できると述べている。同社はまた、ハイパーコンバージドインフラストラクチャと比較して最大 65% のコスト削減の可能性があるとしている。
