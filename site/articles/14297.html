Logicalis、5カ国でCisco Secure Networking専門認定を取得

Logicalis Achieves Cisco Secure Networking Specialisation in Five Countries
The Fast Mode2026-11-04 13:00報道

Logicalis、5か国でCisco Secure Networking Specialisationを取得

Logicalisは、米国、EMEA（ドイツ）、LATAM（ブラジル）、アジア太平洋（中国、インドネシア）を含む、世界の主要な全地域にわたる5か国でこのスペシャライゼーションを保有する初のCiscoグローバルパートナーとなった。

グローバルなテクノロジーサービスプロバイダーであるLogicalisは、Cisco's Secure Networking Specialisationを取得した。これは、ネットワーキング、セキュリティ、マネージドサービスにわたる同社の専門性を認めるものである。 この認定は、接続性とセキュリティを統合した安全な環境を設計、導入、管理するLogicalisの能力を裏付けるものである。

このスペシャライゼーションは、当初5か国のLogicalisの事業体が取得しており、6か月以内にその数を倍にすることを約束している。これにより、Logicalisの顧客は、各地域市場の要件に合ったサポートを維持しながら、グローバルな提供モデルを通じて、検証済みのCiscoの専門性を利用できる。

より安全で回復力のある運用の支援

組織がIT時代からAI時代へ移行するにつれ、ネットワークはより多くの事業上重要なトラフィックを運び、より幅広いユーザー、デバイス、ワークロードをサポートしなければならない。同時に、セキュリティチームは、ますます分散する環境全体で、より明確な可視性とより強力なポリシー制御を必要としている。

LogicalisとCiscoは、AI時代に向けてSecure Networkingのマネージドサービスを進化させている。これはCisco Cloud Controlを基盤とし、Cisco IQ（これらの提供が利用可能な地域において）およびCisco Data Fabricによって強化されている。このサービスは、顧客により大きな可視性とインサイトを提供するとともに、インフラの近代化、回復力の強化、リスク管理、AI対応環境の構築を支援する。

グローバルな提供体制とCiscoの専門性

Logicalisは、すべての主要地域のNetwork Operations CentresおよびSecurity Operations Centresを通じて顧客を支援している。これらのチームは、グローバルな提供体制と確立されたCiscoの専門性を組み合わせて、ネットワーキングおよびセキュリティ環境を監視・管理している。

Cisco Secure Networking Specialisationは、Logicalisの専門性と、複雑なネットワーク環境全体で一貫したセキュリティ制御を適用する能力に対する、独立した検証を提供する。

Logicalisler Ciscoは共に、顧客が自らの環境を評価し、近代化の優先順位を付け、より自動化されポリシー主導の運用を採用できるよう支援する。Cisco IQとCloud Controlは、この過程を通じて、可視性、ライフサイクル管理、運用の一貫性を向上させる。

デジタルトランスフォーメーションの次の段階を可能にする

セキュアネットワーキングは、組織に、変化する事業要件とともに進化できる基盤を与える。ネットワーキング、セキュリティ、自動化、運用上のインサイトを統合することで、Logicalisは顧客が管理を簡素化し、時間をかけてインフラを適応させることを支援する。

このスペシャライゼーションは、従来のインフラ管理を超えて、継続的な改善を支えるマネージドサービスへと向かうLogicalisの動きを補強するものである。これにより顧客は、既存の環境を近代化し、運用を簡素化し、より高い確信を持って技術投資の判断を下すことができる。

Anita Swann、Logicalis グローバルアライアンス担当VP

このスペシャライゼーションは、Ciscoとの長年にわたる関係の強さと、顧客が必要とするスキル、プラットフォーム、サービスに対して当社が継続している投資を反映している。ネットワーキングとセキュリティを変革的なマネージドサービスモデルの中で統合することで、組織が複雑さを減らし、回復力を強化し、AIに必要な安全な基盤を構築することを支援できる。

Elisabeth De Dobbeleer、Cisco Cisco Global Partner Program GTM担当SVP

Ciscoのパートナーエコシステムは、顧客が技術革新を測定可能な成果へと転換することを支援する上で中心的な存在である。

LogicalisがCisco's Secure Networking Specialisationを5か国で取得したことと、大規模にマネージドサービスを提供する能力は、当社の最も強力なパートナーを特徴づける専門性、革新性、顧客重視の姿勢を示している。そのグローバルな能力と地域の専門性の組み合わせは、顧客がインフラを近代化し、運用を簡素化し、AI時代に向けて安全に備えることを支援する。
