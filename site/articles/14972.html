TRAI IP ポート料金：10 Gbps は上限 ₹42.3 lakh [2026] - shattered.io

インドの通信規制当局は、事業者同士がトラフィックを引き渡すために使うポートに価格の上限を設けた。インド電気通信規制庁（TRAI）は、10 Gbps IP ポートの年間料金の上限を ₹42.3 lakh、1 Gbps IP ポートの料金の上限を ₹5.6 lakh と定めた。TRAI のプレスリリース No. 157/2026 と Convergence Now の業界報道によると、この上限は「The Telecommunication Interconnection (Port Charges) (Third Amendment) Regulations, 2026」に盛り込まれており、2027年1月1日に発効する。

これはハードウェアが核にある規制の話である。ポートは事業者の設備上の物理インターフェースであり、新しい規則は、ある事業者がその利用について別の事業者に何を請求できるかを決める。今日は2026年11月11日であり、この枠組みの適用開始まで約7週間となる。本分析は、TRAI と業界報道が確認した事項と、依然として推測にとどまる事項とを切り分けたうえで、この数字がネットワーク構築者、機器の購入者、そして TRAI IP ポート料金 を追う人々にとって何を意味するかを検討する。

インドのネットワークが運ぶトラフィックは増え続けているため、このタイミングは重要である。インドの5Gトラフィックが12.9エクサバイトに達したことを伝えた当方の過去の記事は、需要がいかに急速に伸びているかを示した。そして相互接続容量は、そのトラフィックの多くが一方の事業者のネットワークから他方へ渡らなければならない場所である。ポート価格の上限は、この接点に直接影響する。

TRAI が IP ポート料金について発表した内容

TRAI は、この枠組みをポート料金規則の第三次改正として公表した。題名が話の最初の部分を物語っている。「第三次」という語は、それ以前の改正があったことを示唆しており、今回の改正は、E1/TDM ベースの相互接続をすでに対象としている規則の上に、IP ベースの相互接続のための新たな層を加えるものである。TRAI のリリースは、この文書をプレスリリース No. 157/2026 としている。

主要な数字は単純である。1 Gbps IP ポートの年間上限は ₹5.6 lakh である。10 Gbps IP ポートでは ₹42.3 lakh である。1 lakh は 100,000 に等しいので、これらの上限は年間 560,000 ルピーと 4,230,000 ルピーに相当する。これらは固定価格ではなく上限であり、事業者はそれより安く請求することはできるが、それより高く請求することはできない。

この規則は2027年1月1日に始まる。Convergence Now がこの数字と発効日を報じており、TRAI 自身のリリースも同じ数字を載せている。この記事の検証済みの記録に基づけば、どちらの情報源にも、実名の幹部や当局者の公式発言は含まれていないため、本稿は規則を言い換えて記述するにとどめ、個人に意見を帰属させることはしない。

数字：₹5.6 lakh と ₹42.3 lakh を一つの表で

分析に入る前に、確認済みの記録を一か所にまとめる。以下の各行は、TRAI のプレスリリース、またはそれを伝える Convergence Now の報道に基づく。この表にないものは、未確認として扱うべきである。

注目すべき点が二つある。第一に、対象範囲が広く、上限は固定電話、移動体、そして二種類の長距離通信に及ぶ。第二に、支払う側は、ポートを提供する事業者ではなく、相互接続を求める事業者、すなわち求める側である。この支払いの方向が、上限によって誰が利益を得るかを左右する。

1ギガあたりの計算：10 Gbps ポートの単価が安い理由

2つの上限は直線的には増えず、これが発表の中で最も興味深い点である。1 Gbps ポート10本は、上限では年間最大 ₹56 lakh かかる。10 Gbps ポート1本は最大 ₹42.3 lakh である。以下の計算は、確認済みの数字に基づく当方独自の算術であり、TRAI が公表した数字ではない。

1ギガあたりで見ると、10 Gbps の上限は年間 ₹4.23 lakh となり、1 Gbps ポートの ₹5.6 lakh と比べて、差は約24.5パーセントである。この構造は、トラフィックをより大きなポートに集約する事業者に有利に働く。それはネットワーク技術者がもともと好んで構築する方式とおおむね一致する。リンクが少なく大きいほど、管理すべきインターフェースは少なくなる。

一点注意がある。これらは上限であるため、実際の請求額はそれを下回る可能性があり、TRAI の枠組みはそれを認めている。上記の1ギガあたりの差は規制上の最大値を示すものであり、どの事業者が現在支払っている額、または今後支払う額でもない。検証済みの記録のどの情報源も現在の実際の料金を報告していないため、節約に関するいかなる主張も時期尚早である。

IP ポート料金が実際に支払う対象

相互接続とは、一方のネットワーク上の加入者が、他方のネットワーク上の加入者と通話、メッセージ、またはデータ交換をできるようにする取り決めである。これを機能させるために、2つの事業者は相互接続点でネットワークを接続する。一方の側が自社設備上のポートを提供し、もう一方の側がそれを使う。ポート料金は、そのアクセスに対する手数料である。TRAI の規則では、相互接続を求める事業者が、ポートを提供する事業者に支払う。

誰が誰に支払うか

支払う側は相互接続を求める側である。実際には、これは通常、相手のネットワークに到達する必要がある側を意味し、引き渡しを既存事業者に求める新規または小規模の事業者であり得る。検証済みの記録には事業者名が挙がっていないため、そのような取引でどの具体的な企業がどちらの側に立つのかは、当方には言えない。規則が定めているのは、提供者が請求できる最大額であり、その保護の方向は求める側に有利である。

1 Gbps と 10 Gbps 以外の容量

ネットワークが購入するのは 1 Gbps と 10 Gbps のポートだけではない。TRAI の枠組みは、他の容量の料金も同じ明示された方法論に従うとしており、したがって別のポートサイズを必要とする事業者が、規制のない空白に直面することはないはずである。報じられているとおりのリリースは、当方が確認した報道の中では、中間のすべての容量がどのように価格設定されるかを明記していないため、他のサイズの正確な数字が必要な読者は、規則の本文を参照すべきである。

IP ベースの相互接続と従来の E1/TDM モデルの比較

第三次改正は IP ベースの相互接続に関するものであり、E1/TDM ベースの相互接続に関する既存の規定を補完する。この文言は、インドのネットワークの現状について何かを語っている。回線交換音声を中心に構築された TDM 相互接続には、今なお規制上の規定が残っている。事業者がパケットとして互いにトラフィックを引き渡すことが増えているため、IP 相互接続には独自の価格枠組みが必要になっている。

2つのモデルは、容量の数え方が異なる。E1/TDM リンクは小さな固定回線として提供され、事業者は多数を追加して規模を拡大する。IP ポートは毎秒ギガビットで定格される Ethernet 型のインターフェースであり、事業者はポート速度を上げることで規模を拡大する。1 Gbps と 10 Gbps の階層を持つ、ポートあたりで表された価格上限は、この構築の仕方に合致している。

この比較から得られる要点は連続性である。TRAI は従来の規定を置き換えなかった。IP 固有の数字をそれらの隣に加えたのであり、したがって、従来の TDM リンクと新しい IP ポートが混在する設備を運用する事業者は、両方の規則の下で同時に活動することになる。

上限が対象とするサービス

上限は4つのサービス種別にまたがって適用される。固定電話、移動体、国内長距離、国際長距離である。この幅広さが重要なのは、一つの価格ロジックが、まったく異なるネットワークを規律することを意味するからである。固定電話事業者とトラフィックを交換する移動体事業者は、国際ゲートウェイに通話を引き渡す長距離事業者と同じ上限構造に直面する。

一律の扱いは、コンプライアンスを簡素化する。複数の区分でライセンスを持つ事業者は、事業ごとに異なるポート価格を追跡する必要がない。また、一つのポートが複数のサービスのトラフィックを運ぶ場合に、特定の相互接続がどの区分に属するかをめぐる議論の余地も除かれる。

検証済みの記録は、これが何社の事業者を対象とするのか、また現在各区分でポートをどれだけのトラフィックが通過しているのかを、当方に教えてくれない。これらは市場への影響の規模を見積もるのに有用な数字であろうが、当方が確認した報道の中で誰もそれを公表していない。ここでは推定しない。
