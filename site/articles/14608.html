CrowdStrike、キルスイッチと Fiddler で暴走AIに対処

「エージェント型インシデントは、7月から8月、そして8月から9月にかけて倍増した[2026年]。我々はエージェント型攻撃が倍増していく指数関数的な道の上にいる」と、CrowdStrike の CEO 兼創業者である George Kurtz は述べる。

同 CEO は、スペイン・バルセロナで開催された Fal.Con Europe 2026 の基調講演でこの統計を示した。同社はこの場で、AIエージェントを保護するための一連の機能を発表するとともに、AIオブザーバビリティの専門企業 Fiddler AI の買収計画を発表した。

これらの動きは、AIエージェントがどのように動作し、意思決定を行い、企業システムとやり取りするかについて、組織がより大きな制御を持てるようにすることを目指している。

Falcon Guardian と Fiddler のオブザーバビリティ技術の組み合わせは、企業におけるAI導入の2つの重要な側面、すなわち、許可されていないエージェントの活動を防ぐことと、AIエージェントが意図どおりに動作することを確保することに対処するよう設計されている。

欧州での冷凍庫へのサイバー攻撃：業界の声

欧州7カ国のスーパーマーケットの冷凍庫がサイバー攻撃を受け、温度が最高50℃に達した。

*BBC* によると、ベルギーとルクセンブルクにある約40の Delhaize のスーパーマーケットのほか、スウェーデン、アイルランド、オランダ、エストニア、フィンランドの店舗が影響を受けた。

この大規模な障害は、フランスで数百のスーパーマーケットの冷凍庫が攻撃されてからわずか数週間後に起きており、今回も同じ手法が使われたと報じられている。

インシデントの後、冷凍ユニットの蒸発器が霜取りモードに切り替えられ、腐った食品の山を廃棄しなければならなかった。

NCSC：英国の重要インフラはAIマルウェアの危険にさらされている

AIを利用したランサムウェア攻撃が、2028年までに英国の重要国家インフラに向かうと、National Cyber Security Centre（NCSC）が警告した。

「今後数カ月のうちに、サイバーインシデントの件数が前例のない規模で増加する現実的な可能性に我々は直面している」と、NCSC の CEO である Dr Richard Horne は述べる。

「明確にしておかなければならないが、それはAIが我々を攻撃する新たな方法を発明したからではない。あまりにも長く放置されてきた脆弱性が、かつては想像もできなかった規模で発見され、悪用されうるようになったからである。」

Dr Richard は、この国は長年「安上がりなテクノロジー」で済ませてきたと述べ、企業に対しサイバーレジリエンスに向けた措置を講じ、「選択の時」に向き合うよう強く求めている。

F5 の AI Security CTO、AIリスクについて「大人の対話」を行う

AI企業のCEOたちが、自社の技術が人類にもたらしうる「存在に関わる危険」に注目する一方で、この未来の脅威は、F5 の AI Security 担当 CTO である Jimmy White を悩ませている懸念とはかけ離れている。

Jimmy が重視しているのは、セキュリティにおける実践的な教訓と、これらのツールを構築・導入する企業が、それがアクセスできるもの、行うことを許されるものについて引かなければならない現実の境界である。

エージェントの行動を有用にしている人間離れした速度は、危険な行動を取っているエージェントを止めるための人間の介入が間に合わない可能性があることも意味する。

これが、「安全に振る舞うよう単に指示するだけでは十分ではない」理由である。

GPT-6 Cyber：OpenAI の「アラインされた」セキュリティエージェントの最前線

OpenAI は GPT-6 Cyber を発表した。同社はこれを「セキュリティ研究における大きな飛躍」だと主張している。

この特化型AIモデルは、サイバーセキュリティの専門家が脆弱性を特定し、エクスプロイトを開発し、ソフトウェアの防御を強化するのを支援するよう設計されている。

2026年11月5日に発表されたこの新モデルは、高度な脆弱性検出機能と、許可された範囲内で動作することを確保するための改善されたセーフガードを組み合わせている。

OpenAI は、GPT-6 Cyber がすでに Linux や Firefox を含む広く使われているソフトウェアで数千件の脆弱性の発見に貢献したと述べている。
