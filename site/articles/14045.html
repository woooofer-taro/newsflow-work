「エディタの母」Emacs が50周年

MIT Technology Review という最高の権威が、Emacs エディタが50周年を迎えたと伝えている。ただし、同誌には偏りがある。Emacs は MIT の AI ラボで発明されたからだ。

Simson Garfinkel の記事の題名は単に「EMACS turns 50」だが、その副題がなぜそれがより重要なのかを説明している。

「MIT AI ラボのテキストエディタが、いかにしてフリーソフトウェア運動を生んだか。」

Emacs の起源については複数の年表や説明があり、これは単一の一枚岩のアプリケーションではない。名前は「*E*diting *MAC*ro*S*」の略で、このマクロ群が開発された元のエディタは、1962年に Dan Murphy が書いた TECO――「Text Editor and COrrector」――だった。Murphy は今年の初め、83歳で亡くなった。

唯一無二の Jamie Zawinski は、百科事典的な Emacs Timeline を公開している。彼自身が冒頭で述べているように、彼の関心は、かつて GNU Emacs のフォークを保守していたことにある。そのフォークは元は Lucid Emacs と呼ばれ、後の名前 XEmacs で今も存在している。Emacs のフォークや再実装は*数多く*あり、そのすべてに立ち入ることはしない。さもなければこの記事は一冊の本になってしまい、それはプログラマー考古学者（故・偉大な Vernor Vinge が作った用語を使えば）にしか興味のないものになる。

しかし、その Editing Macros を最初に書いたのは誰かについては、関係者数名の発言を引用した別の歴史資料がある。On the Origin of Emacs in 1976 である。（注――引用の一部には、引用文を示す | 記号がまだ残っている。）

この資料は1975年の最初の仕事を Lisp の達人 Guy L. Steele Jr の功績としているが、その中で Steele は次のように述べている。

「'E' と 'EMACS' という名前は RMS によるものだ。TECO マクロのパッケージを取り上げて、それを地球上で最も強力なエディタに変えたことについて、RMS は功績の99%、あるいは99.9%、あるいは99.99%、あるいは99.999%に値する。」

RMS はもちろん Richard Stallman であり、このページには1976年10月23日と31日の RMS からのメールもいくつか引用されている。ただし、その出来事のわずか数年後、GNU のウェブサイトに保存されている1981年の講演で、Stallman は「私は1974年に TECO の改良として EMACS の開発を始めた」と述べた。最良の FOSS のすべてがそうであるように、ごく初期の段階でも共同作業だった――しかし RMS が開発の大部分を引き継いだのは1976年10月下旬ごろである。

半世紀にわたる開発の間に生まれた Emacs の多くのフォークのうち、いくつかは今もかろうじて生き残っている。XEmacs へのリンクを調べたところ、新しいリリースがあることに驚いた。XEmacs 21.5.37 "lettuce" がちょうど先月登場した。そしてフォークにさえフォークがある。この場合は SXEmacs で、最終更新は2020年だ。

XEmacs と SXEmacs の変更の大半は、最終的に GNU Emacs に取り込まれた。GNU Emacs は今も活発に開発されているが、*The Register* が2008年に報じたように、RMS はもう主たるメンテナーではない。GNU Emacs 31.1 は8月に登場した。

比喩的にテーブルの上に手札を出しておくと、このハゲタカ（筆者）は Emacs ユーザーではない。試したことはある。大きな影響を与えたのは、*Reg* の FOSS デスクのお気に入りの書き手の一人である Neal Stephenson で、彼は1999年に In the Beginning… Was the Command Line というエッセイを発表した。（後にかなり短い本として再刊されたが、本文は今もオンラインにある。）その中で彼は次のように述べている。

「GNU/Linux の世界には、主要なテキスト編集プログラムが二つある。ミニマリストの vi（一部の実装では elvis として知られる）と、マキシマリストの emacs だ。私は emacs を使っているが、これは熱核ワープロとでも考えればよいだろう。作ったのは Richard Stallman だ。それだけ言えば十分だろう。Lisp で書かれているが、Lisp は美しい唯一のコンピュータ言語だ。巨大でありながら、編集できるのはストレートな ASCII テキストファイルだけ、つまりフォントも、太字も、下線もない。言い換えれば、Microsoft Word では差し込み印刷や、企業の覚書に長編映画を埋め込む機能のようなものに費やされたエンジニアの工数が、emacs の場合は、テキスト編集という一見単純そうに見える問題に、狂気じみた集中度で注がれたのだ。あなたがプロの書き手――つまり、あなたの言葉がどう整形・印刷されるかを気にかけることで他の誰かが報酬を得ている立場――であるなら、emacs は、真昼の太陽が星々をかき消すのとほぼ同じように、他のあらゆる編集ソフトウェアを圧倒する。」

Emacs は50年以上前のソフトウェアであり、それは見て取れる。これは巨大で複雑なプログラムだ。数十年前には、EMACS は「Eight Megs And Constantly Swapping」の略だというジョークがあった。習得しやすいプログラムではない。豊富なドキュメントと組み込みのチュートリアルがあるにもかかわらず、このソフトウェアは非常に古く、その用語はマイクロプロセッサやパーソナルコンピュータより前のものだ。

その詳細なマニュアルは804ページに及び、些細な例を挙げると、画面の各部分を表す用語では、現在ウィンドウと呼ばれるものを「フレーム」と呼び、現在ペインと呼ばれるものを「ウィンドウ」と呼ぶ。キーに関する節では、*Control* キーと *Meta* キーが論じられている。これは少々厄介だ。あなたは Meta キーを持っておらず、Emacs の作者たちも持っていない。それは、今ではほとんど伝説的なほど稀少な Space Cadet Keyboard にあったキーで、Deskthority のキーボード wiki はこのキーボードについて次のように述べている。

「キーボードの聖杯として知られている。」

現代のレプリカである Keymacs キーボードを購入できる。チェコ共和国で手作りされており、どのモデルや仕様を望むかによって、Lispsaver の €2,998 から A624N Space Cadet の €6,878 までの価格となる。

言い換えれば、本物の Meta キーを持つキーボードは望めば手に入るが、お金がかかる。

1970年代にすでにプログラミングをしていた人以外には馴染みのないこうした歴史的用語の問題の一つは、意味が変遷することだ。Emacs の文脈では、「Meta」は Alt、または Mac では Opt を意味する。しかし KDE も Meta キーを使う――ただし KDE のドキュメントが「Meta」と呼ぶものは Windows キー、または Mac では Command である。大半の Linux の人々と同様に、GNOME のドキュメントはそれを Super キーと呼ぶ。

名前は重要だ。意味がある。Emacs の人々と KDE の人々のどちらが正しいのか。どちらでもない。*誰も*もう Meta キーを持っていない。私たちにあるのは Ctrl、Alt、そして Cmd/Super/Windows だ。

Emacs を近代化し、現代の UI や用語に合わせようとする勇敢な試みがあった。このハゲタカは Aquamacs を習得しようとした。Aquamacs はネイティブの macOS UI で Emacs を近代化したが、残念ながらもう保守されていない。

もう一つ、試して楽しかったのが ErgoEmacs で、キーバインドを変更し、UI を Windows や大半の Linux デスクトップで使われている IBM Common User Access の配置にずっと近いものに並べ替える。しかし、広く普及することはなく、インストールして自分の地域のキーボード配列向けに設定するには、Emacs の使い方に通じている必要がある。

Emacs は設定が非常に複雑なので、Doom Emacs やミニマリストの Emacs Solo のように、あらかじめ設定済みの Emacs ディストリビューションが複数ある。ErgoEmacs を統合し、既存のキーボード設定を引き継げる「CUA-Macs」設定を誰かが作ってくれればと思う。

そういえば、昨年 GhostBSD とともに取り上げた Gershwin Desktop プロジェクトは活発に開発中で、GNUstep を基盤にしている。開発者たちが Aquamacs を引き継いで GNUstep に適合させることもできるかもしれない。

こうした Emacs の模様替えには長い歴史がある。一例が Borland の Sprint ワープロで、その売りの一つは、当時の主要な MS-DOS ワープロ（それらがすべて IBM CUA に収斂する直前）の大半のユーザーインターフェースをエミュレートできることだった。Borland が取得する前、Sprint は *The Final Word* と呼ばれ、楽器メーカーの Mark of the Unicorn が開発していた。FinalWord は MINCE という Emacs クローンに基づいていた。

大いなるライバル

もう一つの有名な Emacs ディストリビューションは Spacemacs で、Emacs をより Vi に近いユーザーインターフェースに適合させている。
