CiscoとOpenAI、AI駆動型攻撃に対抗するオープンソースのサイバーセキュリティプロジェクトを開始

Cisco and OpenAI Launch Open Source Cybersecurity Project to Counter AI-Driven Attacks
Bold News2026-11-27 07:00報道

CiscoとOpenAI、AI駆動の攻撃に対抗するオープンソースのサイバーセキュリティプロジェクトを開始

新たな Shirudo の取り組みは、人工知能と Linux カーネル技術を用いて脆弱性を特定し、稼働中のシステムを停止することなく一時的なセキュリティ保護を展開する。

サンノゼ、11月24日: テクノロジー企業の Cisco と OpenAI は、組織が高度化する一方のサイバー攻撃からコンピューターシステムを守ることを支援することを目的とした、新たなオープンソースのサイバーセキュリティの取り組みを開発するために手を組んだ。

Shirudo と名付けられたこのプロジェクトは11月23日に発表され、恒久的なソフトウェア更新が開発・インストールされている間に、システムが保護措置を展開できるようにすることで、Linux ベースのインフラストラクチャのセキュリティを強化するよう設計されている。

この取り組みは、Cisco のネットワークおよびインフラストラクチャセキュリティにおける経験と、OpenAI の人工知能の研究開発能力を結集するものである。その中心的な目的は、特に攻撃者が AI を活用したツールを使って弱点を特定し、保護されていないシステムを悪用する機会が増えている中で、セキュリティチームが新たに出現する脆弱性により迅速に対応できるよう支援することである。

脆弱性の特定、パッチの開発、影響を受けるシステムの更新に頻繁に依存する従来のセキュリティ手法とは異なり、Shirudo は、セキュリティ上の弱点が発見されてから恒久的な解決策が展開されるまでの期間における一時的な保護の提供に重点を置いている。

これは、セキュリティ更新をインストールするためにサーバーを停止したりアプリケーションを再起動したりすると不可欠なサービスが中断されかねない、重要なデジタルインフラストラクチャを運用する組織にとって、特に重要である。

両社によると、このプロジェクトは eBPF を使用している。eBPF は、ソースコードの変更を必要とせずに、オペレーティングシステムのカーネル内で小さなプログラムを実行できるようにする Linux の技術である。

この技術を通じて、セキュリティチームは稼働中のシステムに的を絞った保護措置を導入でき、正当な運用を必ずしも中断することなく悪意のある活動を防ぐことができる。

両社は Shirudo をオープンソースプロジェクトとして公開しており、ソフトウェア開発者、サイバーセキュリティ研究者、インフラストラクチャ運用者に対し、その技術を調べ、機能を試し、改善に貢献するよう呼びかけている。

脆弱性の発見とパッチ展開の間のギャップへの対処

サイバーセキュリティの専門家が直面する主要な課題の一つは、ソフトウェアの脆弱性が特定された後にシステムを保護するまでに要する時間である。

セキュリティ上の欠陥が発見されると、開発者やテクノロジー企業は一般に、その技術的特性を理解し、修正更新を準備し、解決策をテストし、影響を受けるユーザーに配布する必要がある。

このプロセスは、脆弱性の複雑さや関係するシステムの数に応じて、数日から数週間かかることがある。

この期間中、組織は、特定された弱点を狙う攻撃にさらされたままとなる可能性がある。

システムが不可欠な業務運用を支えている場合、問題はさらに複雑になる。銀行、病院、通信会社、クラウドサービスプロバイダー、政府部門は、容易にオフラインにできないアプリケーションを運用していることが多い。

十分なテストなしに更新をインストールすると、互換性の問題が生じたり、既存のサービスの機能に影響したりする可能性もある。

Shirudo は、恒久的なソフトウェア修正が準備されている間に、特定の悪意ある活動をブロックする一時的な保護をセキュリティチームが作成できるようにすることで、このギャップに対処することを意図している。

この技術は、不審な挙動を調べ、的を絞ったセキュリティ措置を開発し、その保護が正当なアプリケーションのリクエストを妨げることなく試みられた悪用をブロックするかどうかをテストするよう設計されている。

このアプローチは、脆弱なシステムがサイバー脅威にさらされたままとなる期間を組織が短縮するのに役立つ可能性がある。

Shirudo 技術の仕組み

プロジェクトの中心にあるのは eBPF で、これは extended Berkeley Packet Filter の略である。

この技術は、Linux カーネル内で特殊なプログラムを実行するための仕組みを提供し、基盤となるカーネルのソースコードを変更することなく、セキュリティツールがシステムの挙動を観察し、特定の制御を適用できるようにする。

この機能を使うことで、Shirudo は AI エージェントが脆弱性を調査し、シールドと呼ばれる、影響を受けるシステムに取り付けることができる保護プログラムを開発できるようにすることを目指している。

シールドを展開する前に、それが正常な運用の継続を許しつつ悪意ある活動をうまくブロックするかどうかをテストできる。

このシステムには、無許可または安全でないコードが重要なインフラストラクチャに持ち込まれるのを防ぐことを意図した保護機能も組み込まれている。

両社によると、すべてのシールドは暗号署名されており、受け取る側のシステムが実行前にその真正性を検証できる。

eBPF ベリファイアと Linux のセキュリティ制御は、プログラムが適用される安全要件に適合していることを確認するための追加のチェックを提供する。

Shirudo は、システムに読み込まれた、または取り外されたセキュリティ保護の検証を支援するため、Trusted Platform Module 技術も組み込んでいる。

これらの機能は、一時的なセキュリティ措置が改変されたり、許可なく導入されたりしていないことについて、組織により大きな確信を与えることを意図している。

テストがソフトウェア脆弱性に対する可能性を示す

Cisco と OpenAI は、このプロジェクトの可能性を示すため、Java4Shell と PHP 関連の欠陥と特定された2つのセキュリティ脆弱性に関するテストを取り上げた。

OpenAI が説明した一例では、Codex を使って生成されたセキュリティシールドが、試みられた Java4Shell の悪用から稼働中の Elasticsearch サービスを保護するために使用された。

このテストでは、Java の Base64 デコーダーに入力検証チェックを追加し、その保護措置を稼働中のアプリケーションに取り付けた。

悪意ある入力を使った悪用の試みが行われた際、シールドはそのリクエストを拒否し、Elasticsearch サービスは稼働を続けた。

このデモンストレーションは、アプリケーションを再起動したりオフラインにしたりすることなく、的を絞ったセキュリティ措置を導入できることを示した。

両社はまた、Shirudo がテスト対象の PHP 脆弱性を悪用しようとする試みを特定しブロックできるコードを生成することに成功したと報告した。

これらのデモンストレーションは、AI 支援のセキュリティツールが組織による一時的な保護の開発をより迅速にする助けとなり得ることを示している。

ただし、この結果は特定のテストシナリオを表すものであり、この技術があらゆる種類のサイバー攻撃を防げることの証明と解釈すべきではない。

その有効性は、脆弱性の性質、生成された保護の質、そして展開前にセキュリティチームがそれらの措置を検証できる能力に左右される。

サイバーセキュリティにおける AI の重要性の高まり

今回の発表は、サイバー犯罪における人工知能の利用に対する懸念が高まる中で行われた。

AI ツールは、サイバーセキュリティの専門家と悪意ある行為者の双方がデジタルセキュリティに取り組む方法を変えつつある。

攻撃者は、自動化されたシステムを使ってソフトウェアを分析し、弱点を特定し、悪意あるコードを生成し、脆弱なインフラストラクチャを悪用する手法を開発できる可能性がある。

同時に、サイバーセキュリティ企業は、大量のセキュリティ情報を調べ、異常な活動を特定し、新たな脅威への対応を加速するために、AI の導入を増やしている。

サイバー攻撃の高度化は、セキュリティインシデントを特定し封じ込める能力を向上させるよう、組織にさらなる圧力をかけている。

従来のサイバーセキュリティシステムは、事前に定義されたルール、シグネチャ、手動の調査に依存することが多い。これらの手法は依然として重要であるものの、絶えず進化する新たな攻撃手法に迅速に対応するのが難しい場合がある。

AI 支援のセキュリティシステムは、パターンの分析、不審な挙動の調査、是正措置の推奨を支援できる。
