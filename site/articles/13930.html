Cisco SD-WAN に重大な脆弱性、最高の深刻度スコア10（CVE-2026-20127）

Cisco Catalyst SD-WAN インフラに影響する重大な認証バイパス脆弱性に、最高の CVSS 深刻度スコア 10.0 が付与された。CVE-2026-20127 として追跡されているこの欠陥により、認証されていないリモートの攻撃者が管理者権限を取得し、ネットワーク設定を支配できる可能性がある。

Cisco は 2026 年 2 月 25 日にこの脆弱性を公表し、ピアリング認証の仕組みの弱点により、攻撃者が影響を受けるシステム上のセキュリティ制御を回避できる可能性があると警告した。セキュリティ研究者と政府のサイバーセキュリティ機関が、実際の攻撃での悪用の証拠を報告しており、Cisco のソフトウェア定義ネットワーク技術を使用する組織にとって重大な懸念となっている。出典: Cisco advisory。

どの Cisco 製品が影響を受けるか

CVE-2026-20127 は、旧称 vSmart の Cisco Catalyst SD-WAN Controller と、旧称 vManage の Cisco Catalyst SD-WAN Manager に影響する。この脆弱性は、SD-WAN 導入環境内で信頼関係を確立するためにこれらのシステムが使用するピアリング認証のプロセスに関連している。

旧称 vBond の Cisco Catalyst SD-WAN Validator も、ベンダーのアドバイザリで言及されている。

この脆弱性は CWE-287（不適切な認証）に分類される。CVSS 3.1 のスコア 10.0 は、リモートの攻撃者が既存の認証情報なしに、ユーザーの操作も必要とせずにこの弱点を悪用し、影響を受けるシステムの機密性、完全性、可用性を侵害しうることを反映している。

このリスクは、オンプレミスの導入環境と、サポート対象の Cisco ホスティング SD-WAN クラウド環境の両方に及ぶ。

脆弱性の仕組み

この欠陥は、ピアリング認証の仕組みが正しく動作しないために存在する。攻撃者は、影響を受けるシステムに細工したリクエストを送信し、通常の認証プロセスを回避しようとしうる。

悪用に成功すると、攻撃者は内部の特権の高い非 root アカウントを使用して Cisco Catalyst SD-WAN Controller にアクセスできる可能性がある。そこから攻撃者は、ネットワーク機器の管理に使われるネットワーク設定プロトコルである NETCONF にアクセスし、SD-WAN ファブリックの設定を操作しうる。

このアクセスにより、ネットワーク設定の変更、通信への干渉、組織のネットワーク基盤内での足場の確保につながる可能性がある。

影響は、攻撃者のアクセス権と影響を受けるネットワークの設計によっては、最初に侵害されたコントローラーを越えて広がる可能性もある。

実際の悪用と潜在的な影響

この脆弱性は、実際の攻撃で悪用が確認されているため、特に懸念される。Cisco の Talos 脅威インテリジェンスチームと政府のサイバーセキュリティ機関は、UAT-8616 として追跡されている脅威アクターに関連する活動を指摘している。セキュリティ分野の報告によると、攻撃者は侵害された SD-WAN インフラを使い、不正なピア接続を確立し、永続的なアクセスを維持してきたという。

カナダ・サイバーセキュリティセンターも、影響を受けた組織の SD-WAN 設定に悪意のあるピアが追加され、さらなる管理者アクセスと長期的な永続化を可能にしたインシデントを報告している。

これらの知見は、集中管理されるネットワーク管理基盤を侵害することのリスクを浮き彫りにしている。SD-WAN のコンポーネントを支配した攻撃者は、単一の機器だけでなく、複数の拠点にわたる接続性とセキュリティに影響を及ぼしうる。

組織ができる保護策

Cisco は CVE-2026-20127 に対するソフトウェアアップデートを公開しており、影響を受けるシステムを修正版リリースにアップグレードするよう推奨している。同社は、いかなる回避策も脆弱性を完全には解消しないと述べている。

管理者は、自社の導入環境に適した修正版リリースを特定するため、Cisco の公式アドバイザリを参照すべきである。公開されているガイダンスには、次のアップグレードパスが含まれている:

組織は、特に古いリリースが保守期間を終了している場合には、正確なアップグレード要件を Cisco の公式セキュリティアドバイザリで確認すべきである。

パッチ適用に加えて、セキュリティチームは次の対応を行うべきである:

  • ファイアウォールとアクセス制御リストを使用して、SD-WAN の制御コンポーネントへのアクセスを制限する。
  • TCP ポート 22 と 830 を含む管理ポートへのアクセスを、認可されたシステムに限定する。
  • 認証ログを確認し、予期しない認証成功と見慣れない送信元 IP アドレスを探す。
  • 予期しないピアリングイベント、未知の機器、認可されていない設定変更を調査する。
  • フォレンジック調査を支援するため、システムログと仮想スナップショットを保全する。
  • ログをリモートのログサーバーに転送し、Cisco の SD-WAN ハードニングガイダンスに従う。

Cisco は特に、`/var/log/auth.log` で `vmanage-admin` アカウントに関わる予期しない公開鍵認証の成功を確認し、送信元アドレスを認可されたシステムの IP と照合するよう推奨している。

侵害が疑われる場合、組織は関連する証拠を保全し、パッチを適用するだけで攻撃者の既存のアクセスが削除されると想定せず、脅威ハンティングの調査を実施すべきである。サイバーセキュリティ機関の共同ガイダンスも、証拠を収集し、侵害指標を確認した上で、影響を受けたインフラを完全にパッチ適用するよう推奨している。

結論

CVE-2026-20127 は、認証の仕組みの弱点がいかに重要なネットワーク基盤をリモートの攻撃者にさらしうるかを示している。CVSS スコア 10.0 で悪用も確認されているため、この脆弱性は Cisco Catalyst SD-WAN に依存する組織にとって深刻なリスクである。

管理者は、ソフトウェアのバージョン確認を優先し、適切なセキュリティアップデートを適用し、不正アクセスの兆候を調査すべきである。攻撃成功後に永続的なアクセスが残る可能性を踏まえ、組織は SD-WAN の設定とセキュリティログを見直し、基盤がすでに侵害されていないかを確認すべきである。
