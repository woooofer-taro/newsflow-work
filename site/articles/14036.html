Nvidiaのネットワーキング売上、Ciscoの総売上を超える

Nvidia's networking revenue now exceeds Cisco's total sales
news.lavx.hu2026-11-01 07:00報道

Nvidia のネットワーキング売上高が Cisco の総売上高を上回る - news.lavx.hu

Nvidia の第2四半期のネットワーキング売上高は175億ドルとなり、全製品を合わせた Cisco の173億ドルをわずかに上回った。2019年の Mellanox 買収と Blackwell の NVSwitch トレイが、GPU ベンダーをクラスターインターコネクトの支配的な供給元に変えた。

Nvidia のネットワーキング事業は第2四半期に175億ドルを稼ぎ出した。同期間の Cisco の総売上高は173億ドルに達した。この差は構造的な転換を示している。GPU ベンダーが、従来型のネットワーキング大手が全製品ラインで販売する額を上回るインターコネクト機器とスイッチ機器を販売するようになったのである。

2019年、Jensen Huang は Mellanox に69億ドルを費やした。当時の Mellanox は、主流の Ethernet ではなく、ハイパフォーマンスコンピューティングのクラスター向けに ConnectX NIC と InfiniBand スイッチを製造していた。スーパーコンピューティングと Microsoft の大規模な導入事例を除けば、InfiniBand のハイパースケールでの存在感は限られていた。この取引により、Nvidia はコンポーネント供給元ではなくシステムビルダーとして位置づけ直された。GPU クラスターを購入する顧客にはインターコネクトが必要であり、Mellanox がそのファブリックを提供した。

Nvidia の戦略は共同設計を中心としており、各部品を個別に最適化するのではなく、特定のワークロードに合わせて GPU、スイッチ、NIC、ソフトウェアを調整する。Dell'Oro Group のアナリスト Sameh Boujelbene は、顧客が Nvidia を選ぶのは、AI ワークロード向けに最適化された、コンピュートとネットワーキングが緊密に統合されたアーキテクチャのためだと指摘した。この統合により、導入時間が短縮される。

Recursion の CTO である Ben Mabey は、実務上の影響を裏付けた。2013年に設立された Recursion は、機械学習を創薬に応用している。同社のデータセットは現在50ペタバイトを超え、多くの大規模言語モデルの学習に使われるテキストコーパスより大きい。同社の最初のクラスターである BioHive Zero は、Ethernet で接続されたゲーミング向けの GTX 1080 カードを使っていた。ネットワークはワークロードに追いつけなかった。

2つ目のクラスター、約300基のアクセラレーターを持つ A100 ベースのシステムでは、Recursion は Nvidia Quantum InfiniBand スイッチと ConnectX NIC に切り替えた。コンピュートとインターコネクトを1つのベンダーから購入することで、Recursion はクラスターを単一のシステムとして扱えるようになった。Mabey のチームは調整の支援を求めて Nvidia に連絡した。エンジニアがスタック全体を一緒に最適化した。このレベルの統合は、以前は Cray のようなブティック型のスーパーコンピュータービルダーだけが提供していた。

Nvidia は、ネットワーキングを別個の項目として開示してきたわけではない。CFO のコメントと売上高の追跡に基づくと、この事業は2019年以降着実に成長し、その後2度跳ね上がった。最初の転換点は、ChatGPT が AI ゴールドラッシュを引き起こした暦年2023年（会計年度2024）に訪れた。2度目は、Blackwell GPU が生産に入り大量出荷された2024年から2025年にかけて広がった。

Boujelbene は、Blackwell に結びついた2つの要因を挙げた。NVLink スイッチと、AI バックエンドネットワーク向け Spectrum-X Ethernet の採用の加速である。ユーザーは Nvidia クラスター内で Ethernet スイッチを大規模に導入し始めた。Elon Musk の Colossus スーパーコンピューターは、200,000個の H100 および H200 チップを備え、2024年に Spectrum-X Ethernet を使って稼働を開始し、これまでのこの種の導入として最大級のものの一つである。Meta も、100万GPUを目標とするオハイオ州ニューアルバニーの Prometheus 学習サイトで Spectrum スイッチに依存している。

Spectrum-X が成功しているのは、InfiniBand の低レイテンシーと高い利用率という特性を再現しつつ、Ethernet のより高い radix と幅広い相互運用性を利用しているためである。Ethernet スイッチは1台あたりのポート数が多く、大規模クラスターに必要なスイッチの総数を減らす。InfiniBand はスケールするが、ある GPU 数を超えるクラスターでは、Ethernet のほうが同程度の利用率を保ちながら機器コストを下げることが多い。

ここで Nvidia は単独ではない。Broadcom、Cisco、AMD などは、smartNIC とスイッチの最適化によって InfiniBand に近い利用率を達成している。Mabey と Boujelbene が強調したように、違いは統合にある。ネットワークとコンピュートが、単一ベンダーの調整、ファームウェア、サポート経路を共有する。

Blackwell は経済性をさらに変えた。この世代以前は、NVLink と NVSwitch は単一サーバー内で最大8基の GPU を接続していた。GB200 NVL72 はそれらのスイッチを専用のトレイとして切り出し、ラックあたり9つとして、72基の GPU を1つの論理アクセラレーターに結び付けた。各 NVL72 ラックには9つの NVSwitch トレイが付随する。Nvidia のスケールアウトスイッチを使わない顧客であっても、ラックを構築するには NVSwitch 機器を購入しなければならない。

Boujelbene は、NVSwitch が現在 Nvidia のネットワーキング売上高の約3分の1を占めると推定しており、2年足らず前にはほぼゼロだった。この割合は、NVLink スイッチングがいかに急速に成長エンジンになったかを示している。

Nvidia はライセンス供与を通じてこの足場を広げている。昨年初めに発表された NVLink Fusion は、インターコネクトをサードパーティのチップ設計者に開放する。Marvell、Qualcomm、Arm、Fujitsu、MediaTek、d-Matrix は、NVLink Fusion を使用する CPU とカスタムアクセラレーターの計画を発表している。これらのチップはチップ間通信に依然として NVSwitch トレイを必要とし、Nvidia は NVSwitch の生産をライセンス供与していない。その結果、Nvidia GPU を使わないクラスターでも、スイッチの販売が増えることになる。

Boujelbene はこれを、カスタムアクセラレーター市場全体で AI ネットワーキング支出のより大きなシェアを獲得するための戦略的な動きだと呼んだ。

Nvidia のネットワーキングに関する野心は、現行の Ethernet および NVLink 製品にとどまらない。同社は、従来の学習クラスターよりも緊密な通信パターンを要求するエージェント型 AI ワークロード向けに、スケールインのネットワーキングを開発している。コパッケージドオプティクス（CPO）のようなイノベーションは、クラスターの規模が拡大するにつれて生じる帯域幅、電力、スケーラビリティの限界に対処することを目指している。

あらゆるものを計測するクラスターアーキテクトやホームラボビルダーにとっての教訓は明快である。インターコネクトはもはや周辺機器ではない。ディスクリート GPU と汎用 Ethernet で構築したクラスターは動作するが、統合スタックの利用率やサポート効率には及ばない。Blackwell や将来の世代を中心に構築を計画しているなら、スイッチトレイと NIC を中核コンポーネントとして予算に組み込むこと。コモディティネットワーキングの時代は終わった。
