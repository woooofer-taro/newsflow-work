OpenAI & Cisco Shirudo: AI が停止なしでエクスプロイトを阻止

ダウンタイムを許容できないシステムにとって朗報として、Cisco と OpenAI は、恒久的なセキュリティ修正が開発されている間、組織が脆弱なシステムを保護できるよう、力を合わせている。

この取り組みは Shirudo と名付けられ、実行中のアプリケーションを中断することなく、AI が生成した一時的な保護策をエクスプロイトに対して展開するよう設計されたオープンソースのセキュリティプロジェクトである。

日本語の「盾」を意味する言葉にちなんで名付けられた Shirudo は、AI エージェントが脆弱なシステム向けの的を絞ったセキュリティ対策を開発し、テストすることを可能にする。

これらの保護策は、人間のオペレーターによる承認を受けた後に展開でき、セキュリティチームが恒久的なパッチを実装するための貴重な時間を確保する。

これにより、本物のパッチが作られている間に、AI エージェントが脆弱なシステム向けの小さく的を絞ったシールドを書いてテストでき、本番に投入される前には必ず人が承認する。

「あなたが知っているすべてのリーダーが、今日、AI 主導のセキュリティ脅威にどう対応し続けるかについて考える時間を過ごしました」と、Cisco の会長兼 CEO である Chuck Robbins は LinkedIn の投稿で書いている。

「かつては数日から数週間かかっていた攻撃が、今では数分から数時間で行われる一方、恒久的な修正には依然として時間がかかります。

「セキュリティチームには、その時間を稼ぐ手段が必要です。だからこそ、Cisco と OpenAI は、システムが自らを守るのを助けるオープンソースプロジェクト Shirudo を立ち上げます。

「これにより、本物のパッチが作られている間に、AI エージェントが脆弱なシステム向けの小さく的を絞ったシールドを書いてテストでき、本番に投入される前には必ず人が承認します。」

この取り組みは、インフラおよびセキュリティチームにとって高まりつつある課題、すなわち、脆弱性の発見から恒久的な修正の展開までの空白期間にシステムを保護するという課題への対処を目指している。

Cisco と OpenAI の Shirudo は AI を使って Linux セキュリティをどう強化するか

Shirudo は extended Berkeley Packet Filter（eBPF）を使用する。これは、小さなプログラムをオペレーティングシステム内の特定のポイントで実行できるようにする Linux 技術である。

これにより、セキュリティチームは、影響を受けるサービスを再起動することなく、不審なアクティビティを監視し、的を絞った保護策を導入できる。

悪意のあるアクティビティと正当なアクティビティの両方をブロックしかねない従来のセキュリティ対策とは異なり、Shirudo は、脆弱な動作と通常のアプリケーションリクエストを区別するよう設計されている。

このプロジェクトは、ライブ保護、AI 支援による脅威調査、信頼できる展開、ハードウェアに裏付けられた検証という 4 つの主要な機能を統合している。

その eBPF シールドは、アプリケーションの動作継続を許しながら、脆弱なコードパスをブロックできる。

eBPF を使えば、提案された保護策を、オペレーターが展開を承認する前に、実際のワークロードに対してテストすることもできる。

「私たちは防御者に、脆弱性をより速く見つけて修正するための、より優れたモデルとツールを提供していますが、今日バグを見つけたからといって、明日すべてのシステムにパッチを当てられるわけではありません」と、OpenAI の社長兼共同創業者である Greg Brockman は述べている。

「私たちは Shirudo で Cisco と緊密に提携し、チームが修正を構築して展開する間、稼働し続ける必要のあるシステムを保護できるよう支援しています。

「非常に多くのチームが同じソフトウェアに依存しているので、これらのツールをオープンに構築することは理にかなっています。

「いまや、あるチームがシステムを保護するより良い方法を見つけたとき、他のチームはゼロから始める必要がありません。」

Java4Shell テストが Shirudo の実環境でのセキュリティ上の可能性を実証

管理された環境でのテストにより、Shirudo が、再起動を必要とせずに、実行中のアプリケーションを現在進行中のエクスプロイトから保護できることが示された。

OpenAI の Codex を使い、チームは Java4Shell に対処するための的を絞ったシールドを生成し、Java の Base64 デコーダーに入力チェックを追加した。

この保護策は、実行中の Elasticsearch プロセスに直接アタッチされ、この脆弱性を悪用しようとする悪意のある入力を正常に拒否した。

このデモンストレーションは、恒久的なパッチが準備・展開される間に、AI が生成したセキュリティ対策が組織のエクスポージャーを減らすのにどう役立つかを示している。

オープンソースの Shirudo プロジェクトは開発者に貢献を呼びかける

Cisco と OpenAI は、Shirudo を Berkeley Software Distribution（BSD）2-Clause ライセンスの下でオープンソースプロジェクトとして公開しており、その BPF プログラムは BSD と GNU General Public License（GPL）のデュアルライセンスとなっている。

開発者、セキュリティ研究者、インフラオペレーターは、コードを調べ、保護策をテストし、開発に貢献するよう呼びかけられている。

両社はまた、テスト済みのシールドを脆弱性の開示と併せて利用可能にすることを目指しており、組織が新たなサイバー脅威により迅速に対応できるよう支援する。

Shirudo により、Cisco と OpenAI は、システムがサービスの可用性を損なうことなく脆弱性により速く対応できる、AI 支援のインフラセキュリティへ向けた一歩を踏み出している。

  • Shirudo は、Cisco と OpenAI によるオープンソースのセキュリティプロジェクトで、AI エージェントを使って脆弱なシステム向けの一時的な保護策を構築する
  • Shirudo は Linux 技術である extended Berkeley Packet Filter（eBPF）を使用して、影響を受けるサービスを再起動することなく、的を絞ったシールドを展開する
  • AI が生成したすべてのシールドは、本番に投入される前に人間のオペレーターが承認しなければならない

  • Shirudo は、ライブ保護、AI 支援による脅威調査、信頼できる展開、ハードウェアに裏付けられた検証という 4 つの機能を組み合わせている
