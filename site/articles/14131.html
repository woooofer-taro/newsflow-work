NaaSは誇大広告に見合っていない。それでもなお価値があるか？

NaaS hasn’t lived up to the hype. Is it still worth it?
Network World2026-11-03 07:00報道

NaaSは期待に応えられていない。それでも導入する価値はあるのか？

Network as a service は、初期の普及予測に届いておらず、企業は管理の簡素化という利点と、より高いコスト、ベンダーロックイン、そして NaaS が実際に何を提供するのかという疑問とを天秤にかけている。

2021年、Gartner は Network as a Service（NaaS）の有望な未来を見込んでいた。当時、採用は企業の1%未満にとどまっており、Gartner はその数字が2024年までに15%に上昇すると予想していた。

しかし、Gartner の最新のネットワーキング向けハイプサイクルでは、NaaS の市場浸透率は依然として1%から5%にとどまっている。これは Gartner の以前の予想に届いていない。実際、Gartner は 2026 Hype Cycle for Enterprise Networking において、NaaS を「幻滅期」の奥深くに位置づけている。

NaaS の導入理由

NaaS は、マサチューセッツ州東部に55エーカーのキャンパスを持つ Rivers School でうまく機能している。このキャンパスには進学準備校と音楽院があり、合わせて1,700人以上の生徒が在籍している。

Rivers のテクノロジー・イノベーション担当ディレクターである John Adams は2024年の夏に着任し、老朽化した学校の LAN のアップグレードが最優先事項だった。当時、学校のネットワークには115台の Wi-Fi アクセスポイントに加え、スイッチ、ルーター、ケーブルがあり、接続を提供する ISP が2社あった。

「スイッチの在庫すべてを交換する必要があり、アクセスポイントの約3分の1もサポート終了になっていました」と Adams は言う。

「更新が必要だと上級幹部に提案しました」と彼は言う。理事会が要請を承認して予算を割り当てた後、Adams は選択肢の調査に乗り出した。当初の計画は、学校がすでに持っている機器を、最も古いハードウェアから順にアップグレードし、カバレッジと性能を改善し、セキュリティを向上させ、しかもそれらすべてを人員を増やさずに行おうとするものだった。

ネットワークを管理する従業員は1人で、5人からなるテクノロジーチームの他の誰も手伝える資格を持っていなかったため、理想的には、新しいシステムは必要に応じて誰かが作業の一部を引き継げるものであることも求められた。

既存の構成を部分的に更新する代わりに、Rivers は NaaS を選び、この分野の二大ベンダーの1つである Meter を選定した。最終決定は2025年の晩春に行われ、新しいネットワークは8月末に授業が再開されるまでに稼働していた。

夏の間に、Meter は現地調査を行い、ネットワークを設計し、コンクリートブロックと馬毛入り漆喰の建物にケーブルを通し、すべての機器を設置してテストした。新しいネットワークは25万平方フィートの建物スペースをカバーし、195台のアクセスポイント、55台のスイッチ、3台のファイアウォール、そしてそれらすべてをつなぐケーブルがある。すべての機器は Meter が製造し、所有し、設置し、必要に応じて保守または交換する。デバイス数に加え、ネットワークのカバレッジ、性能、セキュリティ、管理性のすべてが劇的に向上した。

また、すべてのハードウェアが Meter のものであるという事実が、マネージドサービスプロバイダーを使うよりも魅力的な選択肢にしたと Adams は言う。

「MSP の場合、複数の異なる会社を使うことになります」と彼は言う。「Palo Alto のファイアウォール、Aruba のスイッチ…。MSP がハードウェアを所有することはありません。」

NaaS アプローチの1つの制約は地理的なものだ。新しいアクセスポイントのうちいくつかはパビリオンに設置されているため、屋外スペースの一部はカバーされているが、ほとんどの場合、学校のスポーツ競技場やその他の屋外スペースはカバーされていない。

「Meter は平方フィート単位で課金するので、広大なサッカー場を加えると費用がかさむ可能性があります」と Adams は言う。

最大の即時的な利点は管理のしやすさであり、さらにサービス対応のための残業代を心配する必要がなくなったことだった。

「ダッシュボードの品質が高いので、必要なトレーニングはあまりありません」と Adams は言う。「ネットワークを可視化できるのは雲泥の差です。私たちの仕事の質が向上しました。作業ができ、それがとても簡単です。」

ユーザーがネットワークの問題について苦情を言う代わりに、問題はダッシュボード上または通知として表示され、チームは苦情が届く前から解決に取りかかることができる。

仮想的に対処できる問題が発生した場合は、Adams と彼のチームが自分たちで対応するか、Rivers の誰かが、時間外であっても対応する。そして物理的な問題がある場合は、「現地に人を派遣してくれます」。

従来の方法で既存のインフラをアップグレードすることを検討していたときには、サポートの部分を大幅に過小評価していたと Adams は言う。通常の勤務時間外に人が来て20時間かかるような問題があれば、CFO のところへ行かなければならなかっただろう。「そしてアクセスポイントを追加したければ、それも CFO との別の話し合いになります。」

NaaS モデルでは、すべてが含まれていると彼は言う。「長期的には、コストを節約できていると思います。」

NaaS を押しとどめる課題

しかし、すべての組織が Rivers と同じ利点を得られるわけではない。たとえば、企業がすでに稼働中のネットワークを持っている場合、すべてを取り外して NaaS アプローチに切り替えるのは、時間と費用の無駄になるかもしれない。Gartner によると、従量課金型の価格モデルは予測不能になりうるうえ、一般に NaaS は従来の capex ベースの価格モデルより高くなることがある。さらに、NaaS がハードウェアを供給するため、組織はそのプラットフォームにロックインされる。

Gartner は、組織のリソースが限られていて、資産を所有しない、SLA に基づくターンキー型のネットワークソリューションを求めている場合に、NaaS は理にかなうと述べている。

Dell'Oro Group のリサーチディレクターである Siân Morgan は、過去3年間 LAN-as-a-service 市場を調査し、クラウドコンピューティングのモデルをネットワーキングに置き換えるという期待を検証してきた。しかし、ベンダーが実際にそれを行うのに苦労しているのを目にしているという。

「キャンパスネットワーキングには多くのローカルハードウェアが必要で、そのためクラウドに着想を得たモデルを模倣するのが難しいのです」と彼女は言う。

加えて、従来のアプローチは、企業がローカルエリアネットワークをどのように構築し使うかについて、多くの柔軟性を与える。

「LAN-as-utility ベンダーが設計した技術は、その柔軟性の多くを奪ってしまいました」と彼女は言う。

NaaS は WAN 側ではさらに進化していると、同じ Dell'Oro のアナリストで、エンタープライズセキュリティ・ネットワーキング調査のシニアディレクターである Mauricio Sanchez は言う。従来の通信事業者は NaaS の一形態を提供していると彼は言う。

「そして今起きているのは、一部の SASE プロバイダーが準 NaaS プロバイダーへと変貌していることです」と彼は言う。「WAN バックボーンのリンクを廃止して、すべてのトラフィックを彼らに任せることができます…それは、ますます多くの企業が進んでいる分岐点です。」

しかし、これらのサービスは通常、従来の WAN が持つ機能の全範囲を提供するわけではない。

「期待が現実より大きければ、人々は不満を抱くでしょう」と彼は言う。

そして、NaaS の WAN 側と LAN 側のどちらにも、使用量が予期せず増加した場合に衝撃的な請求額を招きうる従量課金のアプローチがある。

「クラウドの請求書が届いて、いやはや、かなり高額になっているという恐ろしい話は何度も耳にしています」と Sanchez は言う。「価格がどうあるべきかについては、いまだ議論を重ねている最中で、企業が不利な側に立って痛い目に遭えば、落とし穴があるでしょう。」

そもそも NaaS とは何なのか？

NaaS の採用が限定的な理由の1つは、NaaS と銘打たれたサービスのほとんどが、単なる価格設定やライセンスの変更であるか、通信事業者によるネットワーク・オン・デマンドの提供だからである。

「NaaS という用語はしばしば誤用され、何も説明しないものになっています」と Gartner は述べている。

Dell'Oro の Morgan は、NaaS が実際に何であるかについて明確さが欠けていることに同意しており、他のアナリストも同様である。
