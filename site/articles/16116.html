Linspace Telecom、netElastic vBNG、CGNAT、netVisionで50%超の設備投資削減と大幅な性能向上を達成

Linspace Telecom Achieves Over 50% Capex Savings and Major Performance Gains with netElastic vBNG, CGNAT, and netVision
Detroit Free Press2026-11-25 07:00報道

*レガシーな Cisco ASR 1000 BNG からオープンな x86 ネットワーキングへ移行し、より高いスループット、優れた IPv6 性能、そして大幅な省エネルギーと省スペースを実現*

netElastic の Linux サーバー上での迅速な導入、標準パッケージマネージャーによる独立したアップグレードパス、そして迅速な専門家サポートが、当社に運用上の俊敏性と必要なセキュリティ態勢をもたらしてくれています。

— André Mamitzsch、CTO、Linspace Telecom GmbH

米国カリフォルニア州サンタクララ、2026年11月24日 /EINPresswire.com/ — ブロードバンド ISP 向けソフトウェアソリューションの主要イノベーターである netElastic は本日、自治体の公益事業会社向けにホワイトラベルのブロードバンドサービスを専門とするドイツの通信事業者 Linspace Telecom が、netElastic の仮想 Broadband Network Gateway（vBNG）、Carrier-Grade NAT（CGNAT）、および netVision 管理ソリューションの導入に成功したと発表した。この移行により、50パーセントを超える設備投資（Capex）の削減、電力およびラックスペースの大幅な削減、IPv4/IPv6 デュアルスタック性能の向上が実現し、同時にベンダーロックインとサプライチェーンの脆弱性が解消された。

Linspace Telecom は、エネルギー、水道、ブロードバンドを提供する自治体の供給会社にサービスを提供している。これらの会社は、完全な ISP プラットフォームを自ら運用する規模を持たないことが多い。同社は柔軟なホワイトラベルパートナーとして、技術運用と規制遵守を担いつつ、顧客が自社ブランドとしてサービスを提供できるようにしている。COVID 時代のサプライチェーンの混乱や、Cisco や Juniper などの従来型ベンダーによるライセンス料の上昇に直面し、Linspace は市販のオフザシェルフ（COTS）サーバー上に構築された、オープンで標準ベースの代替手段を求めた。

オープンネットワーキングがより高いスループット、より強力な IPv6 性能、柔軟な機能を実現

以前の Cisco ASR 1000 シリーズ BNG の導入は、Linspace Telecom に約 20 Gbps のベースラインスループットを提供していたが、デュアルスタック IPv6 トラフィックと加入者の需要が増大するにつれて、アーキテクチャ上の制約に直面した。標準的な Dell x86 サーバー上で 100G インターフェースとともに動作する netElastic のソフトウェアは、現在、High Availability 構成での 70 Gbps という Linspace Telecom の要件に対応している。

netElastic vBNG の導入は非常に迅速であることが分かり、通常は数日ではなく数時間で完了した。Linspace は、Fiber-to-the-Home（FTTH）導入において、vBNG のマルチテナント PPPoE 加入者管理を、QoS、Rate Limiting、Traffic Shaping とともに利用している。共有 IPv4 アドレスを用いた CGNAT の実装により、アドレス枯渇は首尾よく緩和された。netVision のグラフィカルダッシュボードは、変換上限、CPU およびメモリ使用率の可視性を提供するが、設定は主に CLI 主導のままである。自動化には、セッションを終了させ帯域幅プロファイルを更新するための Change-of-Authorization 要求の処理が含まれる。

50% を超える Capex 削減に加え、電力とスペースの大幅な削減

財務面の成果は説得力がある。設備投資は、レガシー機器と比較して50パーセントを超えて削減された。3ラックユニット（3RU）のレガシーボックスを 1ラックユニット（1RU）の Dell サーバーに置き換えたことで、大幅な省エネルギーとラックスペースの削減が得られた。また、簡素化されたアーキテクチャにより、経験の浅いエンジニアでも現地での設置を行えるようになった。

コメント

「サプライチェーンの回復力、劇的に低いコスト、そして強力な IPv6 性能を備えたデュアルスタックルーティングを実行できる能力により、決定は明白なものとなりました」と、Linspace Telecom GmbH の CTO である André Mamitzsch は述べた。「netElastic の Linux サーバー上での迅速な導入、標準パッケージマネージャーによる独立したアップグレードパス、そして迅速な専門家サポートが、当社に運用上の俊敏性と必要なセキュリティ態勢の両方をもたらしてくれました。当社はすでに、残りのレガシーボックスの移行を計画しています。」

「Linspace Telecom のように、オープンで標準ベースのネットワーキングを受け入れる革新的なサービスプロバイダーと提携できることを誇りに思います」と、netElastic の CEO 兼 CTO である Weixiao Liu は述べた。「当社の vBNG、CGNAT、netVision ソリューションは、コモディティハードウェア上でキャリアクラスの性能を提供するよう設計されており、オペレーターが競争し成長するために必要な柔軟性、セキュリティ、コスト面の優位性を提供します。」

netElastic について

netElastic は、CGNAT を含む業界初の仮想ブロードバンドネットワークゲートウェイ（vBNG）の一つをゼロから開発した。2019年の最初の顧客獲得以来、netElastic は世界中の300社を超える ISP 顧客にサービスを提供している。netElastic の業界における重要なマイルストーンには、2,000日間のアップタイムと、x86 サーバー上の単一ルーターインスタンスでの 1 Tbps のスループットが含まれる。netElastic はカリフォルニア州サンタクララに拠点を置いている。
