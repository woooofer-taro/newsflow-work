Hitachi UCPのアップデート、NVMeキャッシュとGPUサーバーを含む

Hitachi UCP update includes NVMe cache, GPU server
Cisco (news)2026-10-31 07:00報道

この記事の全文訳は出せませんが、内容の要約なら日本語でお出しできます。

要約: Hitachi Vantara の UCP 製品群の更新（記事公開時点の情報）

  • 全体: Hitachi Vantara は Unified Compute Platform（UCP）の製品群に、新しいハードウェア、NVMe ベースのキャッシュ対応、自動管理機能、認定済みの事前統合アプリケーションを追加した。UCP Advisor は、コンピュート、ストレージ、ネットワークを単一の画面で管理・オーケストレーションする。
  • NVMe の展望: Hitachi は、エンドツーエンドの NVMe 対応についての長期ロードマップは明らかにしなかった。担当者は「年内の残りの期間について完全なロードマップを計画している」とだけ述べた。
  • UCP HC（ハイパーコンバージド）: VMware vSAN 6.7 に対応し、新モデル UCP HC V220 を追加。Intel Optane によるNVMe キャッシュに対応した V123F モデルを DS120 サーバーで提供する。事前検証済みの Horizon Fast Track VDI オプションも加わった。
  • UCP RS（ラックスケール）: VMware Cloud Foundation 2.3 と vSAN 6.7 に対応し、ハイブリッドクラウド向けとされる。全フラッシュサーバーには Intel Skylake プロセッサを採用。
  • GPU 対応サーバー: 8月に、NVIDIA Tesla GPU を搭載した DS225 サーバーの出荷を予定。VDI、CAD、CAE、テスト・開発などを想定した用途。
  • その他の8月予定: 2U 2ソケットの DS220、2U 4ソケットの DS240 を追加（従来の 1U DS120 より容量が大きい）。複数の外部ストレージアレイへの対応も追加予定で、マルチテナントが必要な大規模導入を想定している。
  • UCP CI（コンバージド）: 新しい VSP 350、370、700、900 に対応。小型の単一ラック構成を低価格で追加。SAP HANA と Oracle データベース向けに最大16コアまで拡張できる DS7000 サーバーと、標準1Uの管理サーバーを追加した。
  • UCP Advisor 2.7: ポリシーベースのプロビジョニング、ベアメタルプロビジョニング（コンテナ用途）、VSP のグローバル・アクティブ・デバイス機能のボリューム管理、OpenStack・コンテナ・VMware 各種アダプターへの対応を追加。
  • 事前統合ソリューション: SAP HANA プラットフォーム向けのデータ分析ソリューションと、Oracle Enterprise Data Warehouse 向けのソリューションを追加。後者は、温・寒データを UCP RS 上の認定 MongoDB クラスターへオフロードできる。
