BroadcomがVMware Cloud FoundationをAI、セキュリティ、復旧機能で拡張

Broadcom expands VMware Cloud Foundation with AI, security, and recovery capabilities
Network World2026-11-05 07:00報道

Broadcom、AI・セキュリティ・リカバリ機能で VMware Cloud Foundation を拡充

新しい VMware Cloud Foundation の機能は、AI インフラストラクチャの展開、セキュリティ、ディザスタリカバリを対象としており、vSphere Express は小規模な環境に仮想化をもたらす。

Broadcom は今週、VMware Cloud Foundation（VCF）製品ポートフォリオを、新たな AI インフラストラクチャ、セキュリティ、ディザスタリカバリの機能で拡充すると発表した。同社はまた、小規模な IT 環境を持つ顧客向けに設計された仮想化製品も発表した。

Broadcom は VCF を、従来型の仮想マシン、コンテナ、AI ワークロードを実行するためのプライベートクラウドプラットフォームと位置づけている。また、これまで高度なサービスとして提供されていた特定のセキュリティおよびリカバリ機能を、VCF に直接移している。

「私たちは常に、ポートフォリオが、あらゆる規模・ニーズの顧客に対応するうえで適切な位置と適切なサイズにあるかを見ています」と、Broadcom の VCF 部門のプロダクトマーケティング担当バイスプレジデントである Prashanth Shenoy 氏は、記者向け説明会で述べた。

VMware vSphere Express は、VMware vSphere Foundation や VCF プライベートクラウドスタック全体のより広範な機能を必要とせず、基本的な仮想化機能を必要とする組織向けの新製品である。vSphere 9 上に構築された Express 製品は、最大 128 コアの環境をサポートし、VM のライブマイグレーション用の vMotion、高可用性、分散スイッチング、迅速なパッチ適用、Trusted Platform Module（TPM）によるセキュリティ機能を含む。

Shenoy 氏は、vSphere Express の顧客は、インフラストラクチャの要件が拡大するにつれて、vSphere Foundation や VCF にアップグレードできると説明した。

Broadcom はまた、AI ワークロード向けのインフラストラクチャの展開と管理にかかる時間とコストも対象としている。新しい AI Infrastructure Quickstart 機能は、単一の vCenter プラグインを通じて、最初の AI インフラストラクチャの展開を自動化するよう設計されている。Quickstart は、vSphere Supervisor の有効化やインフラストラクチャのプロビジョニングを含む複数の構成タスクを、単一のワークフローにまとめる。Broadcom は、これにより AI 環境を稼働させるために必要な手作業が減ると述べた。

「私たちはそれらすべてを統合し、クイックスタートのワークフローを作り、ワークフローを完全に合理化しました」と Shenoy 氏は述べた。

VCF のマルチテナントモデル共有により、複数の事業部門が、個別のセキュリティ制御とデータプライバシーを維持しながら、一元的に展開された AI モデルにアクセスできる。Broadcom によると、事業部門ごとに別々の環境を展開するのではなく、モデルのインフラストラクチャを共有することで、組織は GPU の必要量と関連するインフラストラクチャコストを削減できる可能性がある。

同社はまた、vSAN ネイティブの S3 互換オブジェクトストレージを追加する。これは、既存のブロックサービスおよびファイルサービスと並んで統合オブジェクトストレージを提供し、AI アプリケーションやその他のワークロードをサポートする。

Broadcom は、いくつかのセキュリティ、コンプライアンス、ディザスタリカバリ機能を、VCF のコアプラットフォームに取り込んでいる。強化内容は次のとおり。

  • Site Recovery Manager: 数千のワークロードにわたるディザスタリカバリのオーケストレーションを提供し、組織が障害、ハードウェア故障、その他の中断から復旧するのを支援する。
  • 仮想プライベートクラウド（VPC）のポリシーベース接続: 管理者がワークロードの分離とセキュリティポリシーを定義・適用できるようにするとともに、開発者にネットワークリソースへのセルフサービスアクセスを提供する。
  • インフラストラクチャの構成管理とコンプライアンス: 構成の監視、ドリフトの検出、修復を自動化し、組織がセキュリティベンチマークへのコンプライアンスを維持するのを支援する。
  • コンフィデンシャルコンピューティング: サポートされる Intel および AMD のプラットフォーム全体で、使用中のデータに対するハードウェアレベルの暗号化を提供し、機密性の高いワークロードを保護する。

これとは別に、Broadcom は高度なサービスのポートフォリオを拡充している。VMware HyperArmor はプロアクティブなハイパーバイザー保護を追加し、VMware Live Recovery は安全なリカバリ環境を通じてディザスタリカバリとサイバーリカバリを提供する。VMware Compliance and Configuration Management は、仮想マシンおよびコンテナのワークロードに対する継続的なコンプライアンス監視と自動修復を提供する。

VMware vSphere Express は即時利用可能である。AI Infrastructure Quickstart、vSAN ネイティブの S3 互換オブジェクトストレージ、Site Recovery Manager の機能、ポリシーベース接続、インフラストラクチャ構成コンプライアンス管理は、Broadcom の2027会計年度第1四半期に一般提供が予定されている。VMware HyperArmor、VMware Live Recovery、VMware Compliance and Configuration Management は Broadcom の拡充された高度なサービスのポートフォリオの一部であり、HyperArmor の提供は2027会計年度第1四半期が予定されている。
