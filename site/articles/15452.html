Cisco Multicloud Fabricが限定提供を開始

Cisco Multicloud Fabric Enters Controlled Availability
Cisco Blogs2026-11-18 07:00報道

エンタープライズアプリケーションはもはや1か所には存在しない。ワークロードは複数のパブリッククラウド、プライベートデータセンター、支社拠点にまたがっている。AI は multicloud 環境への移行を加速しており、スケーラブルで、安全で、運用しやすい接続性に対する新たな要求を生み出している。

しかし、多くの組織は依然として、それぞれのパブリッククラウドを別々のツール、ポリシー、運用プロセスで管理している。この分断により、アプリケーションやワークロードがどのように通信しているかを把握すること、一貫したセキュリティを適用すること、ネットワークパス全体にわたって問題をトラブルシューティングすることが難しくなる場合がある。

Cisco Multicloud Fabric (MCF) は現在 Controlled Availability となっている。6月に Cisco Cloud Control を通じて発表された後、MCF は、オンプレミスのデータセンター、パブリッククラウド、エッジ環境にまたがって、統一された、安全で、スケーラブルなネットワーキングファブリックを提供する、マネージドの network-as-a-service 製品である。

サイトとパブリッククラウドにまたがる単一の運用モデル

Cisco Multicloud Fabric は、Cisco Cloud Control における共通の運用体験を通じて、接続性、ポリシー、可視性をもたらす。Controlled Availability により、顧客は MCF を自社の環境に導入し、AWS、Azure、Google Cloud を含むサポート対象のパブリッククラウドへの Meraki MX デバイスのオンボーディングを開始するシームレスな道筋を得られる。

内部では、MCF は、サポート対象のパブリッククラウドのリージョンとアベイラビリティゾーンにまたがる、Cisco が展開・運用する仮想ポイントオブプレゼンス (vPoP) のグローバルファブリックを使用する。これらの vPoP は、サイトからクラウドへ、およびクラウド間のトラフィックフローをサポートする。ファブリックはサービスとして利用されるため、顧客は基盤となるインフラストラクチャを自分で展開することなく、環境をまたいで接続性を拡張できる。これにより、Cisco がファブリックインフラストラクチャを運用する一方で、統一された制御と可視性のモデルを通じて multicloud 運用を簡素化するための実用的な出発点が組織に提供される。

アプリケーションパスを1か所で確認する

環境を接続することは課題の一部にすぎない。チームは、サイトとパブリッククラウドにまたがって接続性がどのように動作しているかも理解する必要がある。

Cisco Cloud Control は、オンボーディングされた環境の接続状態を確認し、サイトとパブリッククラウドにまたがるトラフィックを調査するための統一されたプラットフォームを提供する。これにより、チームは各パブリッククラウドを個別に調査することから、ネットワークパスのより連結されたビューへと進むことができる。

multicloud 接続性に組み込まれたセキュリティ

アプリケーションとデータが環境間を移動する中で、Cisco Multicloud Fabric は、組織が接続性にセキュリティを組み込んだ状態を保つことを支援する。

MCF は、接続性を明示的にするために Zero Trust ルーティングを使用する。顧客は、デフォルトで広範なネットワークアクセスに依存するのではなく、どの特定のサイトとパブリッククラウド環境が通信すべきかを定義できる。これにより、組織は、環境が変化または拡張する際に、きめ細かな制御を適用し、セキュリティに対してより慎重なアプローチを取ることができる。Security Service Chaining はこの Controlled Availability のマイルストーンには含まれておらず、将来のリリースで予定されている。

分散型ワークロードおよび AI ワークロードの基盤

AI ワークロードと最新のアプリケーションは、設計上、分散している。それらは複数のパブリッククラウドのサービスに依存したり、リージョン間を移動したり、エンタープライズの各拠点にまたがってユーザーとデータソースを接続したりすることがある。そのため、一貫したポリシー、スケーラブルな接続性、運用上の可視性がますます重要になる。

Controlled Availability のマイルストーンは、Cisco Cloud Control を通じて、サイトからクラウドへ、およびクラウド間の接続性のための、マネージドな基盤を顧客に提供する。まだ Cisco Cloud Control を利用していない顧客も、Meraki Dashboard を入口として使用できる。より広範な Cisco のルーティングポートフォリオへのサポートは、General Availability のマイルストーンでの IOS XE デバイスを含め、時間をかけて追加される。AI を活用したトラブルシューティングとクロスドメイン運用も将来のリリースで予定されており、この Controlled Availability の発表には含まれていない。

柔軟な消費モデルで拡張する

Cisco Multicloud Fabric は、従量課金制の価格設定を持つ単一のサブスクリプションとして提供される。このモデルは、顧客が追加のサイト、パブリッククラウド環境、ワークロードを接続するにつれて、柔軟なスケーリングを提供するように設計されている。

AI 時代の運用のシンプルさ

Controlled Availability のマイルストーンは、Cisco Multicloud Fabric を、発表段階から、限定的な本番環境で、より簡素な multicloud ネットワーキングのアプローチを評価・導入する準備ができた顧客向けの、発注可能なサービスへと移行させる。

この進展は、AgenticOps を原動力とする運用のシンプルさという Cisco の戦略を支えるものである。マネージドな接続性、明示的なセキュリティの意図、統一された可視性を Cisco Cloud Control を通じて一つにまとめることで、MCF は、組織が、分散型アプリケーションと AI ワークロードの進化に合わせてそれらをサポートできるネットワーク基盤を構築することを支援する。

ネットワークはもはや単なるアプリケーション間のパスではない。それは、組織が AI を拡大し、事業上重要なサービスを保護し、複数のパブリッククラウドにまたがって運用する方法の一部である。

評価を開始する

Cisco Cloud Control または Meraki Dashboard のアカウントから直接、Cisco Multicloud Fabric のトライアルを開始する。MCF が multicloud 接続性の要件をどのようにサポートできるかを知りたい場合、またはカスタムデモを依頼する場合は、Cisco のアカウントチームに連絡する。
