統合されたネットワークとセキュリティのスキルを証明する10のSASE認定資格

10 SASE certifications to validate converged network and security skills
Network World2026-11-14 07:00報道

企業がコンバージドなネットワーキングおよびセキュリティのアーキテクチャを採用するなか、これらの認定資格は、IT専門家が SASE、SD-WAN、ゼロトラストアクセス、クラウド提供型セキュリティに関する専門知識を示す助けとなる。

セキュアアクセスサービスエッジ（SASE）は、エンタープライズ組織がクラウドサービス、AIアプリケーション、ハイブリッドワーク環境の利用を拡大するにつれ、企業のネットワーキングおよびセキュリティ戦略においてますます重要な要素になりつつある。クラウド提供型の SASE は、ネットワーキング機能とセキュリティ機能を統合し、エンドユーザーやリソースがどこにあってもアプリケーションとデータへの安全なアクセスを提供する。

SASE は、ソフトウェア定義WAN（SD-WAN）を、セキュリティウェブゲートウェイ（SWG）、クラウドアクセスセキュリティブローカー（CASB）、ゼロトラストネットワークアクセス（ZTNA）、サービスとしてのファイアウォール（FWaaS）などのセキュリティ機能と組み合わせたものである。組織がこれらの技術を採用するにつれ、ネットワークおよびセキュリティの専門家には、従来のネットワーキング、クラウドセキュリティ、ID ベースのアクセス、ポリシー管理にまたがる専門知識が必要になる。

Dell’Oro Group によると、世界の SASE 売上は2026年第2四半期に35億ドルに達し、前年同期比で20%を超える成長が5四半期連続となった。同調査会社は、市場が2030年までに年間売上240億ドルに達し、2025年の水準の2倍以上になると予測している。

SASE の採用拡大は、コンバージドなネットワーキングおよびセキュリティ環境を設計、導入、管理、トラブルシューティングできる IT 専門家への需要も生み出している。ベンダーの認定資格やアクレディテーションは、ネットワークエンジニア、セキュリティスペシャリスト、ITアーキテクトが自らの知識を検証し、特定の SASE プラットフォームや技術に対する習熟度を示す一つの手段となる。

2026年、Fortinet は Network Security Expert（NSE）プログラムを再編し、SASE に焦点を当てた新しい認定トラックを導入した。一方 Cisco は、変化するクラウドセキュリティ要件を反映するため、CCNP Security 認定プログラムを更新した。他のベンダーも、SD-WAN、セキュアサービスエッジ（SSE）、ゼロトラストアーキテクチャに焦点を当てた資格を提供している。

ここでは、Cato Networks、Cisco、Fortinet、Netskope、Palo Alto Networks、Versa Networks、Zscaler による、IT 専門家がコンバージドなネットワーキングとセキュリティのスキルを開発・検証するのに役立つ、SASE 関連の10の認定資格とアクレディテーションを（アルファベット順に）紹介する。

Cato Networks: SASE Expert Level 1 Certification

  • 概要： Cato SASE Expert Level 1 Certification のこの入門コースは、SASE の推進要因、価値、アーキテクチャ、ユースケース、SASE の主要なネットワーク機能およびセキュリティ機能を含む、SASE フレームワークの基本的な理解を検証する。また、組織が SASE の採用へ向かうのを支援するために必要な知識も提供する。
  • 対象となる専門家： この認定資格は、IT 専門家、ネットワーク管理者、セキュリティアーキテクトに適している。
  • 主なスキル： 認定された individuals は、Cato Management Application（CMA）への習熟度を示し、Cato SASE Cloud を運用、設定、トラブルシューティングするための技術的専門知識を備えている。この認定資格は、クラウドネイティブなアーキテクチャにおけるコンバージドなネットワーク機能およびセキュリティ機能を含む、SASE の基本事項を扱う。
  • 試験の詳細： 受験者は1時間未満の監督なしのクイズを受け、認定されるには85%以上を獲得しなければならない。
  • 費用： 自己ペースの SASE コースと試験は無料である。
  • 前提条件： 受験者にはクラウド、ネットワーキング、セキュリティの経験があることが望ましい。Cato は、受験者が試験の準備としてオンライン動画を視聴し、SASE の資料を読むことを推奨している。
  • 注記： Cato Networks は複数のレベルの SASE 認定資格を提供している。

Cisco: Certified Network Professional (CCNP) Security

  • 概要： SASE に特化したものではないが、Cisco CCNP Security 認定資格は、ネットワーク、クラウド、コンテンツのセキュリティ、エンドポイントの保護と検知、セキュアなネットワークアクセス、可視性、強制を含む、セキュリティインフラストラクチャにおけるスキルを証明する。Cisco は2026年8月27日に CCNP Security 認定プログラムをバージョン2.0に更新し、AI 駆動のセキュリティ運用、クラウドネイティブなフレームワーク、高度な自動化を重視するようカリキュラムを刷新した。
  • 対象となる専門家： Cisco のセキュリティ製品を扱う、3～5年の IT 経験を持つ IT 専門家。これはネットワークおよびセキュリティエンジニア向けのプロフェッショナルレベルの認定資格である。
  • 主なスキル： 認定資格保持者は、脅威と脆弱性の特定、中核となるセキュリティ技術の実装、企業ネットワークの保護、ユーザーとアプリケーションの保護に関する知識を示す。Designing and Implementing Secure Cloud Access for Users and Endpoints コンセントレーションは、クラウドセキュリティアーキテクチャ、ユーザーとデバイスのセキュリティ、アプリケーションとデータのセキュリティ、脅威への対応を扱う。
  • 試験の詳細： 受験者は、350-701 SCOR（Implementing and Operating Cisco Security Core Technologies）コア試験と、300-740 SSCA 試験などのコンセントレーション試験1つに合格しなければならない。SCOR v2.0 試験は120分、300-740 SSCA コンセントレーション試験は90分である。Cisco は具体的な合格点の基準を公表していない。試験は動的なスケールで採点され、受験者は、ブループリントの分野ごとの成績のパーセンテージ内訳を添えた合否結果をすぐに受け取る。
  • 費用： コア試験は400ドル、コンセントレーション試験は300ドルで、合計700ドルである。
  • 前提条件： 正式な前提条件はないが、Cisco はこのプロフェッショナルレベルの認定資格について3～5年の経験を推奨している。
  • 注記： Cisco の認定資格の有効期間は3年間である。コンセントレーション試験に合格した受験者は、対応する Cisco Certified Specialist 認定も取得する。

Cisco: Certified Specialist—Secure Cloud Access

  • 概要： Cisco の Certified Specialist—Secure Cloud Access 認定資格は、クラウドアプリケーションとリソースへのセキュアなアクセスを設計・実装する専門知識を検証する。この資格は、クラウド提供型セキュリティや SASE アーキテクチャを扱う IT 専門家に特に関連が深い。
  • 対象となる専門家： クラウドセキュリティエンジニア、ネットワークセキュリティ管理者、セキュリティアーキテクト、およびクラウドリソースへのユーザーとエンドポイントのアクセスの保護を担う IT 専門家。
  • 主なスキル： この認定資格は、クラウドセキュリティアーキテクチャ、ユーザーとデバイスのセキュリティ、ネットワークとクラウドのセキュリティ、アプリケーションとデータのセキュリティ、可視性と保証、脅威への対応を扱う。
  • 試験の詳細： 受験者は 300-740 Designing and Implementing Secure Cloud Access for Users and Endpoints（SSCA）試験に合格しなければならない。試験時間は90分で、英語で提供されている。
  • 費用： 300ドル
  • 前提条件： 正式な前提条件はない。ネットワーキング、クラウドセキュリティ、ID 管理、セキュアアクセス技術に精通していることが推奨される。
  • 注記： 300-740 試験に合格すると、スペシャリスト認定を取得でき、CCNP Security のコンセントレーション試験の要件も満たす。この資格は、CCNP Security の完全な認定を必要としない専門家に、より焦点を絞った認定への道筋を提供する。

Fortinet: Network Security Expert (NSE) SASE Certifications

  • 概要： Fortinet の NSE SASE 認定資格は、Fortinet の SASE ソリューションの導入、管理、監視、トラブルシューティングのスキルを検証する。2026年7月、Fortinet は従来の FCSS SASE 認定資格を廃止し、NSE 5、NSE 6、NSE 7 の3つの SASE 認定レベルを含む改訂版 NSE プログラムを導入した。
  • 対象となる専門家： Fortinet の SASE 展開の実装と管理を担う、ネットワークセキュリティ管理者、サイバーセキュリティエンジニア、SASE スペシャリスト、セキュリティアーキテクト。
