Logicalis、Ciscoのセキュアネットワーキング専門認定を取得

Logicalis、Cisco Secure Networking Specialisation を取得

2026年11月5日（木）（昨日）
Logicalis は Cisco の Secure Networking Specialisation を取得し、主要な事業地域の5か国でこの認定を保持する初の Cisco グローバルパートナーとなった。

この Specialisation は、Logicalis の米国、ドイツ、ブラジル、中国、インドネシアの事業に付与された。同社は、認証を国際事業のより多くの部分に拡大することで、6か月以内にその範囲を倍にする計画である。

この認定は、ネットワーキング、セキュリティ、マネージドサービスにおける専門性を認めるものである。また、接続性とセキュリティを組み合わせた安全な環境の設計、導入、管理における Logicalis の取り組みを裏付けるものでもある。

同社は、この動きによりグローバルなマネージドサービスの提供が強化されると同時に、顧客が現地市場の要件に合わせた支援を受けられるようになると述べた。これらのサービスは、各主要地域のネットワークオペレーションセンターおよびセキュリティオペレーションセンターを通じて提供される。

マネージドサービス

この進展は、より多くの業務上重要なトラフィック、より多くの接続デバイス、より分散したワークロードを背景に、企業がネットワークに対してより高い要求を課すなかで起きている。同時に、セキュリティチームは、より広範で複雑な環境全体にわたって可視性とポリシー制御を改善するよう圧力を受けている。

Logicalis と Cisco は、その変化に対応するため、セキュアネットワーキングのマネージドサービスを適応させていると述べた。これらのサービスは Cisco Cloud Control 上に構築されており、利用可能な場合は Cisco IQ と Cisco Data Fabric によって強化されている。

両社によれば、これらのサービスは、インフラストラクチャの近代化、レジリエンス、リスク管理を支援しながら、顧客に自らの環境へのより高い可視性を提供するよう設計されている。また、顧客が自社の技術資産を人工知能のより多くの活用に備えられるよう支援する、より広範な取り組みの一部でもある。

Logicalis のグローバルアライアンス担当VPであるAnita Swannは、この節目を、同社と Cisco との長年にわたる関係の反映であると述べた。

「この Specialisation は、Cisco との長年にわたる関係の強さと、お客様が必要とするスキル、プラットフォーム、サービスに対して当社が継続している投資を反映しています。ネットワーキングとセキュリティを変革的なマネージドサービスモデルの中で統合することで、組織が複雑さを減らし、レジリエンスを強化し、AI に必要な安全な基盤を構築できるよう支援できます」と、Logicalis のグローバルアライアンス担当VPであるAnita Swannは述べた。

Cisco との関係

この発表は、Cisco のチャネル戦略におけるパートナー認定の重要性も浮き彫りにしている。Logicalis にとって、この認定は、大規模で複雑なネットワーク資産全体に一貫したセキュリティ制御を適用する能力に対する第三者による裏付けとなる。

Cisco は、この成果は当初から5か国にまたがり、国際規模でのマネージドサービス提供と結びついている点で際立っていると述べた。この組み合わせは、異なる市場にわたって共通の運用基準を求める多国籍の顧客にとって重要である。

Cisco のGlobal Partner Program GTM担当SVPであるElisabeth De Dobbeleerは、この成果はパートナーシップの深さを反映していると述べた。

「Cisco のパートナーエコシステムは、お客様が技術革新を測定可能な成果へと転換するうえで中心的な存在です。Logicalis が5か国で Cisco の Secure Networking Specialisation を取得できたこと、そして大規模にマネージドサービスを提供する能力とを合わせて、最も優れたパートナーを特徴づける専門性、革新性、顧客重視の姿勢を示しています。彼らのグローバルな能力と現地の専門知識の組み合わせは、お客様がインフラストラクチャを近代化し、運用を簡素化し、AI 時代に向けて安全に備えることを支援します」と、Cisco のGlobal Partner Program GTM担当SVPであるElisabeth De Dobbeleerは述べた。

認証そのものに加えて、両社は、顧客が既存の環境を評価し、近代化の優先順位を設定し、より自動化されポリシー駆動型の運用へと移行できるよう、協力していると述べた。そのプロセスでは、可視性、ライフサイクル管理、運用の一貫性を改善するために Cisco IQ と Cloud Control が使用される。

より広範な変化

今回の Specialisation は、Logicalis の事業が従来のインフラストラクチャ管理から、継続的な運用改善に焦点を当てたマネージドサービスへと移行しているという、より広範な変化も反映している。実際には、これは顧客が既存のシステムを更新し、日々の運用を簡素化し、より明確な情報に基づいて技術投資の意思決定を行えるよう支援することを意味する。

セキュアネットワーキングは、ネットワーク管理、セキュリティ、自動化、運用監督を単一のサービスモデルにまとめるため、その提案の中心的な要素となっている。断片化した技術資産を抱える顧客にとって、これは、すべての現地市場で同じアプローチを必要とせずに標準化へ至る道筋を提供する。

Logicalis は、5か国での認証により、顧客はグローバルな提供モデルを通じて検証済みの Cisco の専門性を利用でき、同時にサポートを現地の要件に沿わせ続けることができると述べた。
