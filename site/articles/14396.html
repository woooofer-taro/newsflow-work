Cisco、パートナーに「高利益率」のレジリエントなインフラサービスを主導するよう促す

Cisco Pushes Partners To Lead With ‘High- Margin’ Resilient Infrastructure Services
CRN2026-11-05 13:00報道

Cisco、パートナーに「高利益率」のレジリエントなインフラストラクチャサービスを前面に出すよう促す

*Cisco のパートナーへのメッセージは、レジリエンスを売ることだ。このテックジャイアントは、パートナーがリスクを見つけ、顧客環境を近代化できるよう、この推進を新しい Cloud Control AgenticOps 機能、Model Foundry、量子耐性を備えた Wi-Fi 7 アクセスポイント、そしてより幅広い Live Protect のサポートと組み合わせている。*

Cisco Systems は、パートナーにレジリエントなインフラストラクチャサービスを前面に出してほしいと考えており、同社は Cisco IQ と Cloud Control を、顧客環境内のリスクや旧式の機器を特定し、これらの企業の近代化を支援する AI 搭載ツールとして売り込んでいる。

Cisco のエグゼクティブバイスプレジデント兼最高カスタマーエクスペリエンス責任者である Liz Centoni によると、パートナーにとっては三段階の施策となる。リスクを明らかにし、運用を近代化し、通知するだけでなく行動する AI エージェントを展開することだ。

「ところで、これはあなた方のプロフェッショナルサービスであり、高価値、高利益率です。そして Mythos 後の世界では、お客様は待つ余裕がありません。しかし、ここであなた方のビジネスに本当の転換が起こります。なぜなら、そのお客様がリスクを特定して是正する手助けをしたなら、お客様の環境の近代化というより大きな話をする資格を得たことになるからです」と、Centoni は先週開催された Cisco Partner Summit 2026 の壇上でパートナーに語った。

この目的のため、同社は Cisco Cloud Control 向けの新しい AgenticOps 機能をいくつか発表した。Cloud Control は、ネットワーキング、セキュリティ、コラボレーション、オブザーバビリティの各ポートフォリオにまたがる、エージェント型 AI のための同社の統合プラットフォームである。カリフォルニア州サンノゼに本社を置く同社によると、新機能はより多くのタスクを自動化し、チームがより迅速に連携して作業できるよう支援する。

[関連記事：Cisco CEO Chuck Robbins：「アーキテクチャ全体を代表できるパートナー」が際立つ]

Model Foundry は Cloud Control 内の新サービスで、パートナーや企業が Cisco の AI モデルを試せるようにする。Cisco によると、ユーザーはモデルの評価、ファインチューニング、自社データでの実行を、すべて一か所で行える。Model Foundry は Cisco の最新モデルバージョンの専用の提供場所である。

Cisco は現在、Model Foundry を限定提供で、パートナーから順に展開している。

Cisco はまた、対象となる Networking Essentials および Advantage ライセンスを持つ顧客向けに、追加費用なしで ThousandEyes を Wi-Fi 6E および 7 アクセスポイントにネイティブに組み込んでいる。これにより、企業はアプリとネットワークのパフォーマンスの24時間体制の自動テストを利用できるようになる。同社はまた、ネットワーキングプラットフォーム向けの Model Context Protocol サーバーも導入しており、AI ツールがライブのネットワークデータにアクセスするための標準的な方法を提供する。これは、パートナーがカスタム接続を構築する必要がなくなり、自動化されたトラブルシューティングやレポートのワークフローを作成しやすくなることを意味する。

量子の面では、Cisco は量子耐性を備えた Wi-Fi 7 アクセスポイントを発表する。このデバイスは、無線通信における Post Quantum Cryptography による量子安全な通信のために Qualcomm と共同で構築されており、Intel の Wi-Fi チップセットと、Windows ソフトウェア向けの Microsoft が組み合わされている。同社によると、このアクセスポイントは、ワイヤレス、スイッチング、ルーティングにまたがる Cisco の量子耐性ネットワーキングポートフォリオの最新の追加製品であり、パートナーが量子対応の評価を提供するのに役立つ。

同社はまた、脆弱性の開示とパッチ適用の間のギャップを狭める Live Protect を、N9000 および N9300 スイッチ、Catalyst SD-WAN、C9000 スイッチ、CW9800 ワイヤレスコントローラーに拡大しており、Cisco 8000 Secure Routers とファイアウォールへのサポートは2026年末までに予定されている。さらに Cisco は、Teleport との Privileged Infrastructure Access を開発しており、ネットワークチームと AI エージェントに、ルーターとスイッチへの管理された短期間のアクセスを提供すると同社は述べた。

「私たちのビジネス、特にエネルギー分野では、お客様ができるだけ速くパッチやアップグレードを行う余裕がないというのは事実です。発生している悪意ある活動により、脅威アクターは今やとても素早く行動しています」と、テキサス州ヒューストンを拠点とする MSP で Cisco パートナーである Alykas の社長兼 CEO、Faisal Bhutto は述べた。

Bhutto によると、特に Cisco が提供する Cloud Control や Live Protect といったツールを備えたレジリエントなインフラストラクチャは、ソリューションプロバイダーが、コストのかかるリップアンドリプレースのアップグレードを行うことなく、顧客への影響を軽減するのに役立つ。

「外に出て『よし、新しいパッチを適用しなければならないから、工場全体を停止する』と言うことはできません。しかし、そこで私たちのレジリエントなインフラストラクチャから Live Protect のようなものが登場するのです」と彼は述べた。

Bhutto によると、多くの顧客はすでにレジリエンスをインフラストラクチャに組み込むべく取り組んできた。

「問題は、Cisco が役割を果たせるのですから、Cisco パートナーである私たちが今、どのようにクライアントを支援できるかということです」と彼は付け加えた。

レジリエントなインフラストラクチャ：Cisco の売り込み、MSP の要望リスト

Cisco の社長兼最高製品責任者である Jeetu Patel によると、パートナーにとって最大の機会は、顧客のインフラストラクチャがスケーラブルで、信頼性が高く、頼りになるものであるようにすることにある。それはビジネスの強さに「正比例する」からだ。

「私たちがやりたいのは、それを実現するためのあらゆる仕組みを提供することです。もし障害が発生するなら、発生する前に予測できるか。障害の調査と検知にかかる時間を短縮し、対応と是正を可能な限り迅速に行えるようにできるか。もし侵害であるなら、横方向の移動がないよう、その侵害を先回りして阻止できるか。組織にとって、セキュリティ侵害と、エージェントが指示を非常に文字どおりに受け取ってそれに従おうとした結果、それが正しいことだと思って単に不適切に振る舞っているだけの場合とを区別することは、ますます難しくなっていくでしょう。」

Patel によると、Cisco はパートナーと顧客のために、セキュリティとオブザーバビリティのテレメトリを別々に扱うのではなく組み合わせており、顧客は、侵害でない場合であっても、AI エージェントが不審な動きをしていることを見つけられる。Cisco IQ と Cloud Control は、パートナーがその可視性を使ってレジリエントなインフラストラクチャを構築する方法である。Cisco IQ と Cloud Control は、レジリエントなインフラストラクチャを構築するパートナーにとっての入り口である。Cisco IQ は顧客が環境内に何を持っているか、何が旧式かを明らかにでき、Cloud Control はそのテレメトリを単一のビューにまとめるからだ。

「私の考え方はとてもシンプルです……私たちはただ、お客様が、自社の資産内に何があるか、その資産内でパッチ適用がどのように行われているか、そして何をアップグレードする必要があるかを理解できるよう、テレメトリとデータを持っていることを確実にしたいのです。そして、Cloud Control と Cisco IQ の組み合わせが、必要とされる完全な可視性をお客様に提供します」と彼は述べた。

Cisco のレジリエントなインフラストラクチャに関するメッセージは重要である一方、それを再現可能なプラクティスにするためにパートナーが同社に求めるものがまだいくつかあると、アルバータ州カルガリーを拠点とする Cisco パートナー Long View Systems の戦略アライアンス担当ディレクター、Lane Irvine は述べた。

Cisco のマルチテナント MSP ツールはまだ整っていないと彼は付け加えた。

「ランブックが必要です。マルチテナンシー［オプション］を可能にする具体的なツールが必要です。マネージドサービスプロバイダーとして、ボタンをクリックすれば、その特定のバージョンを使っているすべての環境がアップグレードされるようにできるべきです。そしてダウンタイムはありません」と Irvine は述べた。

Irvine によると、自動化を備えたレジリエントなインフラストラクチャは、顧客を Cisco にも MSP にも、より定着させる。

「それは、顧客が Cisco にとどまる上で大きな利点であり、顧客がマネージドサービスを利用する上でも大きな利点で、粘着性のあるつながりを生み出します。マネージドサービスを利用しているお客様は、ベンダーを乗り換えようとは考えないものです」と彼は述べた。
