OpenAIとCisco、パッチ適用前にLinuxのエクスプロイトを阻止するShirudoを発表

OpenAI and Cisco launch Shirudo to block Linux exploits before patches
Mezha.net2026-11-27 07:00報道

OpenAI と Cisco、パッチ適用前に Linux のエクスプロイトをブロックする Shirudo を公開

*写真提供: BleepingComputer*

*研究者らは、カスタムの Shirudo シールドが、稼働中の Elasticsearch サービスに対する Java4Shell エクスプロイトの試行を、サービスを中断させることなくブロックしたと述べている。*

OpenAI と Cisco は、管理者がパッチを準備して展開する間、一時的なランタイム保護を展開するオープンソースの Linux セキュリティツール、Shirudo を公開した。サービスを再起動することなく、脆弱性のエクスプロイトをブロックするように設計されている。

これは BleepingComputer が報じた。

Shirudo は Linux の eBPF（extended Berkeley Packet Filter）を使用して不審なアクティビティを監視し、「シールド」と呼ばれる的を絞った保護を適用する。eBPF により、プログラムはオペレーティングシステムのカーネル内の制御された環境で、そのソースコードを変更したり再起動を必要としたりすることなく実行できる。また、システムおよびネットワークのアクティビティをリアルタイムで監視し、パフォーマンスを分析し、セキュリティ保護を適用することもできる。

OpenAI と Cisco の研究者らは、カスタム生成したシールドをテストし、稼働中の Elasticsearch サービスに対する Java4Shell エクスプロイトの試行を、中断させることなくブロックしたと述べた。シールドは、正当なアプリケーションの動作を妨げずに悪意ある動作を止めることを意図している。

マネージド検知・対応企業 Expel の主任脅威研究者である Marcus Hutchins 氏は、「eBPF にはランタイムのエクスプロイト緩和の可能性が本当にたくさんある」と述べる一方、カーネルに影響し得るルールを AI エージェントに書かせることには注意を促した。また、このツールの「機能は Linux に限定される。Mac/Windows では、効果を発揮するために必要なコンポーネントが実装されていないためだ」とも述べた。

Cisco が 2024 年に買収したクラウドネットワーキング・セキュリティ企業 Isovalent の研究者らは、Shirudo を、Isovalent が 2022 年に発表したオープンソースの eBPF ベースのランタイムセキュリティプラットフォーム Tetragon の書き直しであると説明している。Tetragon は Cisco の Live Protect 技術の基盤でもある。

Shirudo は、緩和策を展開する際の自律性を設定可能なエージェント型コントロールプレーン向けに設計されている。Isovalent によると、アプリケーションまたはユーザー空間のランタイムバイトコードを変更して、eBPF を超えた保護へ拡張することもできる。展開されたシールドは、エクスプロイトの試行と防御の強化が必要になり得る箇所を示すヒットカウントをオペレーターに提供する。

OpenAI と Cisco は、パッチが利用可能になるまでの間、脆弱性の開示と併せて、テスト済みの「すぐに使える」シールドを提供する計画である。シールドは、暗号署名された「.bee」パッケージとして OCI レジストリ経由で配布される。Isovalent によると、Shirudo はコマンドラインインターフェースから有効化でき、マシン上でデーモンを常時稼働させる必要はない。

Isovalent は、Shirudo はエージェントがコードを生成できるようにするための、エージェントとマシンインターフェースを組み合わせる取り組みの「始まりにすぎない」と説明している。このプロジェクトは BSD および GPL ライセンスの下でオープンソースであり、クイックスタートガイドと Isovalent の「getting started」ドキュメントが含まれている。

OpenAI は、Shirudo がどのように動作し、eBPF と人工知能を組み合わせて新たな攻撃を検知・対処するのかを、12月15日の技術ウェビナーで説明する予定である。
