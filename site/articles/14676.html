F5とOracle、OCI顧客向けのWAAP統合を計画

F5はOracleと提携し、Oracle Cloud Infrastructureでホストされるアプリケーションのセキュリティを強化する。この協業を通じて、F5の著名なアプリケーションセキュリティ技術がOCIに組み込まれ、サイバー脅威に対する強固な防御を提供する。この取り組みでは、アプリケーションとAPIの保護を優先しつつ、セキュリティ運用を簡素化する。主な機能にはAIランタイム防御と仮想パッチ適用が含まれる予定だが、展開の時期は明らかにされていない。

F5とOracleは、Oracle Cloud Infrastructure（OCI）上でアプリケーションを運用する顧客に、Webアプリケーションおよび API 保護（WAAP）機能を提供するための協業計画を発表した。

拘束力のない覚書（MoU）に基づき、両社はF5のアプリケーションセキュリティ技術をOCIに統合し、組織がアプリケーションとAPIをサイバー脅威から保護できるよう支援する計画である。

アプリケーションとAPIの保護：組織が高度な攻撃から重要なアプリケーションとAPIを保護できるよう、セキュリティ機能を提供する。

セキュリティ運用：チームが既存のクラウド環境内でアプリケーションとAPIの保護を管理できるようにし、運用の複雑さと専門的なセキュリティ知識への依存を減らすことを目指す。

両社は、計画されている統合の時期を発表していない。
