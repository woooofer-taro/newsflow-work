Ciscoの Centoni 氏：Cisco IQ は「一度きり」の取引を継続的なパートナー事業に変える

Cisco’s Centoni: Cisco IQ Will Turn ‘One-And-Done’ Deals Into Recurring Partner Business
CRN2026-10-30 07:00報道

Cisco の Centoni 氏：Cisco IQ は「売り切り」の取引をパートナーの継続的なビジネスに変える

*Cisco IQ は、同社とそのパートナーによると、パートナーが差別化されたマネージドサービスを構築し、初回販売を超えた収益機会を生み出す支援を目的として、新しいホワイトラベルのオプションと AI およびリスクインテリジェンス機能を備えてパートナー向けに拡張された。*

Cisco Systems は、現在一般提供となっている Cisco IQ for Partners を、ソリューションプロバイダーが顧客のリスクの特定、更新機会の発見、サポート契約の販売、マネージドサービスの構築、継続的な収益の創出に使えるプラットフォームとして位置づけていると、この大手テクノロジー企業が月曜日に明らかにした。

Cisco は現在、パートナーが自社ブランドの下で Cisco IQ をホワイトラベル化して継続的なサービス収益を大幅に伸ばせるようにすることで、Cisco IQ をパートナーの手に直接渡そうとしていると、同社はカナダのバンクーバーで開催された Partner Summit 2026 で発表した。

「Cisco IQ によって、私たちは売り切りの取引というアプローチを、パートナーにとっての継続的なビジネスへと変えようとしています」と、同社のエグゼクティブ バイスプレジデント兼最高カスタマーエクスペリエンス責任者である Liz Centoni 氏は CRN に語った。

［関連：Cisco はエンタープライズ AI の「スイス」になりたい］

Cisco IQ をパートナーに拡張することで、同社はソリューションプロバイダーがマネージドサービスを構築し、初回販売後の新たな機会を追求できるよう支援することを目指している。同社は、顧客のリスクや近代化のニーズへの直接的な洞察を提供する API とロールベースのアクセスを通じてこれを行っている。

Cisco の主要なサポートポートフォリオには Basic、Standard、Signature の3つの階層があり、Cisco IQ を通じてデジタルで提供される。Cisco の Basic サービス階層が可視性、つまり「地図」を提供するのに対し、Standard 階層と Signature 階層は、顧客がリスクをより効果的に特定し対処できるよう、AI を活用したアクション、脆弱性の優先順位付け、プロアクティブなリスクインテリジェンスを加えるもので、これが「GPS」であると Centoni 氏は付け加えた。

Centoni 氏は、Standard と Signature のサービス階層が提供する可視性は、パートナーが顧客環境内の弱点を発見するのに役立ち、利益率の高い是正サービスを提供する機会を生み出すと述べた。

「パートナーは今や、Cisco が IQ で見ているのと同じ深い洞察を使って、自社のマネージドサービスを構築できます」と同氏は語った。

パートナーはより深い洞察とマネージドサービスのために Cisco IQ に注目

Cisco IQ をパートナーに拡張することで、取引成立後の新たな機会への扉が開かれる。そしてそれは意図されたものである。Cisco は、パートナーが単にハードウェアを販売するのではなく、Cisco IQ を使ってサービス主導の取り組みを推進することを望んでいると、Cisco のチャネル責任者 Tim Coogan 氏は述べた。

「Cisco IQ は、パートナーの道具袋の中で非常に強力なツールになるでしょう」と Coogan 氏は語った。「［製品としてではなく、］パートナーが新たなサービス収益、新たな機能、そして顧客にとって異なる種類の購買・利用体験を提供するために使えるプラットフォームとして考えてください」

Cisco IQ が一般提供となってからの6か月間で、中小企業から最大手のハイパースケーラーまで、世界中で約16,000の顧客がこのプラットフォームを利用していると、Cisco のカスタマーエクスペリエンス プロダクトマネジメント担当シニア バイスプレジデント Vikas Butaney 氏は述べた。

「パートナーは私たちの戦略の中心です。私たちは IQ のこれらすべての洞察と機能をパートナーの手元に置くつもりです」と同氏は語った。

Cisco は Cisco IQ を AI 主導のサービス戦略の重要な柱として位置づけている一方、パートナーは、継続的な収益の創出に役立つ、より深い顧客インサイトとマネージドサービス機能をこのプラットフォームが提供することを求めている。

Cisco IQ は、パートナーに顧客環境へのより優れた可視性と、より強力なセキュリティインテリジェンス、およびマネージドサービスへのサポートを提供し得ると、アルバータ州カルガリーに拠点を置き、長年の Cisco パートナーである Long View Systems の戦略アライアンス担当ディレクター Lane Irvine 氏は述べた。

「IQ に関する重要なニュースは、［次の点にあります］。顧客に対して、どのようにしてより良い洞察を得るのか。どのようにしてより多くのセキュリティ情報とセキュリティ上の洞察を提供するのか。……そして、マネージドサービスパートナーにとって大きな要素であるマルチテナンシーです」と Irvine 氏は語った。

Cisco IQ と、ネットワーキング、セキュリティ、コラボレーション、オブザーバビリティのポートフォリオにまたがるエージェンティック AI 向けの同社の統合プラットフォームである Cloud Control は、密接に連携していくことになると同氏は付け加えた。

Cisco は月曜日、顧客とパートナー向けに、Cisco Cloud Control とのスムーズな統合を含む、いくつかの新しい Cisco IQ 機能を発表した。ほかの機能には、通常のパッチ適用、優先度の高いバグ、ソフトウェア適合性評価を超えたリスクの特定に役立つ、AI を活用した量子安全およびソフトウェアのサポート終了に伴う脆弱性のプレイブック、そして、コンテキストに基づくリアルタイムのデータと Cisco Technical Assistance Center のナレッジを活用したトラブルシューティングを備えた Cisco IQ AI Assistant の機能強化が含まれると、同社は述べている。

Cisco IQ のパートナーコミュニティへの拡張は、すでにこのプラットフォームが顧客の AI ニーズに対応していると見ているソリューションプロバイダーにとって恩恵であると、カリフォルニア州アーバインに拠点を置く Cisco パートナー Trace3 のパートナービジネス開発担当シニア バイスプレジデント Mark Graham 氏は述べた。

「Cisco が Cisco IQ で示したバリュープロポジションは、私たちの顧客にとって本物です。特にあらゆるフロンティア AI が進行している今日の環境にとって本物です。パートナーコミュニティはこれをうまく採用すると思います」と同氏は語った。
