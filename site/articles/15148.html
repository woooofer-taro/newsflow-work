HN851: Inside the Certified Kubernetes Network Engineer (CKNE) Program
Packet Pushers2026-11-14 07:00報道

本日、DrewとEthanは、Nico Vibertを迎えて、新しくできたCertified Kubernetes Network Engineerプログラムを取り上げる。Nicoはこの認定の作成に協力しており、O'Reillyから2027年に刊行予定のこのプログラムの学習ガイドを執筆している。彼らは、CKNEが何を扱うのか、誰が受験すべきか、どのように準備するか、そしてクラウドネイティブネットワーキングにおけるキャリアをどう前進させられるかについて話し合う。
