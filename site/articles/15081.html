エージェンティックAI時代に、素早く動きながら制御を保つ

AIは、頼まれるのを待つことをやめた。エージェントは今や24時間体制で、自律的に動いている。そのため、問いは「どれだけ速く進めるか」から「AIが私たちより速く動くとき、どのように制御を保つか」へと変わった。

ブレーキを踏んでも答えにはならず、うまくいくことを願うだけでも答えにはならない。しかし、AIに仕事を任せることは、制御を手放すことを意味する必要はない。

これはどの市場のリーダーも直面する緊張関係であり、Ciscoが Cisco Live Melbourne で発表した新しいレポートにもはっきりと表れている。この調査のためにインタビューした25人のオーストラリアのリーダーの1人で、AustralianSuper の Head of AI である Sarah Carney は次のように語った。「信頼を築いていなければ、予測した成果や利益は得られません。人々がそのシステムを使わなくなるからです。」彼女の指摘はオーストラリアにとどまらず広く当てはまる。能力は企業が何を自動化*できるか*を決め、信頼は企業が何を自動化*するか*を決める。

企業は、スピードを落とさずにどのように信頼を獲得するのか。

インフラが、制御を失わずに速く動ける者を決める

答えは、Cisco が40年以上にわたって土台としてきた考え方から始まる。ネットワークはノードよりも強力である、という考え方だ。モデル、アプリ、エージェントはいずれも重要だが、真の魔法はそれらの間のつながりにある。私が6月にラスベガスでそう主張したとき、世界はちょうど Claude Mythos と出会ったばかりだった。これは世界の防御にとって不可欠になりつつあり、悪意ある者の手に渡れば、その防御を破るほど強力になり得る種類のAIである。それ以来ペースは上がる一方であり、インフラはさらに重要になっている。

しかし、私が楽観的である理由はここにある。エージェントが行動するたびに、接続が生まれ、セキュリティ境界を越え、データの痕跡が残る。そして、ネットワーク、セキュリティ、可視性が一体として機能すれば、企業はすべてのエージェントが何をしているか、何がリスクにさらされているかを見ることができる。エージェントを操縦し、重要なときに介入することが、AIと同じ速度で可能になる。

スピードと制御は、企業が新しいサービス、新しい働き方、新しいビジネスモデルを築くのと同じ場所、すなわちインフラから生まれる。制御は、事業の運営方法の一部になる。

今週の私たちのニュースは、リーダーがAIに重要な仕事を任せる前に必ず尋ねる2つの問いに答えるものだ。誰かが侵入を試みたらどうなるのか、そしてコストを管理下に置けるのか、という問いである。

「誰かが侵入しようとしたらどうなるのか」

*弱点を先に見つけ、より速く修正する*

ネットワークを守る人々に尋ねれば、従来のやり方はもう終わったと言うだろう。2018年には、攻撃者がセキュリティ上の欠陥を悪用するまでに平均63日かかっていた。今では、修正が公開される前に攻撃するのが一般的だ。それに対応できるだけの速さを持つ企業はほとんどない。防御側には2つの仕事がある。自社のAIを含め、弱点を先に見つけること、そして攻撃者が到達する前にそれを修正することだ。

弱点をテストするのはレッドチーミングの仕事である。難点は、テストの質は、それが模擬する攻撃の質を超えないということだ。

Cisco AI Defense は Anthropic の Claude Mythos を追加し、そのレッドチーミングフレームワークに組み込む。これにより、そうでなければ見逃されてしまうような巧妙で多段階の攻撃を計画する推論能力がもたらされる。しかし、それほど強力なツールには明確な境界が必要だ。Claude Mythos を使う場合、AI Defense は顧客が所有し、登録し、承認したシステムのみをテストし、すべてのテストは特定の個人に紐づけられていつでも停止でき、顧客が自由にプロンプトを与えることはできない。

新たなレベルの推論が、Cisco AI Defense を使う防御側のために働き始めようとしており、一部の顧客向けに近く提供される。

迅速な修正で登場するのが Cisco IQ だ。すでに16,000社を超える顧客がこれを利用して約2,000万台のデバイスを監視しており、どのネットワーク機器が脆弱で、どのように設定され、耐用期間のどの段階にあるかを把握できる。今回、Splunk Platform を搭載した Cisco Data Fabric がその情報を直接取り込み、セキュリティチームとAIエージェントは、Splunk Enterprise Security 上の実際の脅威を、リスクのあるデバイスと突き合わせられるようになる。

その後、システム間でデータをコピーすることなく、修正が動き出す。対応するAIエージェントおよび ServiceNow 向けのコネクタはネットワークの同じ全体像を共有し、各検出結果を、影響を受ける機器にリンクされた ServiceNow の問題レコードに変える。AIを活用したレジリエントなインフラのプレイブックは、既知の不具合に関するパーソナライズされたアラートから、暗号化が量子コンピューティングに対応できているかまで、その機器のライフサイクル全体にわたる重大なリスクを示す。これにより、チームと認定パートナーは何から先に近代化するかを判断できる。

攻撃者に必要なのはたった1つの隙だ。防御側は今や、そこに先に到達する手段を手にしている。

「コストを管理下に置けるのか」

*各エージェントのコストと、それに見合う価値があるかを把握する*

エージェントが答えるすべての質問、すべての再試行、すべての追加ステップが、請求書が届くまで見えないことの多い料金に積み上がっていく。Splunk の最新の State of Observability レポートによると、組織の半数をわずかに上回る割合がAIコストを管理できていない。しかも、コストは話の半分にすぎない。エージェントは高価でありながら、なお間違うことがある。

Splunk Agent Observability は、すべてのエージェントに領収書と成績表を与える。12月にプライベートプレビューが始まる Tokenomics は、Amazon Bedrock と Amazon Cloudwatch のデータを使って、各エージェントのコストをその成績の隣に並べて示し、どのエージェントが予算に見合っているかをリーダーが確認できるようにする。

顧客がエージェントの活動と専門家のフィードバックを自前の評価モデルに変えられるようになったことで、先週の失敗は今週のセーフティネットになり得る。次世代の Eval-G1 モデルは、商用LLMより最大98%低いコストでチェックとガードレールを実行し、従来のLLMより2.5倍速く応答し、リアルタイムで高精度なエージェント制御を可能にする、カスタムの小規模言語モデルだ。evaluation tuner は、品質基準を適用し、機械の速度でエージェントを操縦する、ファインチューニングされた評価モデルを作成する。

評価モデルと evaluation tuner は今月提供開始となり、Tokenomics は2027年初めに AWS Marketplace で一般提供に移行する。

取締役会は、AIがパイロットから本番に移る前に、熱意ではなく証拠を必要とする。これはその証拠を提供する。

この地域は未来を待ったことがない

アジア太平洋、日本、グレーターチャイナのどこでも、テクノロジーが一通りの形でのみ到来したことはない。いくつかの市場は世代をまるごと飛ばし、モバイル、リアルタイム決済、デジタル公共サービスへと直接進んだ。他の市場は何十年もかけて深く成熟したネットワークを築き、今それを近代化している。それぞれの飛躍はインフラに関する判断の上に成り立っており、それまで存在しなかったサービスやビジネスモデルを切り開いた。

AIはそれらすべての出発点に同時に到達し、その一方で数十の市場がデータとAIに関する独自のルールを定めている。制御を失わずに素早く動くことは、この地域で事業を行ううえですでに求められていることであり、AIはそのスピードを高め、リスクを引き上げる。

規模拡大の許可を誰かが与えてくれるわけではない。AIをテストし、見つけたものを修正し、それが費用に見合うことを証明するたびに、その許可を獲得するのだ。それを可能にするインフラは、自分たちの市場が次にどうなるかに利害を持つエンジニア、オペレーター、リーダーたちによって構築されつつある。そして私たちは、彼らとともにそれを築いている。
