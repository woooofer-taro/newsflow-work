アビジャンが地域サイバーセキュリティセンターを開設

Abidjan opens regional cybersecurity centre
ITWeb Africa2026-11-06 21:00報道

アビジャンが地域サイバーセキュリティセンターを開設 - ITWeb Africa

米国拠点のテクノロジー企業 Cybastion は、西アフリカおよび中央アフリカ全域のサイバーセキュリティへの備えを強化し、サイバー防衛能力を高めるため、コートジボワールのアビジャンに Cisco Cybersecurity Centre を開設した。

Cybastion によると、木曜日に落成したこの施設には、潜在的な脅威がないかデジタルシステムを監視する Security Operations Centre (SOC) と、サイバーインシデントを調査し対応する Security Incident Response Team が置かれている。

このセンターは、サイバーセキュリティ研修および重要インフラの保護のための地域拠点としての役割も果たす。

この取り組みは、2025年10月に Cybastion、コートジボワールの女性・家族・児童省、および Cisco の間で署名された覚書を土台としている。

この合意は、サイバーセキュリティ認定研修を活用して人材育成と経済成長を支援することを目指している。

また、THEYA Foundation が支援する Africa DigiEmpower プログラムを拡大するものでもあり、同プログラムは Cisco Networking Academy を通じて、2030年までにコートジボワールの20万人の学習者にサイバーセキュリティ、ネットワーキング、人工知能のスキルを身につけさせることを目指している。

デジタル移行・技術革新大臣の Djibril Ouattara 氏は、この取り組みは国の能力を強化し、地域のサイバーセキュリティのエコシステムにおけるコートジボワールの地位を強めるものになると述べた。

ITWeb Africa は以前、接続の拡大が高い若年層の失業率、インフォーマル経済、地域の犯罪者の移動性と交差する中で、西アフリカが構造的なサイバーセキュリティ上の脆弱性に直面していると報じた。

これらの要因は、ビジネスメール詐欺、暗号資産詐欺、世界中の被害者を狙った企業なりすましなど、ますます巧妙化する攻撃の一因となっている。

「このセンターは、サイバー脅威に対する私たちのレジリエンスと、専門的なスキルを育成する能力の両方を強化します。また、コートジボワールを西アフリカおよび中央アフリカに貢献するサイバーセキュリティの専門知識の拠点にするという私たちの目標を前進させます」と Ouattara 氏は述べた。

Cybastion の社長兼 CEO である Thierry Wandji 博士は、アフリカ諸国は業務をデジタル化し、AI を活用した経済へ移行するにあたり、現地に拠点を置くサイバー防衛能力を必要としていると述べた。

「アフリカ諸国が急速に業務をデジタル化し、AI を活用したデジタル経済へ移行するなか、自分たちに近いところに、その運用環境を理解するチームが配置されたサイバー防衛能力が必要です」と彼は述べた。

「Cybastion は、コートジボワール政府の支援を受け、Cisco のテクノロジーを取り入れて、サイバー防衛およびインシデント対応の能力をコートジボワールと地域にもたらし、あわせてこの職業におけるキャリアへの体系的な道筋も提供します。」

女性・家族・児童大臣の Nassénéba Touré 氏は次のように述べた。「女性と若者にサイバーセキュリティの研修を行うことは、彼女たち彼らのエンパワーメントと、わが国のデジタル変革への貢献を強化することを意味します。」
