Google Chromeのゼロデイ脆弱性CVE-2026-125350が悪用されている

Google Chrome Zero-Day Vulnerability CVE-2026-125350 Exploited in the Wild
www.systemtek.co.uk2026-11-13 07:00報道

Google Chrome ゼロデイ脆弱性 CVE-2026-125350 が実環境で悪用されている

Google は、CVE-2026-125350 として追跡されている深刻度の高い脆弱性が実環境で積極的に悪用されていることを確認したのち、Chrome ウェブブラウザ向けの緊急セキュリティアップデートをリリースした。

この脆弱性は、Chrome の XML コンポーネントにおける use-after-free のメモリ処理上の欠陥であり、リモートの攻撃者が、特別に細工された HTML ページを被害者に開かせることで、ブラウザのセキュリティサンドボックス内で任意のコードを実行できる可能性がある。

Google は、この脆弱性に対するエクスプロイトが実環境に存在することを確認しており、2026年11月9日に定例外のセキュリティアップデートをリリースした。この欠陥の深刻度は High と評価されており、CVSS 3.1 スコアは 8.8 である。

use-after-free 脆弱性は、ソフトウェアがすでに解放されたコンピューターメモリの領域に引き続きアクセスしようとするときに発生する。攻撃者は、この状態を悪用してメモリを破壊し、アプリケーションの動作を操作し、悪意のあるコードを実行できる可能性がある。

今回の場合、攻撃者は、フィッシングリンク、悪意のある広告、または侵害されたウェブサイトを通じて、特別に細工されたウェブページを届けられる可能性がある。被害者がそのページを訪れると、Chrome の XML 処理機能が起動され、ブラウザのサンドボックス内で悪意のあるコードが実行される可能性がある。

サンドボックスは、コードがアクセスできる対象を制限することで保護の層を追加するが、特に、攻撃者がブラウザのセキュリティ制限を回避できる他の脆弱性と組み合わされた場合、悪用の成功は依然として重大なセキュリティリスクとなり得る。

9件のセキュリティ脆弱性に対処

この緊急アップデートでは、Chrome のさまざまなコンポーネントに影響する他の8件のセキュリティ脆弱性にも対処している。これらには以下が含まれる。

  • CVE-2026-125346 – XML における use-after-free 脆弱性。
  • CVE-2026-125344 – V8 における type confusion 脆弱性。
  • CVE-2026-125348 – GPU における境界外書き込み。
  • CVE-2026-125347 – FileSystem における不適切な認可。
  • CVE-2026-125343 – Compositing におけるバッファオーバーフロー。
  • CVE-2026-125345 – WebGL における未初期化リソースの脆弱性。
  • CVE-2026-125349 – GPU における未初期化リソース。
  • CVE-2026-125342 – GPU における未初期化リソース。

このリリースで対処された9件の脆弱性のうち7件は、深刻度 High に分類されている。

この脆弱性は、米国サイバーセキュリティ・インフラストラクチャセキュリティ庁（CISA）の Known Exploited Vulnerabilities（KEV）カタログにも追加されており、対処が必要な既知のセキュリティ上の脅威であることが確認されている。

影響を受けるバージョンとセキュリティアップデート

Google は、サポート対象のデスクトッププラットフォーム全体でこの脆弱性に対処するため、更新された Chrome バージョンをリリースした。

以下のバージョンにセキュリティ修正が含まれている。

  • Windows: Chrome 157.0.8103.51
  • macOS: Chrome 157.0.8103.51
  • Linux: Chrome 157.0.8103.50
  • Chrome Extended Stable: 156.0.8078.96

それ以前の脆弱なバージョンを実行しているユーザーは、できるだけ早く更新すべきである。

管理者はまた、Microsoft Edge、Opera、Brave、Vivaldi を含む他の Chromium ベースのブラウザも確認し、利用可能になり次第、該当するベンダーのアップデートをインストールすべきである。

Google は、ユーザーが Chrome の組み込みアップデート機構を通じて、次の場所に移動してアップデートを確認することを推奨している。

設定 → Google Chrome について。

ブラウザは利用可能な最新のアップデートを自動的にダウンロードするはずだが、セキュリティ修正が有効になるには再起動が必要である。

CVE-2026-125350 がすでに悪用されていることが確認されたため、組織と個人ユーザーは、通常のメンテナンススケジュールを待つのではなく、ブラウザの更新を優先すべきである。
