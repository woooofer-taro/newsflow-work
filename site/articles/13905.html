F5 & Oracle plan OCI security tie-up for AI threats

F5 と Oracle、AI の脅威に対する OCI セキュリティ連携を計画

2026年10月30日（金）

F5 と Oracle は、Oracle Cloud Infrastructure の顧客に Web アプリケーションおよび API の保護を提供するための共同の取り組みを計画していると発表した。この取り組みは、F5 のセキュリティ技術を Oracle のクラウド環境に統合することを意図している。

この取り決めは拘束力のない覚書（MOU）の下にあり、Oracle Cloud Infrastructure（OCI）上でアプリケーションを稼働させている組織を対象としている。顧客が重要なアプリケーションと API をより高度な攻撃から保護しつつ、運用の複雑さを減らせるようにすることを目的としている。

この動きは、個別の専門システムを通じてではなく、既存のクラウド環境の内部に展開できるセキュリティツールへの需要が高まっていることを反映している。企業がインターネットに面したアプリケーションやマシン間接続への依存を強めるにつれ、Web アプリケーションおよび API の保護は、クラウドプロバイダーとセキュリティベンダーにとってより大きな焦点となっている。

Oracle は、この協業を、顧客が OCI 内で追加のアプリケーションセキュリティツールを利用できるようにする手段として提示した。アプリケーションデリバリーとセキュリティに注力する F5 は、この統合は、クラウド、セキュリティ、プラットフォームの各チームにワークロードを保護するためのより直接的な方法を提供することを意図していると述べた。

両社によると、計画されている提供内容は主に2つの課題に対処する見込みである。アプリケーションと API を高度な攻撃から守ること、そして日常のセキュリティ運用を簡素化することである。顧客は、専門的なセキュリティの知見を必要とせずにこれらの保護を利用できるようになるはずだと両社は述べた。

こうした強調は、企業が自動化された脅威や AI の支援を受けた脅威の増加に直面する中で出てきている。攻撃者は、ソフトウェアの脆弱性を素早く特定して悪用するために自動化をますます利用しており、パッチや修復が完了するまでの暫定的な保護を見つけるよう、技術チームに圧力がかかっている。

「サイバー脅威が進化する中、当社の顧客には、運用の複雑さを増すことなく歩調を合わせられるアプリケーションおよび API の保護が必要です」と、Oracle のグローバルパートナーシップ担当シニアバイスプレジデントの KP Papamiltiadis 氏は述べた。

「両社で、F5 のアプリケーションセキュリティの専門知識を OCI に取り入れ、Oracle のクラウドインフラストラクチャとサポートに裏付けられた形で、顧客が重要なアプリケーションと API を保護しつつセキュリティ運用を簡素化できるようにすることを計画しています」と Papamiltiadis 氏は述べた。

両社は、商業条件や提供開始時期を明らかにしなかった。また、計画されている保護がまずどの OCI サービスに適用されるかも特定せず、プラットフォーム上でホストされる Web アプリケーションと API の保護に焦点を当てると述べるにとどまった。

Oracle にとって、この協業は、ネットワーキング、AI、インフラストラクチャのサービスを拡大してきたクラウド事業に、もう1つのセキュリティ層を加えるものである。F5 にとっては、顧客がアプリケーションの稼働場所により近い所へセキュリティツールを集約しようとする中で、大手パブリッククラウドプラットフォームの1つへと展開範囲を広げるものである。

AI の脅威

発表における AI 時代のセキュリティへの言及は、クラウドおよびセキュリティベンダーが、新世代の脅威を軸にメッセージングと製品計画を調整していることを浮き彫りにしている。セキュリティプロバイダーは、AI に支援された攻撃は偵察、脆弱性の発見、悪用を加速させ、防御側の対応時間を減らす可能性があると主張している。

F5 は、Oracle との計画された取り組みをこの傾向と結び付け、AI ランタイム防御と仮想パッチ適用をクラウドチームにとって重要なツールとして挙げた。仮想パッチ適用は、恒久的な修正が適用できるようになる前に、公開されたシステムを既知の弱点から守るために一般的に使われる。

「AI を活用した攻撃は、企業がパッチを適用できる速度よりも速く脆弱性を見つけて悪用できます。Oracle と F5 は、AI ランタイム防御がクラウドチームにとっての答えだと考えており、チームが修復に追いつくまでの間、公開されたシステムを保護する仮想パッチ適用を可能にします」と、F5 の最高マーケティング責任者である John Maddison 氏は述べた。

「F5 のアプリケーションセキュリティ技術を OCI に統合する計画を通じて、セキュリティ、アプリケーション、プラットフォームの各チームに、運用上の摩擦を生じさせることなく、F5 が支える次世代ソリューションで重要なワークロードの保護を支援する、実績のある分かりやすい方法を提供することを意図しています」と Maddison 氏は述べた。

発表は正式な製品の提供開始を確認するまでには至っておらず、この取り組みを確定したものではなく計画段階のものとして繰り返し説明している。それでもなお、両社が、より分散したソフトウェア環境とより速い脅威サイクルに対処するクラウド顧客にとって、アプリケーションと API のセキュリティが中核的な要件だと見なしていることを示している。
