PP135: ネットワークとセキュリティの用途のためのeBPFを理解する

PP135: Understanding eBPF for Network and Security Use Cases
Packet Pushers2026-11-18 13:00報道

Linux システムの内部、つまりそれが起きているまさにその場所──ネットワークスタックの中、プロセスが起動するとき、あるいはシステムコールが発火するとき──で何が起きているかを見ることができるとしたらどうでしょうか。これが eBPF の約束です。カーネルの内部からシステムを観測し、さらに保護する新しい方法であり、安全性、パフォーマンス、制御をめぐる興味深いトレードオフを伴います。

何が強力で何が誇大宣伝かを見分けるために、Packet Protector は Liz Rice を迎えます。彼女は Cisco の Isovalent における Chief Open Source Officer です。また、Learning eBPF の著者であり、オープンソースコミュニティの有力な発言者でもあります。

私たちは、eBPF がどのように動作するか、eBPF がネットワークおよびセキュリティの専門家に可能にする可視性とセキュリティ制御、どのツールが eBPF を使っているか、パフォーマンスに関する潜在的なトレードオフ、eBPF が新たなリスクをもたらすのかどうか、などについて話します。
