New Cisco firewall zero-day being actively exploited

Flaw in Remote Access SSL VPN allows attackers to remotely crash devices; there are no workarounds, but there are patches.

Cisco Secure Firewall Adaptive Security Appliance (ASA) と Cisco Secure Firewall Threat Defense (FTD) の Remote Access SSL VPN サービスにある高深刻度の脆弱性が、脆弱なデバイスをクラッシュさせるために積極的に悪用されている。

この脆弱性は CVE-2026-76418 として追跡されており、深刻度は 8.6 と評価されている。Cisco はアドバイザリで、トンネルグループに二次認証が設定されている場合のロジックエラーが原因だと述べた。リモートの未認証攻撃者が、SSL リモートアクセス VPN への接続時に細工したリクエストを送信することで、デバイスのリロードを引き起こし、その結果サービス拒否に至る可能性がある。

脆弱な製品

「実行中の構成に `webvpn` キーワードが含まれ、少なくとも 1 つのインターフェースで SSL VPN が有効になっている場合、その構成は脆弱である」とアドバイザリは述べている。「`tunnel-group-list enable` が設定されている場合は、デフォルトトンネルグループ `DefaultWEBVPNGroup` を含むすべてのトンネルグループについて `secondary-authentication-server-group` を確認すること。`tunnel-group-list enable` が存在しない、または `no tunnel-group-list enable` コマンドで削除されている場合は、デフォルトトンネルグループ `DefaultWEBVPNGroup` について `secondary-authentication-server-group` を確認すること。デフォルトグループが二次認証を使用している場合、グループリストを無効にしても露出は解消されないためである。」

同社は、回避策は存在しないと述べている。

Cisco は、Secure Firewall ASA のバージョン 9.16.4.104、9.18.4.96、9.20.4.50、9.22.3.200、9.23.1.48、9.24.1.27、9.24.10.1 で修正を公開した。

Secure FTD の修正済みリリースは、バージョン 7.0.11、7.2.13、7.4.9、7.6.7、7.7.14、10.0.3、10.1.1 である。

顧客が脆弱な製品を特定できるよう、Cisco は Cisco Software Checker を提供している。これはセキュリティアドバイザリの影響を受けるソフトウェアを特定し、脆弱性を修正する最も古いリリースを返す。

緩和策

Cisco は顧客に直ちにアップデートするよう求めているが、この脆弱性に対する一時的な緩和策も提示している。ユーザー設定のトンネルグループリスト、またはデフォルトトンネルグループ `DefaultWEBVPNGroup` で二次認証を無効にすることだ。

ただし同社は次のように警告している。「この緩和策はテスト環境で展開され、有効性が確認されているが、顧客は自社環境および自社の利用条件において適用性と有効性を判断すべきである。実施されるいかなる回避策や緩和策も、顧客の導入シナリオや制約によっては、ネットワークの機能、性能、および/またはセキュリティ態勢に悪影響を及ぼす可能性があることを認識すべきである。」
