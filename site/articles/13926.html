Cisco、AIオペレーションと耐量子ネットワーキングを拡張

Cisco Expands AI Operations, Quantum-Safe Networking
Channel Insider2026-10-30 21:00報道

Cisco、Cloud Control に AgenticOps 機能を追加し、量子耐性ネットワーキング技術を導入

Cisco は、新しい AgenticOps 機能を追加して Cloud Control プラットフォームを拡張し、量子耐性ネットワーキング技術を導入します。これによりパートナーは、ネットワーク管理を自動化し、顧客の AI インフラを保護するための追加ツールを得ます。

バンクーバーで開催された Cisco Partner Summit で発表されたこの内容には、拡張された Live Protect のサポートや、ネットワーク運用を簡素化するために設計された新しい統合機能も含まれます。

Cisco、AgenticOps で Cloud Control を拡張

Cisco は、パートナーが AI 対応インフラを構築、保護、管理するための新しい方法を提供するため、Cisco Cloud Control の提供内容を拡張しました。

Cisco Cloud Control は、企業が AI エージェントを拡大するにつれて生じるダウンタイム、可視性のギャップ、ID ベースの脅威といったリスクに対処します。チームと AI エージェントが IT 領域全体で重要なインフラを保護し管理できる、共有の統合運用プラットフォームを提供することによってです。

Cisco の戦略・計画担当 SVP である Jeff Schultz によると、テレメトリと専用に構築されたモデルを組み合わせることで、Cisco は問題をより迅速に特定し解決できることを目指しています。

「これらすべてを、カスタム構築された専用モデルでまとめ、Cisco が問題を自律的に、これまでになく速く特定し解決できるようにします」と Schultz は述べました。「これは、私たちがパートナーと話している、極めて重要な機能です。」

新しい統合により AI 駆動のネットワーク管理を簡素化

Cisco は、Cisco IQ 内に Cisco Cloud Control の統合機能を導入しました。Cisco IQ は、AI 搭載のデジタルインターフェースであり、Cisco CX を一元化する「ワン・フロント・ドア」プラットフォームです。この統合により、量子対応状況を含むリアルタイムのリスク情報が表示され、Cloud Control 内で、リスクのあるコントローラー管理デバイスに対してワンクリックで操作できるようになります。

さらに Cisco は、Cloud Control に以下を含む AgenticOps 機能を導入しています。

  • Model Foundry: Cisco Cloud Control 内の新しいプラットフォームサービスです。Cisco の専用モデルを、検出、評価、ファインチューニング、そして自社データでの実行まで、すべて一か所で行えるようにするものです。また、より広範な公開に先立ち、Cisco の最新モデルバージョンとウェイトの専用の提供先にもなります。管理された提供(Controlled Availability)は Cisco パートナーから開始されます。
  • 信頼される自律運用のための ThousandEyes インテリジェンス: ThousandEyes は WiFi 6E および 7 のアクセスポイントにネイティブに統合されます。これにより、ユーザーがオンラインでない場合でも、アプリケーションとネットワークのパフォーマンスを24時間体制で検証する自動バックグラウンドテストが可能になり、エージェント的な操作に対する顧客の信頼を強化します。
  • エージェント統合: Cisco は、標準化されたブリッジとして機能する MCP 接続をそのプラットフォームに導入しています。これにより、AI ツールがライブのネットワークデータに容易にアクセスできるようになります。パートナーが複雑なカスタム接続を構築・保守する必要がなくなり、トラブルシューティングやレポート作成などのタスクで自動化されたワークフローを作りやすくなります。また、テレメトリを実行可能なエクスペリエンス指標に直接結び付けることで、IT チームが問題をより速く特定し解決できるよう支援します。

量子耐性 Wi-Fi と Live Protect がセキュリティの選択肢を拡大

重要なワークロードを長期にわたって接続し、電源供給し、保護するために必要な物理的・デジタル的基盤を強化するため、Cisco は新しい耐障害性と量子耐性のイノベーションを導入しました。

これらのイノベーションには以下が含まれます。

  • 無線ネットワーク全体への量子対応の拡大: Cisco は、量子耐性機能を備えた WiFi 7 アクセスポイントを発売します。無線経由の耐量子暗号(PQC)による量子安全な通信のために、Cisco は Qualcomm 製チップを搭載したアクセスポイントを提供します。また、クライアント側のソリューション一式は、Intel の WiFi チップセットとドライバー、および Microsoft Windows ソフトウェアによってサポートされます。
  • Live Protect のサポート拡大: Live Protect は、対応する Cisco プラットフォームおよびリリースにおいて、脆弱性の開示からパッチ適用完了までの間隔を縮めます。現在は、N9000 シリーズスイッチ、N9300 スマートスイッチ、Catalyst SD-WAN、C9000 シリーズスマートスイッチ、CW9800 ワイヤレスコントローラーでサポートされています。Cisco 8000 セキュアルーターおよび Cisco ファイアウォールのサポートは、2026年末までに提供される予定です。
  • 特権インフラアクセス: Teleport と共同開発された Cisco Privileged Infrastructure Access は、ネットワークチームと AI エージェントに、短命で ID に紐づいた証明書を用いて、Cisco ルーターとスイッチへの迅速で統制され、タスク固有のアクセスを提供します。セッションは記録され、特権はセッション終了時に失効します。

Schultz は次のように述べています。「Live Protect は、パッチをまだ適用していなくても、顧客が最も重大な脆弱性を悪用されることを防ぐための盾を提供する機能です。これは、データセンター、キャンパス、ブランチにまたがり、当社のネットワーキング製品の Essentials ティアの一部として無料で利用できます。」

Cisco、パートナー向けのマネージドサービスの機会を拡大

Cisco のパートナーにとって、新しい機能はネットワーク管理の合理化と、顧客に提供するサービスの拡大に役立つ可能性があります。AgenticOps と MCP 統合は、トラブルシューティングやカスタム統合に費やす時間を減らすことができ、拡張された Live Protect のサポートと量子耐性ネットワーキング技術は、顧客の変化するセキュリティニーズに対応する追加の手段を提供します。

全体として、これらのアップデートにより、MSP やその他のソリューションプロバイダーは、運用負荷を比例的に増やすことなく、ますます複雑化する顧客環境を管理できるようになる可能性があります。
