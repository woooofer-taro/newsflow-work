GDライブラリ：Junos OSはどのようにして攻撃にさらされたのか？

GD library: How did it open the Junos OS to attacks?
TechTarget2026-11-05 07:00報道

GD library: How did it open the Junos OS to attacks? - TechTarget

Juniper Networks Inc. と US-CERT は、Junos オペレーティングシステムで使用されている GD グラフィックスライブラリの深刻な脆弱性に関するセキュリティアドバイザリを発行した。GD ライブラリ（LibGD）は、他のベンダーにも問題を引き起こしている。単純な画像ライブラリが、どのようにして Junos を攻撃にさらしたのか？ 企業は GD ライブラリのようなオープンソースの画像ライブラリを避けるべきか？

ルーターやネットワーク機器に、通常であればより従来型のサーバーでしか見られないと予想される脆弱性があると聞くのは、興味深いことだ。この出来事は、包括的な脆弱性管理プログラムを持つ必要性を裏付けている。

同様に、攻撃対象領域と複雑さを減らすために、デバイスには絶対に必要な機能だけが含まれると期待するのは妥当に思える。たとえば、システムに Web サーバーがインストールされていなければ、その Web サーバーを保護したり、更新をインストールしたりする必要はない。

ルーターやネットワーク機器は標準的なサーバーと同じ機能を多く持つため、同様の脆弱性を抱えうる。ルーターやネットワーク機器は通常 Web サーバーとは考えられていないが、従来のコマンドラインのオプションと並んで、デバイスを管理するための Web インターフェースを持つことが多い。

Juniper Networks は、動的な画像を作成するためのオープンソースのコードライブラリである GD ライブラリの深刻な脆弱性に関するセキュリティアドバイザリを発行した。この脆弱性は、同社のルーターやネットワーク機器で使用されている Juniper の Junos OS に影響を与えた。

Juniper Networks が挙げた回避策は、オンボードの PHP スクリプトの使用を中止することと、Web 管理へのアクセスを制限することである。ルーターやネットワーク機器へのアクセスを制限することは、標準的なベストプラクティスだからだ。Juniper Networks は、画像を生成する独自のソフトウェアを開発するか、商用ライブラリのライセンスを取得することで、この脆弱性を回避できた可能性がある。

しかし、ソフトウェア開発の複雑さと、同社の中核的な能力がネットワーキングにあることを考えると、GD ライブラリのような十分にテストされ広く使われているオープンソースライブラリを使うことは非常に妥当である。ライブラリの種類にかかわらず、Jupiter Networks は、ソフトウェア開発ライフサイクルの一環として、それを更新し、セキュリティ脆弱性を監視する必要がある。
