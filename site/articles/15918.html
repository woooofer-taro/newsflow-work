GPT-5.1 のトークン1ドル分で、中国のグレート・ファイアウォールを回避する新たな方法が見つかる

研究者らは、わずか1ドル相当のトークンを費やしただけで、中国のグレート・ファイアウォールを回避する新たな方法を見つけた。

この結果は、Association for Computing Machinery の Special Interest Group on Security, Audit and Control が主催する Conference on Computer and Communications Security で先週発表された、「CircumVolve: Automated Discovery of Censorship Evasion Strategies Using Large Language Models」と題する論文に掲載された。

マサチューセッツ大学アマースト校、コロラド大学ボルダー校、および活動家団体 Great Firewall Report の6人の研究者が執筆したこの論文は、グレート・ファイアウォールの穴を見つけるのは骨の折れる作業であり、したがって AI に任せるのにうってつけの作業だと指摘している。

著者らは「CircumVolve」と呼ぶツールを考案し、これを「ネットワークスタック全体にわたる検閲回避戦略を自動的に発見するためのシステム」と説明している。

「CircumVolve は、LLM によるコード生成と、反復的なフィードバック駆動型の評価を組み合わせ、検証可能で展開可能な回避技術を生成する」と著者らは書いている。「CircumVolve は、さまざまな検閲技術を個別のシナリオとしてモデル化し、各シナリオは現実の検閲者の具体的な文脈、プロトコル上の制約、およびブロック機構を捉えている。各シナリオの中で、回避戦略は、パケットおよびプロトコルの操作を実装する実行可能な Python プログラムとして表現される。その操作は、TCP/IP ヘッダーフィールドの書き換えから、パーサーの曖昧さを突く DNS クエリの作成、暗号化された QUIC Initial パケットの内部構造の変更にまで及び、その間、プロトコルの正しさを許容範囲内で維持するか、有益な場合には戦略的にそれに違反する。」

著者らは、中国、イラン、パキスタン、カザフスタンが使用する模擬検閲ツールと、それらの国のクラウド上に展開した仮想プライベートサーバーで CircumVolve を試験した。これらの試験では、GPT-5.1 を使用した場合、*最初の回避成功*までの API コストの中央値は、トークン費用で1ドル未満だった。

著者らは、検閲インフラの運用者が CircumVolve の動作を観測できる可能性があることを認めているが、ペイロードが比較的小さいこと（送信トラフィック80 KB、受信トラフィック150 KB）と、テストの間に25〜45秒の間隔があることから、検知を免れるのではないかと考えている。

「CircumVolve は、検閲回避のライフサイクルを加速するために LLM を活用する第一歩である」と著者らは書いている。「プロトコル分析、実装、テストといった労力のかかる作業を自動化することで、AI 駆動のアプローチは、比較的リソースの乏しいインターネットの自由のコミュニティにとって、回避能力の研究をはるかに身近なものにする。[そして] AI 支援システムが、インターネットの自由の擁護者と潤沢な資金を持つ検閲国家との間のリソースの差をどのように縮められるかを示している。」

Lenovo、ついにデータセンターで巨額の利益を上げる

2014年に IBM の x86 サーバー事業を買収して以来、中国のハードウェア大手 Lenovo は、ストレージ、ネットワーキング、ハイパースケーラー向け販売へと事業を拡大しながらも、データセンター販売から利益を出すのに苦戦してきた。

さまざまな戦略転換や誇大宣伝の波ではできなかったことを、AI ブームがついに成し遂げた。同社の Infrastructure Solutions Group (ISG) を四半期利益10億ドルへと押し上げたのだ。

先週発表された第2四半期決算 [PDF] で、同社は ISG の売上高が四半期として過去最高の113億ドルに達し、前年同期比178パーセント増となったこと、そしてその見事な大きな利益を明らかにした。企業向けハードウェアのサプライチェーンが逼迫している時期に、Lenovo は x86 サーバーの出荷を増やすことができ、さらに16パーセントの市場シェアでこの種のシステムの最大のベンダーになったと述べている。

Lenovo はまた、四半期売上高が174億ドルに達したインテリジェントデバイス事業グループの前年同期比15パーセントの成長を挙げ、世界有数の PC プロバイダーとしてさらに先行したと主張した。同社は PC 市場の23.8パーセントを占めるとしており、最も近い競合である Apple より7パーセント多い市場シェアを持つという。同社は、プレミアムデバイスが PC 事業の63パーセントを占めると述べた。

全体の売上高は、当四半期に前年同期比48パーセント増の302.4億ドルとなった。

インドネシアの氷河はほぼ消滅

南緯11度から北緯6度の熱帯の緯度にある1万7000の島々にまたがる国であるインドネシアに、氷河が形成されるほど高い山岳地域があると知れば、読者は驚くかもしれない。

インドネシアの氷河は、南緯4度のニューギニア島にある標高4,884メートルの山頂、Puncak Jaya（別名 Carstenz Pyramid）の頂上にしがみついていた。

残念ながら、NASA が先週発表した評価によれば、氷河は、わずかな氷の斑点以外にはほとんど何も残っていない程度まで溶けた可能性が高い。

NASA は先週、1988年には Puncak Jaya の頂上で4.31 km2 を覆っていた氷河を示す画像と、その氷の大半が消えていることを示す今年の画像を公開した。2025年9月の画像には、わずか.09km<sup>2</sup> の氷しか残っていないことが示されていたようだ。

「氷塊が氷河と見なされるには、一般に、自重で斜面を流れ下るのに十分な厚さがあり、雪の蓄積が融解を上回る領域がなければならない」と NASA の Kathryn Hansen は書いた。「Puncak Jaya に残る氷は非常に薄くなり、小さな停滞した斑点に分断されたため、もはや流れていない。」

参考までに、商業事業者は Puncak Jaya への遠征を運営している。一部の人々がこれをオーストララシア/オセアニアで最も高い山と見なし、したがって各大陸の最高地点である「Seven Summits」の一つと考えるため、ピークハンターたちはこの山を求める。

*The Reg* は、Puncak Jaya をそのリストに含めることの妥当性をめぐる議論には立ち入らないが、赤道直下の高山を楽しみたいなら、本記者は最近、マレーシアの標高4,095mの Mount Kinabalu に登った。技術も装備も要らない一泊の登山だが、しなやかな膝が確実に必要だ。この山頂は遠い昔には明らかに氷河に覆われていたが、現在の Kinabalu では雪は極めてまれだ。

オーストラリアの銀行、バグ探しツールを無償公開

奇妙な話がある。オーストラリアの Commonwealth Bank (CBA) は、独自コードのバグをスキャンする AI 搭載ツールを作成し、それを「CodeCheck」という無償リリースとして公開した。

同行は、これが OpenAI の Codex と Anthropic の Claude Code の出力を、「コードを分析し、潜在的な脆弱性を調査し、エンジニアを支援する情報を提供するための一貫したプロセス」で分析すると述べている。これは「CBA 内で使用されているアプローチに基づいているが、CBA が社内で使用するシステム、ツール、統制と同じものではなく、それらを表すものでもない」という。

同行は CodeCheck を GitHub に投稿し、そこで、このプロジェクトは「企業が評価するための一度限りのオープンソースリリース」であり、コードを積極的に保守、更新、サポートすることはないと警告している。

日本の宇宙計画、一部の打ち上げを Mitsubishi に移管

日本の宇宙航空研究開発機構 (JAXA) は先週、特定の構成で使用される主力ロケット H3 の打ち上げ運用の責任を、Mitsubishi Heavy Industries (MHI) が引き継ぐことで合意に達したと発表した。

この合意により、MHI は、2基の LE-9 液体燃料エンジンと2基の SRB-3 固体燃料ブースターを組み合わせて使用する H3 の打ち上げを担当することになる。

JAXA は、異なる構成、または実験的な構成を使用する打ち上げの運用を引き続き担当する。

JAXA は、それらの新しい機体の信頼性に納得したら、それらも民間事業者に移管する計画だ。®
