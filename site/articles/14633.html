Cisco、新たなCisco 360でパートナー向け機会を拡大…

Cisco Expands Partner Opportunity with New Cisco 360…
aapnews.aap.com.au2026-11-08 21:00発表

*パートナーシップの強化により、AI時代にあらゆるパートナーが先手を打ち素早く動ける道筋が生まれる*

ニュース概要:

  • Cisco は、取引のあらゆる段階でエコシステムを認め支援するため、新たなインセンティブおよびAI対応ツールとともに、Ecosystem Deal Registration を導入する。
  • Cisco IQ for partners の一般提供開始により、新たな収益性の道筋と成長機会がもたらされる。
  • Cisco Cloud Control の提供範囲拡大により、パートナーは AI-ready なインフラストラクチャを構築、保護、管理する新たな方法を得る。

ブリティッシュコロンビア州バンクーバー、2026年10月27日 /PRNewswire/ -- AIはインフラストラクチャを企業投資の中心に据えつつあり、AI時代を支えるネットワークを近代化、拡張、保護するための重要な市場機会を生み出している。パートナーがこの変革を主導できるよう、本日 Cisco Partner Summit において、Cisco（NASDAQ: CSCO）は、パートナープログラム、カスタマーエクスペリエンス提供内容、テクノロジーポートフォリオにわたる新たな進化を発表し、グローバルな接続性成長の次の波を捉えるために必要なツールとインセンティブを提供する。

Cisco 360 Partner Program 内のインセンティブの拡大と、Cisco IQ for Partners の一般提供開始が組み合わさることで、現在の環境においてより高い俊敏性とインテリジェンスを求める需要に応える。Cisco Cloud Control は引き続きそのすべてをまとめ上げ、Cisco のパートナー、IT担当者、AIエージェントが、AI時代の重要なインフラストラクチャを接続し、保護し、運用するために協働できるプラットフォームを提供する。

「パートナーは Cisco が顧客と出会う場所であり、AI時代は私たち全員により多くを求めています」と、Cisco のグローバルパートナーセールス担当 SVP である Tim Coogan は述べた。「顧客には、先手を打って素早く動く俊敏性を持つパートナーが必要です。Cisco 360 Partner Program の強みを Cisco IQ および Cisco Cloud Control と組み合わせることで、意思決定を形づくるアドバイザーから、それを提供しサポートするパートナーまで、あらゆるタイプのパートナーに、それを実現し、その対価を得る新たな方法を提供しています。」

俊敏なパートナーエコシステムの推進

アドバイザー、デベロッパー、ディストリビューターは、顧客が何を購入するか、そしてそれがどのように提供されるかをますます左右するようになっており、Cisco 360 Partner Program が最初の通年を迎えるにあたり、プログラムはそれぞれのための専用の道筋を追加した。さらに、あらゆるパートナータイプを対象にプログラム体験、収益性、イネーブルメントにわたる強化が行われ、AI時代における真のエコシステムの俊敏性を実現し、すべてのパートナーの貢献に報いる。

  • Ecosystem Deal Registration: アドバイザーとデベロッパーが、取引につながる貢献について正式に認められる新たな方法であり、顧客ライフサイクル全体にわたるパートナーの影響を実証する。
  • 新たな成長の道筋: アドバイザーおよびデベロッパー向けの Partner Value Indexes（PVI）が利用可能になり、新たな統合ディストリビューター PVI は2027年春までに利用可能となる。これは、それぞれの役割が顧客にもたらす独自の価値に基づいてパートナーの貢献を測定するという Cisco の取り組みを裏付けるものである。
  • Cisco Partner Incentive（CPI）レートの進化: パートナーの価値交換への継続的な投資として、ACV成長報酬を50%引き上げ、すべてのユースケースにおける Adopt を2倍に引き上げるとともに、Cisco IQ に関する新たな adopt インセンティブを開始する。
  • 追加の +2% クロスセルボーナス: Splunk を含む、まったく新しい Cisco アーキテクチャへ顧客アカウントを拡大する Preferred および Portfolio パートナー向けの、既存のクロスセルリベートに上乗せされる追加の +2%。
  • Cisco IQ Adopt Incentive: 顧客がオンボーディングされ、テレメトリと統合されるよう、パートナーによる Cisco IQ の採用に報いるために設計されている。

さらに、パートナーが顧客向けの提供内容を差別化し拡大できるよう、強化されたパートナーエクスペリエンスのリソースが利用可能になった。

  • Partner Experience Platform（PXP）での案件登録の可視化: パイプラインの健全性を最適化し、パートナーが成長機会を特定できるようにする、自動化されたリアルタイムのインサイト。
  • 高度なトレンド分析と適格性トラッキング: 新しい PVI API により、パートナーはビジネス成果を最適化し、自らの実績を先回りして管理できる。
  • オンデマンドのエージェント型リソース: One Cisco Content Agent（ベータ）により、パートナーの営業担当者とマーケティング担当者は、承認済みの Cisco コンテンツに素早くアクセスし、特定の優先事項や業界トレンドに合わせて顧客ごとに価値提案をカスタマイズでき、関連性の高い共同ブランドのプレゼンテーションを数時間ではなく数分で作成できる。
  • 新しい CPI Deal Estimator: パートナーが取引の経済性をモデル化し、あらゆる案件でリベート収益を最適化できるようにする。
  • 新しい OT 認定: IT、OT、セキュリティの融合が進んでいることを反映し、Learn with Cisco は新しい Cisco OT Security Practitioner 認定を開始するとともに、新しいハンズオンラボ機能を備えた Cisco Modeling Labs 2.11 をリリースする。

Cisco IQ: 収益性の高いサービスのための新たなパートナー機会

顧客は、自社のIT環境をより良く理解し、リスクを直感的に特定し、問題がビジネス成果に影響する前に迅速に対処する能力を求めている。パートナーも、顧客により関連性の高い、より付加価値の高いサービスを提供し、近代化の機会を提案できるよう、同じレベルの可視性を必要としている。本日、Cisco は Cisco IQ for Partners の一般提供開始を発表し、グローバルなパートナーエコシステムが、マネージドサービスとリセラーモデルの両方にわたって、反復可能で高利益率の成長を促進できるようにする。2026年4月以降、16,000を超える顧客を擁し、約2,000万台のデバイスにわたる可視性を備える中で、Cisco IQ のパートナーへの拡張は、取引成立後の成長に向けた新たな機会を提供する。

  • 差別化されたマネージドサービスの提供: Cisco IQ MCP Server と拡張された API アクセスにより、パートナーは自社のプロフェッショナルサービス、ワークフロー、AIエージェントにインテリジェンスをシームレスに統合できる。これにより、パートナーは顧客の環境に即座に問い合わせることができ、新たに出現するAI搭載の脅威などの短期的なリスクに対処しつつ、顧客のインフラストラクチャ近代化の計画を支援できる。
  • リセラー向けの安全で自動化された機能: Cisco IQ の新しい Role-Based Access Control（RBAC） により、顧客はパートナーに、自社のインストールベースへの直接的で安全な可視性を付与できる。これによりリセラーは、リアルタイムデータと API を活用してマシンスケールで運用できる、インテリジェンス主導のパートナーへと変わる。隠れたネットワークリスクを発見し、手動でのエクスポートをなくし、顧客の近代化を先回りして推進する。

Cisco は、顧客とパートナー向けの新しい Cisco IQ 機能も導入する。

  • 定型的なパッチ適用を超えたリスクの特定を支援する、新しいAI搭載の Quantum Safe および Software End of Vulnerability Support（EoVS）プレイブック。
  • 停止リスクを見つけ、修復の優先順位を付け、アップグレードやハードニングサービスの範囲を定めるための Priority Bugs & Software Conformance Assessments。
  • 量子対応状況を含むリアルタイムのリスクインテリジェンスを表示し、Cloud Control 内で、コントローラー管理下のリスクのあるデバイスに対してワンクリックで対処できるようにする、シームレスな Cisco Cloud Control 統合。
  • 豊富なコンテキストを持つリアルタイムデータに基づく Cisco IQ AI Assistant の強化。トラブルシューティングは、デバイス診断と Cisco Technical Assistance Center（TAC）のナレッジに基づくものになった。TAC ケース管理が簡素化され、AI Assistant 内から TAC ケースを作成、クローズ、エスカレーションできる。

「長い間、パートナーは Cisco が持っていたのと同じ視点を持たないまま、顧客との会話に臨んできました。それが本日、変わります」と、Cisco の EVP 兼 Chief Customer Experience Officer である Liz Centoni は述べた。

「Cisco IQ Partner Support Standard により、パートナーは同じインテリジェンスを自社ブランドの下で、自社の専門家を通じて提供できるようになります。それはパートナーの名前であり、パートナーの顧客関係であり、パートナーのサービス事業です。Cisco IQ はエンジンです。パートナーがビジネスです。」
