Cisco、エージェント型エンタープライズを保護するフロンティアAIレッドチーミングとエージェントObservabilityを発表

AI Defense、Splunk、Cisco IQ のイノベーションにより、セキュリティおよびオペレーションチームは、リスクを発見し、価値を測定し、信頼を証明するための一つのループを得る。

ニュース概要:

  • Cisco AI Defense の適応型AIレッドチーミングフレームワークに Anthropic の Claude Mythos が追加され、高度な敵対的推論を活用してAIエージェントに対する現実世界の攻撃をシミュレートする。
  • Cisco の強化された Tokenomics により、組織はエージェントのコストを ROI とリアルタイムで直接結び付けることで、最も重要なものを守るためにAI支出を最適化できる。
  • 何十年にもわたる脆弱性およびトラブルシューティングのデータを活用する Cisco IQ は、ライブの脅威検知データを、露出している可能性のあるネットワークインフラストラクチャと機械の速度で相関付け、修復を加速する。
  • これらのイノベーションを合わせることで、企業は、ますます高性能になるAIエージェントと複雑なエンタープライズAI展開を保護し、統制し、観測するための常時稼働の信頼ループを得る。

オーストラリア、メルボルン、2026年11月10日 -- CISCO LIVE APJC -- Cisco（NASDAQ: CSCO）は本日、AIアプリケーションおよびエージェントのレッドチーミングのために AI Defense に Claude Mythos を追加することを発表した。これにより、防御者はフロンティアの敵対者の推論でAIシステムをストレステストできる。新しい Splunk Agent Observability および Cisco IQ の進化と組み合わせることで、Cisco は、エージェントを機械の速度で保護し、観測し、統制することを必要とする新しい信頼の時代に向けて企業を準備している。

「保護、統制、観測ができないものを拡張することはできません」と、Cisco の社長兼最高製品責任者である Jeetu Patel は述べた。「フロンティアレベルのAIランタイム保護と機械の速度のエージェント品質管理を統合することで、私たちは継続的な信頼ループを構築しています。エージェントを侵害から守りつつ、費やされるすべてのトークンが測定可能なビジネス価値をもたらすことを確実にします。」

AIエージェントが急増し、複雑なツールや機密データに接続するなか、先月の Splunk のグローバル調査レポートによると、ITOps およびエンジニアリングの専門家の81%が、セキュリティチームとオブザーバビリティチームの間の協力の増加を挙げている。Cisco の Splunk および AI Defense のイノベーションは、セキュリティリーダーが、高性能なAIエージェントに対して個別に調整されたセキュリティテストを実施しながら、トークン支出と効果的なツール使用を把握できるようにする。

Cisco が2025年1月に AI Defense を開始して以来、数百のお客様が、本番稼働前にAIモデル、アプリケーション、エージェントの重大な欠陥を特定するのを支援してきた。その適応型レッドチーミングにより、セキュリティチームは、対象システムに対するカスタマイズされた多段階の攻撃を迅速に構築し、特定のリスクを明らかにできる。Claude Mythos は、重要なテストを計画し、その結果を各システムに対する攻撃のアイデアに変換する高度な推論で、このフレームワークを拡張する。

機能は以下のとおり:

  • 現実的な敵対的アイデア創出: 複雑なアーキテクチャ全体にわたる微妙な脆弱性の特定を支援するよう設計された、多段階でコンテキストに沿った攻撃経路を生成する。
  • 安全で封じ込められたアクセス: 設計上、お客様は AI Defense の構造化されたインターフェースを通じてのみ操作する。お客様には自由形式のプロンプトアクセスはない。
  • 監査証跡と再現可能な結果: AI Defense は監査のためにすべてのテスト操作を記録し、結果は、後続の攻撃ループに情報を与えるために引き継ぐことができる。

「企業は、中核業務にAIエージェントをますます組み込んでおり、本番稼働させる前にそれらのエージェントを徹底的にテストしたいと考えています」と、Anthropic のサイバーセキュリティ責任者である Michael Moore は述べた。「Claude Mythos を Cisco AI Defense に導入することで、Cisco は、テストを計画し各システムに対する攻撃のアイデアを生成する高度な推論により、セキュリティチームがエージェントをレッドチーミングするのを支援できます。」

Cisco は、多層的な保護措置を備えた Claude Mythos を使用するよう AI Defense を設計した:

  • 登録済みで承認された対象: 企業のお客様が明示的に登録し、所有し、テストを承認した対象に対してのみ動作する。任意のインターネットインフラストラクチャをスキャンすることはできない。
  • 名前が特定されたオペレーターへの帰属: すべてのレッドチーミングの実施には認証が必要であり、暗号的に、名前が特定された企業のオペレーターに結び付けられる。
  • 取り消し可能な実行: 実施は、人間のユーザーが定義した固定のジョブと目的で実行され、必要に応じて停止できる時間制限付きのセッションで行われる。
  • 二層の監督: AI Defense の製品レベルの制御は、プログラムレベルの保護措置および監視と並行して動作する。

ループを閉じる: テストの所見から測定可能なエージェント ROI へ

フロンティアAIモデルは、AIレッドチーミング戦略の立案などの複雑なセキュリティタスクで優れた能力を発揮できる。その能力は両刃の剣である。多くの企業が、拡大するAIポートフォリオ全体でセキュリティ、ガバナンス、ROI の考慮事項のバランスを取ろうとしているまさにそのときに、AIは攻撃者の参入障壁を下げている。

組織がAIエージェントを自信を持って大規模に展開するには、AIエージェントのコスト、ビジネスパフォーマンス、品質に対する統合されたリアルタイムの可視性が必要である。Cisco は、新しい Splunk Agent Observability の強化により、信頼のギャップを埋めている:

  • Tokenomics: AI支出を出力品質に結び付けるコストガバナンスで、まもなく AWS Marketplace で提供開始予定。Amazon Bedrock と Amazon CloudWatch の使用状況データを用いて、各エージェントのコストを、その作業の品質と影響を評価する評価と組み合わせ、組織にAI ROI の単一のビューを提供する。これは、.conf26 で開始された、Claude Code、Codex、Cursor などのAIエージェントおよびコーディングツール全体でコストを追跡するトークン支出の帰属を拡張するものである。
  • Eval-G1 評価モデル: Splunk Agent Observability は、エージェントのトレースと専門家のフィードバックを、商用LLMより最大98%低いコストで評価とガードレールを実行するカスタム小規模言語モデルに変えるためのサポートを拡張する。これらの次世代 Eval-G1 モデルは、従来のLLMより2.5倍高速な評価応答時間を実現し、高い精度でのリアルタイムのエージェント制御を可能にする。
  • 評価チューナー: チームは、エージェントのトレースと専門分野の専門家のフィードバックを、ファインチューニングされた評価モデルに変え、品質基準を適用し、機械の速度でエージェントを誘導できる。

Claude Mythos による適応型レッドチーミングは、一部の企業向けにまもなく提供される。Tokenomics は12月にプライベートプレビューで提供され、AWS Marketplace での一般提供は2027年初頭となる。評価モデルと評価チューナーは今月から一般提供されている。

Cisco IQ と Splunk Platform を基盤とする Cisco Data Fabric によるインフラストラクチャの露出とセキュリティ対応の接続

脆弱性の露出を理解することは重要である一方、防御者は、複雑なエンタープライズ環境全体でリスクを修復する速度も加速しなければならない。Cisco IQ は重大な露出を特定し、Cisco パートナーと Professional Services の強力なエコシステムが、洞察を行動に変える。パートナーは大規模な修復の提供とインフラストラクチャの近代化を支援し、Cisco Professional Services は新しい Cisco の機能を実践に移すための深い専門知識をもたらす。Cisco とそのパートナーは共に、運用の合理化と、AI時代に向けたIT インフラストラクチャの将来性の確保を支援できる。

AIによって加速された脅威が、脆弱性の公開から悪用までの期間を数週間から数時間に短縮するなか、ある時点での監査では組織は露出したままとなる。セキュリティおよびネットワーク運用チームが機械の速度で行動できるよう、Cisco は、2,200万台を超えるデバイスにわたる約17,000のお客様を持つ Cisco IQ からのリアルタイムのインテリジェンスを、エンタープライズセキュリティ環境、オープンなエージェント型プロトコル、自動化されたライフサイクルワークフローへ直接拡張している。

主な更新内容は以下のとおり:

  • Cisco Data Fabric 統合: Cisco IQ の脆弱性、ライフサイクル、構成データを、オープンAPIを介して Splunk Platform に直接取り込み、SecOps チームとAIエージェントが、Splunk Enterprise Security で、ライブの脅威検知を基盤となるネットワークの露出と相関付けられるようにする。
