トップ10：データセンターのサイバーセキュリティ企業

攻撃者がいったんデータセンター内部に入り込めば、境界防御は役に立たない。

重要なのは、攻撃者がどこまで移動できるかであり、マイクロセグメンテーションは、攻撃者が到達できる範囲を限定するのに役立つ。

Illumio と Akamai Guardicore は横方向の移動の封じ込めに注力しており、Broadcom の VMware vDefend は仮想化環境に同様の制御をもたらす。

一方、Palo Alto Networks、Fortinet、Cisco はネットワーク自体を保護し、CrowdStrike と Microsoft はエンドポイント、ID、クラウドワークロードをカバーする。

Check Point と Trend Micro もランキングに入っており、ハイブリッド環境全体でワークロードを保護し脅威を検知するよう設計されたツールを備えている。

10. Trend Micro

CEO： Eva Chen

設立： 1988年

本社所在地： 日本、東京

Trend Micro は、マルウェア、ランサムウェア、メール、クラウドワークロード向けのセキュリティの開発に、40年近くを費やしてきた。

同社の強みは幅広さである。セキュリティチームにリスクの共通した見方を提供するよう設計されたプラットフォームを通じて、エンドポイント、ネットワーク、ハイブリッドクラウド環境を保護する。

データセンター運営者にとって、これは物理インフラ、仮想マシン、パブリッククラウドサービスに関して重要であり、これらは併せて防御されなければならない。

Trend Micro のグローバルな脅威インテリジェンスは、攻撃手法が変化するなかで迅速に対応することにも役立っている。

9. Illumio

CEO： Andrew Rubin

設立： 2013年

本社所在地： 米国、カリフォルニア州

Illumio の専門は封じ込めである。同社のマイクロセグメンテーション技術は個々のワークロードの周囲に制御を配置するため、攻撃者が1台のサーバーを侵害しても、他のサーバーへ自由に移動することはできない。

これは、何千もの相互接続されたシステムが攻撃者にとって意図しない経路を生み出し得るデータセンターで、特に有用である。

Illumio のアプローチはゼロトラストモデルに適合している。ネットワーク内部のすべてが安全であると仮定するのではなく、システム間の通信を検証し制限する。

その結果、問題が発生した際の被害範囲（ブラストラディウス）が小さくなる。

8. Akamai

CEO： Tom Leighton

設立： 1998年

本社所在地： 米国、マサチューセッツ州

Akamai は、インターネットトラフィックをグローバル規模で配信し保護することで名を成した。2021年の Guardicore の買収によりマイクロセグメンテーションが加わり、顧客はワークロード間の通信をマッピングし制御できるようになった。

この組み合わせは、チームが外部トラフィックとサーバー間の内部の東西方向の移動の両方を保護する必要があるデータセンターに適している。

Akamai のプラットフォームは現在、コンテンツ配信、エッジセキュリティ、API保護、ワークロードのセグメンテーションに及んでおり、組織がランサムウェアやその他の侵入に利用され得る機会を減らすのに役立っている。

Broadcom は、エンタープライズセキュリティ市場の2つの重要な要素を結び付けている。VMware のインフラストラクチャソフトウェアと Symantec のセキュリティ事業である。

VMware vDefend は、マイクロセグメンテーション、分散ファイアウォール、脅威検知を含む、仮想化環境およびクラウド環境内のセキュリティを提供する。

Symantec は、エンドポイント保護とより広範なエンタープライズセキュリティ機能を加える。

VMware ベースのデータセンターを運用する組織にとっての利点は統合である。セキュリティポリシーを、保護対象となる仮想マシンやワークロードの近くに適用できるからである。

6. Check Point Software

CEO： Nadav Zafrir

設立： 1993年

本社所在地： 米国、カリフォルニア州

Check Point は商用ファイアウォールの初期の先駆者であり、その後、クラウド、エンドポイント、モバイル、ネットワークセキュリティへと拡大してきた。

同社の Quantum ポートフォリオはデータセンターとネットワークの保護に対応し、CloudGuard はパブリッククラウド環境を保護し、Harmony はユーザーとデバイスをカバーする。

同社の Infinity Platform は、これらの製品を結び付けるよう設計されており、セキュリティチームに共有されたインテリジェンスとより連携したポリシー管理を提供する。

データセンターの資産がオンプレミスのサイト全体および複数のクラウドにまたがるなか、この統合されたアプローチの重要性は高まっている。

5. CrowdStrike

CEO： George Kurtz

設立： 2011年

本社所在地： 米国、テキサス州

CrowdStrike は Falcon プラットフォームを、単純な考えを軸に構築した。エンドポイントで何が起きているかをリアルタイムで把握し、その可視性を使って攻撃を阻止するというものである。

同社のクラウドネイティブなエージェントはサーバー、ノートパソコン、仮想マシンからテレメトリを収集し、AI と脅威インテリジェンスが不審な挙動の特定に役立つ。

同社にはインシデント対応における強い実績もあり、それが製品による脅威の検知と調査のあり方に反映されている。

データセンターのチームにとって、Falcon は重要なサービスを支えるサーバーとワークロード全体にわたる保護を提供する。

4. Microsoft

CEO： Satya Nadella

設立： 1975年

本社所在地： 米国、ワシントン州

Microsoft のセキュリティ事業は、オペレーティングシステム、生産性ソフトウェア、IDサービス、クラウドインフラストラクチャにまたがるその立場から恩恵を受けている。

Defender はエンドポイントとクラウドワークロードを保護し、Entra は ID を扱い、Sentinel はセキュリティ情報イベント管理を Microsoft クラウドにもたらす。

Azure を使用している組織にとって、これらのツールは、すでに稼働させているプラットフォームとネイティブに連携できる。

この統合により、ツールの乱立を減らし、ハイブリッドデータセンター、Microsoft 365 環境、パブリッククラウドワークロード全体にわたってセキュリティチームにより高い可視性を与えることができる。

3. Cisco

CEO： Chuck Robbins

設立： 1984年

本社所在地： 米国、カリフォルニア州

Cisco のセキュリティ上の強みは、ネットワーク自体に存在していることから始まる。

同社は、ファイアウォール、セキュアアクセス、ゼロトラスト、エンドポイント保護、ネットワークの可観測性を、多くのデータセンターに見られるスイッチングおよびルーティング技術と組み合わせている。

そのアプローチは、単一の防御境界から、ユーザー、デバイス、ワークロードに追随する制御へという移行を反映している。

大規模で分散した資産を管理する運営者に対し、Cisco は、表面的なレベルではなく、ネットワークファブリックにセキュリティを組み込む方法を提供する。

Fortinet は、高性能なセキュリティを大規模インフラストラクチャ向けに実用的にすることで、このリストでの地位を獲得した。

同社の FortiGate ファイアウォールは多くのデータセンターネットワークに欠かせない存在であり、より広範な Fortinet Security Fabric は、クラウド、エンドポイント、メール、ID、セキュリティオペレーションにまで保護を広げる。

主要な差別化要因は、同社によるカスタム ASIC チップの使用であり、これによりファイアウォールがボトルネックになることなく、高いスループットでセキュリティ検査を行える。

トラフィック量が多く、レイテンシが商業的に敏感なデータセンターでは、これが重要である。

Fortinet の統合されたアプローチは、管理しなければならない個別のコンソール、ライセンス、ポリシーの数を減らそうとするチームにも魅力的である。

ネットワーキングとセキュリティを1つのプラットフォームに組み合わせることで、運営者は脅威をより明確に把握でき、複雑な環境全体で保護を適用するより一貫した方法を得られる。

1. Palo Alto Networks

CEO： Nikesh Arora

設立： 2005年

本社所在地： 米国、カリフォルニア州

Palo Alto Networks のセキュリティプラットフォームの幅広さと一貫性に匹敵する競合は少ない。

同社のファイアウォールとネットワークセキュリティ製品は、多くのデータセンターアーキテクチャにとって依然として重要だが、その範囲は現在、はるかに広がっている。

Prisma Cloud はパブリッククラウド環境全体でワークロードとアプリケーションを保護し、Cortex はセキュリティオペレーション、自動化、脅威インテリジェンスを結び付ける。

同社のIDベースのゼロトラスト製品は、重要なシステムにアクセスするユーザーとデバイスに対する制御の層をさらに加える。

Palo Alto Networks を際立たせているのは、これらの要素がどのように組み合わさっているかである。

個別の製品を販売するのではなく、セキュリティチームの複雑さを減らし、製品間でインテリジェンスを共有し、対応プロセスの一部を自動化することを意図したプラットフォームを構築している。

分散したインフラストラクチャ、クラウドの採用、拡大する攻撃対象領域に直面するデータセンター運営者にとって、この奥行き、規模、統合の組み合わせにより、Palo Alto Networks は打ち負かすべき企業となっている。
