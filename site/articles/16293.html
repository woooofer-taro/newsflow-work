サイバーセキュリティ意識向上月間：動画まとめ

Cybersecurity Awareness Month: Video Recap
Cisco Blogs2026-11-27 13:00報道

忙しかった10月のセキュリティ

Cybersecurity Awareness Month 2026 は、単なる注意喚起ではなく、実際のインシデントを伴ってやって来た。1週間のうちに、ウェブの3つの柱が緊急の対応を必要とした。

  • PHP は10月21日に 8.5.12、8.4.27、8.3.36、8.2.35 を公開し、メモリ管理とエラー処理における2件の重大なリモートコード実行の欠陥を修正した（CVSS 9.2）。開示の禁輸措置（エンバーゴ）は1日早く漏れた。__PHP Foundation__
  • Node.js は同日、26.x、24.x、22.x の各系統にわたる10件の CVE にパッチを適用した。その中には、RCE につながり得る Brotli デコーダの境界外書き込みや、複数の TLS ホスト名検証のバイパスが含まれる。__Node.js__
  • 認証局である eMudhra は、8つの中間証明書の秘密鍵がほぼ瞬時に復元された。P-384 の鍵は 256 未満の小さな整数だった。Mozilla と Chrome は、その ECC ルートへの信頼を取り消した。__Mozilla Bugzilla__

共通する筋道：AI ツールは今や、防御側にとっても攻撃側にとっても、かつてない速さで弱点を見つけ、悪用する。それこそが、10月の動画の主題である。

シリーズを見る

  1. __Build Your AI Agent for Network & Security Operations__（3:20）：Pi coding agent と Cisco MCP サーバーを使って AI エージェントを構築する。ネットワーク偵察ツール、ミニログトリアージ、リモートおよびローカルの MCP サーバーのスキャン、そして Secure Access MCP サーバーによる反復作業の自動化。
  2. __Specification, Skills, and Scanners for Agentic AI Security__（6:46）：再利用可能な__Agent Skills for Cisco products__（ThousandEyes スキルを含む）、続いて AI が生成したコードを保護するための Project CodeGuard、そして Cisco ACI スクリプトを構築するための Spec Kit と__Foundry Security Spec__。
  3. __Automated Kill Chain and Cybersecurity Threats__（5:03）：APT の状況（APT28、APT29、Sandworm、Lazarus Group）、標的となる分野と攻撃ベクトル、AI が統率するキャンペーン、__Cisco LLM Security Leaderboard__、そして LLM 駆動の攻撃パイプラインのトークンコスト。
  4. __Short: Vibecoding, But Make It Secure__（0:28）：__Project CodeGuard__ の簡単な紹介：AI コーディングエージェントに安全でないコードを書かせないための、セキュリティスキルとルール。
