Microsoft、Windows Server 2028でAI推論を企業データの近くへ

Microsoft brings AI inference closer to enterprise data with Windows Server 2028
Network World2026-11-19 13:00報道

公開プレビューは、機密データの近くで推論を実行することへの関心の高まりを反映し、セキュリティ、ストレージ、管理のアップグレードとあわせてAIインフラストラクチャ機能を追加する。

Microsoftは、AI推論が最も理にかなった場所で行われるハイブリッドな未来に賭けている。それは論理的には、データがすでに存在する場所、すなわち企業が管理するインフラストラクチャ上である。

そのために、今週のMicrosoft Ignitureで、このテック大手はWindows Server 2025以来最大のプラットフォーム更新となるWindows Server 2028を発表した。

現在公開プレビュー中のこの次世代サーバーは、「エンタープライズ・ハイブリッド・インテリジェンス」を支えるAI推論の基盤として位置づけられている。企業が自社のインフラストラクチャ上で推論を実行できるようにする新しいAIアクセラレーター、データ転送を高速化するストレージツール、「初日から安全なベースライン」を確立するセキュリティ制御、そして簡素化された管理者向けおよび管理用ダッシュボードを導入する。

しかし、自動化、管理、ID、セキュリティ、復旧、ストレージ、仮想化にわたる新機能を約束する一方で、Windows Server 2028はまだ初期段階にあり、さまざまな機能の提供状況や成熟度はそれぞれ異なる。

「これは公開プレビュー段階であることを忘れてはならず、多くはまだロードマップ上の約束にとどまっている」と、Infotechのアソシエイトバイスプレジデントであるジョン・アナンド氏は述べた。

企業がいる場所で支援する

Windows Server 2028は、顧客が物理的な運用の近くや、自らが管理するエコシステム内で推論ワークロードを実行できるようにする。これは、「拠点ごとに別々のAIスタック」を構築・運用する必要がないことを意味すると、Windows Serverプロダクトチームのリーダーであるニール・ヒナント氏はブログ記事で説明した。

Microsoftは自社のサーバーにAIアクセラレーターを導入している。特に、AMDのInstinct MI350Pカードは、Server 2028を含む対応するWindows Serverシステム向けに、2027年上半期にプレビューとなる。同社は、そのハードウェアを管理し、推論環境を展開・構成し、モデルへのリクエストを適切な環境に振り向けるためのツールも開発している。

Microsoftは、この提供は、Microsoft Foundryを「ローカルのトークンファクトリー群」へと拡張し、Foundry Local、Windows ML、vLLM、Llama.cppにわたるオープンウェイトおよびカスタムモデルをサポートするという長期的な投資の始まりでもあると述べた。

「AIで加速されるワークロードが企業全体に広がるにつれ、ワークロードごとに必要なものは異なる」とヒナント氏は書いた。「コスト、レイテンシ、知的財産の保護、データレジデンシー、規制要件のすべてが、その判断を形作る。」

新しいセキュリティ、ストレージ、管理機能

セキュリティの面では、Windows Server 2028は「デフォルトで」堅牢化されたServer Core構成を備え、業界ベンチマークに沿った数百のセキュリティ設定が初回起動時に有効になる。

「セキュアな構成は開始時の状態であり、セットアップ後に実施するプロジェクトではない」とMicrosoftは説明した。企業は、ワークロードが必要とする設定だけを緩和すればよい。「それにより、新しく展開されたサーバーが堅牢化されるのを待つ間、無防備なままになる期間がなくなる。」

新しいサーバーは、分離のための封じ込めレイヤー、エージェントのIDとガバナンスのためのAgent 365、そして信頼の連鎖を構築するための仮想マシン（VM）保護を組み込んでいる。Microsoftは、人とマシンの両方のIDを検証し、侵害を防ぎ、トラフィックを暗号化するための自動証明書管理にも、ポスト量子暗号とあわせて投資していると述べている。これにより、日々のセキュリティ業務と、「明日の脅威に備えて」近代化するというより長期的なニーズとのバランスを取れる。

また、デフォルトで、Windows Server 2028はネイティブのNVMe（non-volatile memory express）ストレージをサポートし、「負荷の高いワークロードにより多くの成長の余地を与える」。

企業は、ポリシーを適用し、更新を管理し、環境全体で何が稼働しているかを把握できる必要がある。現在プレビュー中のWindows Servers向けIntune管理は、構成、コンプライアンス、更新を含むエンドポイント管理ワークフローを、対象となる常時稼働のサーバーにもたらす。現在Windows Serversで一般提供されているWindows Admin Center Virtualization Mode（WAC vMode）は、管理者が特定のサーバーやインフラストラクチャを「ひとつのファブリックとして」扱う能力をさらに提供すると、ヒナント氏は説明した。

「ワークロードに注意が必要なときや、仮想化ホストのトラブルシューティングが必要なとき、管理者はマシンに近づいて何が起きているかを理解する必要がある」と彼は述べた。

ハイブリッド・インテリジェンス機能は、ハードウェア要件を含むアーリーアクセスプログラムを通じて、限られた数の顧客に提供されているとMicrosoftは述べた。Windows Server 2028へのアーリーアクセスに関心のある顧客は、Windows Server Technology Adoption Program（TAP）を通じて申し込める。NVMeとサーバー向けIntune管理は、現在テスト可能である。

将来の投資に関する考慮事項

既存のハードウェア上でローカルAIにServer 2028を使いたい場合、NvidiaまたはAMDのアクセラレーター（AMDのオープンソースGPU向けROCmには多くの関心が集まっている）を追加する必要があるとInfotechのアナンド氏は指摘し、さらに「ますます高価になるRAMを大量に」追加することは言うまでもないとした。さらに、3年前には「猛烈に高速」だった10GbEネットワークカードは、50または100GbE以上にアップグレードするまでは、おそらくボトルネックになる。

「誰も驚かないだろうが、AIにServer 2028を使いたいなら、新しい機材に投資する必要がある」とアナンド氏は述べた。

多くの企業は、プラットフォームの足場に関するAIの誇大宣伝よりも、使い勝手の改善に関心があると彼は述べた。こうした顧客にとって、Server 2028は「既存ハードウェア向けの実行可能な中間アップグレード」である。

Microsoftの価値提案はエコシステム、少なくとも製品のバンドル、そして企業による管理であるとアナンド氏は述べた。Server 2028上のAIの力は、Microsoft Foundryやその他のAzureクラウドサービスとの統合性から生まれる。セキュリティとコスト管理の両面から見たローカル推論は、対象となるMicrosoftの顧客層にとって注目の話題である。

パブリッククラウドでAIを実行することは高コストであることが分かっており、公開されたWindows 2028の機能セットに暗に含まれているのは、「Azure環境という青空から、オンプレミスに戻りたいMicrosoftの顧客がいることの暗黙の承認」であるとアナンド氏は述べた。

現時点では誰にでも向くわけではない

Microsoftは、一般提供に向かってはいるものの、Windows Server 2028はプレリリース製品であると強調した。一部の要素は正式リリースまでに「大幅に変更」される可能性がある。

また、セキュリティとメモリのデフォルトが厳格化されるため、Windows Server 2025で動作していた一部のものが、構成を変更しなければWindows Server 2028では動作しない可能性がある点にも注意が必要だとMicrosoftは述べた。問題となりうる機能には、古いプロトコル、レガシー認証、一部の管理ツールやスクリプトが含まれるとMicrosoftは述べた。同社は企業に対し、展開前にこれらの構成に対してアプリや運用ツールをテストし、必要な場合にのみ設定を緩和するよう助言した。

確かに、すべての企業が、新しいサーバーが正式に展開されたらすぐにアップグレードする必要性を感じるわけではないと、専門家は指摘した。結局のところ、Windows Server 2025は2034年まで延長サポートが続き、以前のエディションもWindows Long-Term Servicing Channel（LTSC）の対象となっている。Windows Server 2022は2031年10月14日まで、2019は2029年1月9日まで、Windows Server 2016は2027年1月12日に終了する。

以前はLong-Term Servicing Branch（LTSB）として知られていたWindowsのLTSCは、企業が安定した、機能が固定されたOSを維持できるようにする。この提供は、特にミッションクリティカル、高度に規制された、または制限された環境を対象としている。

後発採用者が勝者になるかもしれない

多くのAIの先駆者は、Microsoftが何かを企業にとって安全で準備の整ったものにするのを待たない。彼らは自前のLinuxクラスターを立ち上げたり、Neocloudプロバイダーと協力したり、AWS BedrockやAzure Foundryで作業したりしてきたとアナンド氏は指摘した。
