⚡ 今週の脅威

脅威アクターが VMware vCenter の脆弱性を 0-Day として悪用 — Armory Castle（旧 UNC5221）として知られる、中国と関係があると疑われるサイバースパイ集団が、2026年9月初旬の VMware vCenter Server における重大なセキュリティ欠陥のゼロデイ悪用の実行者とされた。CVE-2026-123890（CVSSスコア: 9.8）として追跡されているこの脆弱性は、VMware Directory Service における認証バイパスの事例であり、システムへの不正アクセスを得るために悪用されうる。10月、Google は、Armory Castle が BeyondTrust の Remote Support ツールを通じて組織を悪用するキャンペーンについて説明した。このキャンペーンでは、ゼロデイを使ってエッジアプライアンスに侵入し、ネットワーク偵察や組織内での下流の侵害に役立つ機密情報を盗んでいた。最新の調査結果は、BeyondTrust が、Linux マシンへのバックドアの展開を伴う、より深く複雑なキャンペーンへの単なる入口にすぎなかったことを示している。

🔔 注目ニュース

  • Cursor、悪意ある Claude 拡張機能のリリースを Fireworks AI のインシデントに関連付け — Cursor は、同社のマーケットプレイスにおける Anthropic の Claude Code 拡張機能の悪意あるバージョンに関わるセキュリティインシデントの発端を、AI インフラストラクチャプロバイダーである Fireworks における侵害にまでたどった。「攻撃者は、私たちが Fireworks に発行していたアクセスキーを入手した」と Cursor は述べた。「そのキーは Fireworks によって露出しており、攻撃者はそれを使って、私たちが彼らとデータを共有するために使っていた読み取り専用のストレージバケットからデータをコピーした」。Cursor のインシデントは、AI を活用した開発ツールの急速な採用と、ますます相互接続が進むソフトウェアエコシステムが、ソフトウェアサプライチェーンのリスクをいかに悪化させたかを示すもう一つの兆候である。
  • Cold Relic、クラウド侵害を悪用して組織を標的に — Cold Relic として知られるロシアのサイバースパイ集団は、クラウド侵害を、被害組織のより広範な信頼関係のネットワークを標的にするための足がかりに変えている。昨年末に確認された最初の侵入では、攻撃者はクラウド管理者アカウントの制御を獲得し、社内通信、従業員の詳細情報、その他の組織記録を収集した。Cold Relic はその後、その情報を使って最初の組織の従業員になりすまし、2番目の組織の個人に対してソーシャルエンジニアリング攻撃を行った。これらのキャンペーンは「人間中心のソーシャルエンジニアリングとクラウドアイデンティティの悪用の収束を示している」と Google は述べた。「戦略的な人員名簿や業務文書へのアクセスを得ることで、ロシアの情報機関は正当な業務上の通信を、信頼されたパートナーに対する攻撃ベクトルに変えている」。
  • 悪意ある Web ページが Meta Muse を乗っ取り可能 — NebuSec の研究チームによる新たな研究は、攻撃者が制御する Web ページを悪用して、Meta Muse に関連するユーザーデータへの不正アクセスを得て、それが動作する基盤の仮想マシン（VM）を侵害できることを実証した。「攻撃者は、Muse のネットワーク承認プロンプトを発生させることなく、会話履歴と保存された記憶を取得できる可能性がある」と NebuSec は述べた。「この攻撃では、保存された記憶と会話履歴を改変することもでき、不正なデータアクセスを超えるリスクを生んだ。共有 Linux カーネルの脆弱性を悪用することで、私たちはエージェントのランタイムコンテナから脱出し、基盤のユーザー VM で root 権限を取得した」。Meta はその後この問題に対処している。
  • 新たな FastUnlock Windows Narrator ロック画面バイパスの詳細 — セキュリティ研究者の Abdelhamid Naceri（別名 Chaotic Eclipse）は、FastUnlock を公開した。これは未修正の新しい Windows 11 ゼロデイで、Narrator スクリーンリーダーを悪用してロック画面を通過し、ロック画面アカウント「WsiAccount」としてコードを実行する。この攻撃には物理的なアクセスと、オンラインの Microsoft アカウントにリンクされた少なくとも1つのアカウントが必要である。
  • GL.iNet GoodCloud が悪用されリバースシェルやバックドアを配布 — ハッカーが GL.iNet の GoodCloud クラウド管理プラットフォームの脆弱性を悪用し、顧客のルーターや KVM デバイスにマルウェア、バックドア、リモートアクセスツールをインストールした。「許可されていない第三者がこの脆弱性を悪用し、一部の GL.iNet ルーターおよび KVM デバイスにアクセスして悪意あるソフトウェアをインストールした」と GL.iNet は述べた。「攻撃経路は遮断された。私たちはクラウドの脆弱性を修正し、このインシデントで使用されたアクセスを遮断した。この攻撃経路でデバイスが新たに感染することはもうない。クラウド側の修正だけでは、すでに感染したデバイスからマルウェアは除去されない」。GL.iNet は、攻撃者がどのようにしてクラウドプラットフォームを悪用したのか、何人の顧客が影響を受けたのか、またこれらの侵害の結果として情報が盗まれたかどうかを明らかにしていない。RemoteToHome は、183台のルーターを調べ、152台で不審な活動を発見したと述べた。その内訳は、root 権限のリバースシェルが24台、古い永続的バックドアが47台、攻撃者が与えたコマンドが実行された証拠を示すものが81台である。同社はまた、GoodCloud クライアントにおけるコマンドインジェクションの可能性がある脆弱性も特定しているが、GL.iNet は、これが攻撃で使われたものと同じ脆弱性かどうかを確認していない。
