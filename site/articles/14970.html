Cisco BroadWorksとOpenwaveの脆弱性、パッチが利用可能であるにもかかわらず悪用される

Cisco BroadWorks and Openwave Flaws Actively Exploited Despite Available Patches
The Hacker News2026-11-12 07:00報道

米国サイバーセキュリティ・インフラストラクチャセキュリティ庁（CISA）は火曜日、Cisco BroadWorks と Openwave Messaging Webtop Media Transcoder に影響を与える2件のセキュリティ上の欠陥を、悪用の証拠が確認されたとして、Known Exploited Vulnerabilities（KEV）カタログに追加した。

脆弱性の詳細は以下のとおり。

  • CVE-2026-20320（CVSSスコア: 7.5）- Cisco BroadWorks の Open Client Interface（OCI）XML パーサーにおける XML 外部エンティティ参照の不適切な制限の脆弱性。認証されていないリモートの攻撃者が、影響を受けるシステム上で Cisco BroadWorks ユーザーの権限で機密性の高い設定情報を読み取ることが可能になる恐れがある。（2026年8月に修正）
  • CVE-2026-111793（CVSSスコア: 4.3）- Openwave Messaging Webtop Media Transcoder における、スフィア間での不正なリソース転送の脆弱性。認証されたユーザーが、Webmail の体験を迂回する場合に、意図されていない文書タイプを処理・変換できる恐れがある。（2026年10月に修正）

CVE-2026-111793 の KEV カタログへの追加は、Japan Vulnerability Notes（JPN）が発した警告に続くものであり、JPN は注意喚起において「開発者は、この脆弱性を悪用した攻撃が確認されていると述べている」と記していた。

この脆弱性情報ポータルは、認証された攻撃者がこの脆弱性を悪用して、特別に細工したファイルをアップロードし、機密情報を取得する可能性があるとも警告した。

CVE-2026-20320 については、このセキュリティ上の欠陥が、「Operation Snowball」と名付けられたエージェント型攻撃キャンペーンの一部として利用された。この中で、正体不明の中国語話者の脅威アクターが、DeepSeek Flash モデルのジェイルブレイク版を用いて構築された自律型フレームワークを活用し、ヨーロッパの通信事業者と、そのインフラ上でホストされている13社を標的にした。

Malbear Labs によると、この活動により、2週間にわたって、数百の資産の列挙、数十組の認証情報の抽出、そして事業者の社内課金プラットフォームからの数千行の加入者課金記録およびデバイス記録の持ち出しが行われた。

この AI エージェントは、以下を含む幅広い製品にわたる既知のセキュリティ脆弱性群を悪用する能力を持つ。

  • JBoss RichFaces（CVE-2013-2165）
  • Liferay CE/DXP（CVE-2020-7961）
  • ForgeRock OpenAM（CVE-2021-35464）
  • Linux（CVE-2021-4034）
  • SAP NetWeaver（CVE-2022-22536）
  • Cisco Expressway（CVE-2023-20269）
  • Citrix NetScaler（CVE-2023-4966）
  • Qlik Sense（CVE-2023-41265、CVE-2023-41266）
  • PAN-OS GlobalProtect（CVE-2024-3400、CVE-2024-9474）
  • Adobe Experience Manager（CVE-2025-54249）
  • Broadcom VMware Cloud Director（CVE-2026-2003、CVE-2026-2004、CVE-2026-2005、CVE-2026-2006）
  • Claris FileMaker Server（CVE-2026-86934）、および
  • F5 BIG-IP（CVE-2026-41225）

「通信事業者のインフラにおける主な標的は、ポート 2208 で稼働する BroadWorks XSP（eXtended Services Platform）の Release 23.0.1.1075 だった」と Malbear Labs は述べた。「エージェントは、BroadWorks OCI XML パーサーにおける認証不要の XXE である CVE-2026-20320 を悪用した。」

「XSP ホストから、エージェントはシステム ID の秘密鍵、3組の SSL 認証情報、および証明書との一致が確認された3つの追加の秘密鍵を回収した。システム ID 鍵は BroadWorks プラットフォームが自身のコンポーネント間を認証するために使用するものであり、これを所持していると、コンポーネント間通信において XSP になりすますことが可能になる。」

この活動は、偵察ツールの使用、ポストエクスプロイトのための Sliver、Chisel、さらに永続的なアクセスのための Behinder などのウェブシェルの使用によっても特徴づけられている。

「これは、侵入を AI に委任し、進捗を確認するために非同期で確認していた脅威アクターである」と Malbear Labs は付け加えた。主たるエージェントは継続的に稼働し、ワーカーエージェントに並列タスクを発行し、キャンペーン全体を通して一貫した作戦計画を維持し、オペレーターの入力のために停止することなく防御制御に適応した。」

「ハーネスは、偵察を実行し、攻撃対象領域を特定し、悪用経路を選択し、制御に阻まれた際には適応し、既存のツールが失敗した際には新たなツールを書き、認証情報を抽出し、データを持ち出し、完成した標的リストを作成した。そのいずれの間も、オペレーターは不在だった。」

先月末、Cisco は、Catalyst SD-WAN の脆弱性（CVE-2026-20127、CVSSスコア: 10.0）と、Secure Firewall Adaptive Security Appliance（ASA）Software および Secure Firewall Threat Defense（FTD）Software の脆弱性（CVE-2026-76418、CVSSスコア: 8.6）という2件の異なる脆弱性が、実環境で悪用されていることを明らかにした。

悪用が確認されていることを踏まえ、連邦文民行政機関（FCEB）は、ネットワークを保護するため、2026年11月24日までにパッチを適用することが推奨されている。
