イノベーションの加速：Cisco CVD と Red Hat Ansible がデータセンター自動化をどう変革しているか

「Month of Cisco Validated Designs (CVDs)」の第2回では、Red Hat の Stephen Fulmer 氏と Cisco の Archana Sharma 氏に話を聞き、CVD と Red Hat Ansible によるデータセンター自動化を使って、企業がインフラをどのように導入・管理するかを再形成している、複数年にわたる強力な協業について議論した。

この提携の中核は何か。Cisco のネットワーキングおよびデータセンターハードウェアにおける深い専門知識と、Red Hat の業界をリードする Ansible 自動化機能を組み合わせることだ。

手作業のドキュメントから、自動化された精度で提供される CVD へ。

Cisco は長年にわたり、厳密にテストされ検証された設計文書である CVD を公開してきた。しかし、インフラの複雑さが増すにつれ、チームは純粋に手作業のドキュメントから、自動化された再現可能なプロセスへ移行する必要があると認識した。

Red Hat Ansible を CVD に取り入れることで、チームは静的なガイドを超えた。Archana 氏は CVD について次のように述べる。「お客様がそのまま受け取って導入することは想定していません。お客様には、これを出発点として設計を変更していただくことを想定しています。」

そのため CVD は、手作業の手順と自動化の両方を並べて提供する。導入に関する章は、Ansible コードと同じ Git リポジトリに置かれている。これにより、自社のビジネスニーズに合わせて設計を適応させることができる。CVD の自動化は、GitHub の Cisco UCS Compute Solutions organization で閲覧できる。

Cisco Intersight Ansible collection は137モジュールに成長

この提携の際立った成功例が Cisco Intersight Ansible collection だ。これは古い API 上に構築された約12個のモジュールから始まった。最新の API で再構築され、137モジュールに成長した。Stephen 氏は、現在お客様がこれで毎月数百万件のジョブを実行していると述べている。

チームがここから得た教訓は次のとおりだ。ネットワークの専門家と自動化の専門家が早期に連携すると、大規模な運用に耐えるソリューションが生まれる。

Day 2 運用とコンプライアンスのためのデータセンター自動化

自動化は初期導入だけのものではない。環境を維持することでもある。この協業は次の点を重視している。

  • ドリフト管理： 立ち上げ後も長期にわたってインフラのコンプライアンスを維持すること。
  • セキュリティのガードレール： ロールベースアクセス制御（RBAC）と監査ログを自動化フローに組み込み、AI 駆動プロセスにおける人間による監督を確保すること。
  • 統合サポート： 共同サポートモデルにより、お客様は購入窓口もサポート窓口も一本化される。Intersight コンテンツについては、Red Hat が最初の問い合わせを受け、Cisco サポートと連携してトリアージを行う。混在環境でベンダー間の責任のなすり合いに置かれることはない。

これらの考え方を検証済み設計で確認するには、Cisco コンピュートと Red Hat Ansible による Day 2 自動化に関する CVD を読んでほしい。

今後の展望：AI Pod CVD

チームは、近日公開予定の AI Pod CVD についても先行して紹介した。Cisco UCS X-Series と Nexus のインフラを Everpure（旧 Pure Storage）と組み合わせたこの新しい設計は、推論プラットフォームに焦点を当てている。推論プラットフォームとは、学習済みモデルを本番環境で提供するシステムである。これは Cisco の既存の AI PODs に加わることになる。

この CVD は約1か月後に公開される見込みで、Ansible による自動化がその少し後に続く。議論した目標は、Ansible を使って AI スタック全体のセットアップを自動化し、導入時間を数か月から数時間へ近づけることだ。

未来を支える： Cisco と Red Hat の次のステップ

この提携は、OpenShift、仮想化、AI インフラへと拡大し続けており、アプローチは同じだ。テスト済みの設計、適応可能な自動化、そして何かが壊れたときの一本化されたサポート窓口である。データセンター自動化においては、白紙の状態からではなく、検証済みの設計と動作するプレイブックから始められるということだ。

Archana 氏と Stephen 氏との対談の全編は、YouTube の DevNet Month of Cisco Validated Designs の第2回で視聴できる。キックオフを見逃した場合は、第1回の投稿「Welcome to the DevNet Month of Cisco Validated Designs」から始めてほしい。
