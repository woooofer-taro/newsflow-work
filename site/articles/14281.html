Cisco Live Melbourne: Learn with Cisco ブースで何が起こるか

Lacey Caldwell Senko
Learn with Cisco
2026年11月3日 • 3分で読める

ネットワーキングの世界は活気づいています。スキルを磨きたいなら、メルボルンに勝る場所はありません。2026年11月9日から12日まで、Cisco Live APJC のためにテックコミュニティがここに集結します。これはまさに本物です。テック分野でのキャリアを真剣に考えるすべての人にとって、今年最大のイベントです。

会場に来られる方も、遠方からオンラインで参加される方も、今年は一つの大きな変化、つまり人工知能の急速な進化を軸に据えています。AI のトレンドについて語るだけではありません。デジタルレジリエンスの仕組み、AgenticOps の台頭、クラウドコンピューティングの未来、そしてそのすべての基盤であるインフラストラクチャに踏み込みます。

Cisco Live Melbourne の Learn with Cisco ブースの内部

到着したら、Learn with Cisco ブースを成長の拠点にしてください。ここは単なる案内所ではありません。つながり、競い、認定を取得できる場所です。CCIE または CCDE の認定をお持ちの方は、特別な記念グッズを受け取りに立ち寄り、水曜日の午後遅くに行われる CCIE レセプションにご参加ください。まだ Cisco Certified Expert ではありませんか？ご心配なく。テック分野での成功の頂点に到達するための道のりについて、私たちのチームがお話しする準備ができています。

Cisco U. Theatre でスキルアップ

Cisco U. Theatre は、Cisco Live Melbourne の World of Solutions 内の Learn with Cisco エリアにあります。Cisco U. Theatre では、常に何かを学べます。45分のセッションと先着順の着席で、次のひらめきは Cisco Live のすぐそばにあります。（YouTube チャンネルでライブストリームを視聴することもできます。）

気軽に立ち寄って席に着き、OT Security Practitioner Certification などの最新の認定アップデートについて聞いたり、エージェンティック AI のセキュリティ戦略を探ったり、Splunk のスキルを高めたり、エンタープライズネットワークのトラブルシューティングの専門知識を築いたりできます。

クイズはいかが？

「What's the question?」のラウンドで技術スキルを証明しましょう。競争心があるなら、ジョパディ形式のゲーム「What's the question?」に参加してください。イベント期間中ずっと実施しています。他の挑戦者を2人見つけたら、スキルを証明する準備は完了で、賞品を持ち帰れるかもしれません。

Cisco Live APJC で知識を認定へ

on-testing で試験を割引価格に

Certification Exam Testing Centre は毎日開いており、Full Conference または IT Leadership パッケージをお持ちの方は、試験が無料になります。（必ず2026年11月8日までに、参加者ダッシュボードから登録してください。）スケジュールにさらに追加したい方には、空きがある場合に限り、現地での試験登録を50%割引で提供しています。

世界中で受験できる Exam Safeguard

自信を高めたいですか？Exam Safeguard もぜひご検討ください。CCNA、CCNP core、Professional レベルの試験の準備に最も人気のある方法の一つで、より低い価格で成功への二度目のチャンスが得られます。

Cisco Live Melbourne で継続教育クレジットを獲得

Cisco Live の期間中、参加者は対象となる現地アクティビティを完了することで CE クレジットを獲得できます。たとえば、認定試験への合格、Breakouts、Labs、Seminars（一部の Cisco U. Theatre セッションを含みます！）への参加、Capture the Flag ミッションの完了などです。

Cisco Modeling Labs (CML) が割引に

どこからでもデジタルサンドボックスを構築したいですか？メルボルンにいらっしゃる場合は、ブースでバッジをスキャンすると、CML-Personal または CML-Personal Plus の50%割引コードを受け取れます。イベントに来られない場合でも、2026年11月9日から12日の間、Cisco U. Store で25%の割引を受けられます。2026年11月11日に大型アップデートが公開されるため、最新のツールをすぐに使い始められることにご留意ください。

Rev Up to Recert: SP Cloud

サービスプロバイダーの皆様へ。2026年12月10日まで、Designing and Implementing Cisco Service Provider Cloud Network Infrastructure | SPNCI Learning Path に無料でアクセスできます。40 CE クレジットを獲得でき、CCNP Service Provider コンセントレーション試験 300-540 SPCNI: Designing and Implementing Cisco Service Provider Cloud Network Infrastructure に取り組むために必要な知識を得られます。

SPCNI Learning Path の詳細、扱う内容、そしてその教材がサービスプロバイダーのクラウドと現代のエンタープライズ接続における変革的なスキルの状況にどう当てはまるかについては、Senior Technical Advocate の Quinn Snyder による Why Virtualization is No Longer Optional for Service Provider Engineers をお読みください。
