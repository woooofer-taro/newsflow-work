Nvidia、AI インフラ推進をハイパフォーマンスコンピューティングへ拡大

Nvidia expands AI infrastructure push into high-performance computing
Network World2026-11-19 07:00報道

Supercomputing ’26 で Nvidia が HPC 向けの新しい GPU、CPU、ネットワーキング技術を発表

おそらく CEO を巡る騒動ではなく技術について語りたかったのか、Nvidia はシカゴで開催されている Supercomputing ’26 のショーで、HPC 関連のニュースを一挙に発表した。

SC26 での Nvidia の発表は、GPU の販売にとどまらず、AI および高性能コンピューティングのインフラ一式を供給する方向へ事業を広げるという同社の取り組みを継続するものである。

Rubin HPC: 科学計算向けの新しい GPU

このニュースは、次世代の GPU および CPU プラットフォーム、ネットワーキングおよび相互接続技術、アクセラレーテッド・サイエンティフィック・コンピューティング、大規模 AI ワークロード向けに設計されたシステムに及ぶ。

以下は主要な発表の内訳である。

Nvidia は、高性能コンピューティング用途向けに特化して設計された、Vera Rubin プラットフォーム内の新しい GPU である Rubin HPC を発表した。主に AI のトレーニングと推論向けに最適化された GPU とは異なり、Rubin HPC は科学シミュレーション、エンジニアリングアプリケーション、大規模データ処理を高速化するよう設計されている。

Rubin HPC は 1 基の GPU に 50,000 を超える CUDA コアを備える。通常の Roman GPU のコア数は公表されていない。第 7 世代 NVLink による GPU 間通信の高速化、スパースデータのアクセラレーション、そしてスパース行列演算、ステンシル計算、ソートおよびリダクション演算の最適化を含む。

Rubin HPC は 2028 年に出荷される見込みである。

Vera CPU プラットフォームが HPC に拡大

Nvidia はまた、HPC 向けに特化して設計された Vera CPU プラットフォームのラックスケール版も発表した。Nvidia が自社の CPU を最初に発表した際は、Intel や AMD の従来型サーバープロセッサの代替として位置付けていた。現在、Nvidia は同社の CPU を特定の市場向けに位置付けている。

新しい構成は、1 ラックあたり 192 基の Vera CPU に、Quantum-X800 InfiniBand ネットワーキングと SHARP インネットワークコンピューティング技術を組み合わせたものである。シャーシ、配電、冷却インフラを含む既存の NVL72 ラックコンポーネントを使用する。

Nemotron for Science: 科学研究向けの AI エージェント

Nemotron は Nvidia が開発した AI モデルのファミリーであり、AI アプリケーション、特に自律型 AI エージェントを動かすよう設計されている。Nemotron for Science は、研究者が専門的な AI エージェントを開発するのを支援するよう設計された、オープンな AI モデル、科学データセット、ポストトレーニングツールの集合である。

このプラットフォームは Nemotron 3.5 Super VL を基盤としており、科学評価ツール、オープンな化学データセット、専門的な科学アプリケーション向けのポストトレーニングレシピ、CUDA-X アクセラレーテッド・コンピューティング・ライブラリとの統合を含む。

目的は、AI エージェントが科学的な質問に答えるだけにとどまらないようにすることである。AI エージェントは、研究情報を解釈し、コードを生成し、計算ツールを実行し、科学ワークフローを支援できる。

CUDA-X: 科学アプリケーションの高速化

Nvidia は、専門的な科学アプリケーションを高速化するよう設計された CUDA-X ソフトウェアライブラリの追加機能を発表した。

注目すべき機能には次のものがある。cuPhoton は、天体物理学および望遠鏡データについて、分析時間を 1 か月以上から 8 分に短縮できる。cuPotential は、分子シミュレーションを前世代の最大 3 倍高速化する。Daviator は、材料科学および量子力学計算を前世代の最大 22 倍高速化する。cuSpa は、生物学的および細胞の分析を CPU の最大 900 倍高速化する。

より広い目的は、創薬、材料研究、天体物理学、生物学研究を含む科学ワークフロー全体で GPU アクセラレーションを利用可能にすることである。

Nvidia Photonics: 大規模 GPU クラスター向けのネットワーキング

Nvidia は、同社のフォトニクス技術、特にコパッケージドオプティクス（CPO）スイッチを強調した。この発表には、クラウドプロバイダーの Lambda による導入が含まれており、同社は Nvidia Photonics スイッチを使用して、10,000 基を超える GPU を含む GB300 NVL72 ラックを接続している。

CPO は、光接続をスイッチングシリコンのより近くに統合し、高帯域幅のデータ移動における従来の電気接続への依存を減らす。

期待される利点として、ネットワーキングの消費電力の低減、ネットワークの信頼性の向上、スケーラビリティの改善、ますます大規模化する GPU クラスターに対する接続性の向上が見込まれている。

AI クラスターが成長するにつれて、ネットワーキングの消費電力と帯域幅が主要な制約になりつつあるため、これは重要な進展である。
