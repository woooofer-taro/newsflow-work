中国関連の脅威により、VMwareの脆弱性が悪用される

VMware vulnerability exploited by China-nexus threat
SDxCentral2026-10-31 07:00報道

中国と関係のあるハッキンググループ Warp Panda が、仮想化に関連する脆弱性のエクスプロイトを再び使って戻ってきた。

CrowdStrike の調査によると、このグループは CVE-2026-41709 を悪用した。これは 7 月に初めて発見された VMware ESX のログ記録不足の脆弱性である。この欠陥により、攻撃者は管理コマンドのログ記録を回避して悪意ある活動を隠蔽でき、その間に VMware vCenter 環境内にマルウェアが展開された。

この侵害は、問題の欠陥を Broadcom がパッチ適用する前に発生しており、欠陥は vCenter と、関連する Cloud Foundation、vSphere Foundation、Telco Cloud のサービスに影響した。

これを受けて、Cybersecurity and Infrastructure Security Agency（CISA）は今週、この欠陥を深刻度「低」の評価で Known Exploited Vulnerabilities カタログに追加した。影響を受ける米連邦機関は、11月11日までにこの問題を修正する必要がある。

CrowdStrike の発表は法務分野に対する脅威に関する報告書に含まれていたが、このキャンペーンは技術分野と製造分野にも影響したと指摘している。Warp Panda の工作員は通常、Ivanti Connect Secure VPN アプライアンスや F5 BIG-IP システムなど、インターネットに面したエッジデバイスの脆弱性を悪用して最初のアクセスを得た後、VMware vCenter 環境内へ横方向に移動する。そこに入ると、正規の vCenter プロセスを模倣するバックドアツールである Brickstorm を含む独自のマルウェアを展開した。

一部の攻撃は Microsoft のクラウド環境を標的にしており、Brickstorm は Microsoft 365 サービスへのアクセスに使われた。攻撃者は、ネットワークエンジニアリングおよびインシデント対応チームに関するファイルを含む、機密性の高い SharePoint 文書をダウンロードした。

「CrowdStrike Intelligence は、Warp Panda が少なくとも 2027 年半ばまで、仮想化インフラとエッジデバイスの脆弱性を引き続き優先すると中程度の確度で評価している……」と CrowdStrike の研究者らは警告した。
