Logicalis が Cisco Secure Networking Specialisation を取得

Logicalis からの最新情報をお届けします。グローバルなテクノロジーサービスプロバイダーである Logicalis は、ネットワーキング、セキュリティ、マネージドサービスにわたる専門性が認められ、Cisco の Secure Networking Specialisation を取得しました。この認定は、接続性とセキュリティを統合した安全な環境を設計、実装、管理する Logicalis の能力を裏付けるものです。

このスペシャリゼーションは、当初 5 か国の Logicalis の事業会社で取得されており、6 か月以内にその数を倍にすることを約束しています。これにより、Logicalis の顧客は、現地市場の要件に適したサポートを維持しつつ、グローバルな提供モデルを通じて、検証済みの Cisco の専門性を利用できるようになります。

より安全でレジリエントな運用の支援

組織が IT の時代から AI の時代へ移行するにつれ、ネットワークはより多くの事業上重要なトラフィックを運び、より幅広いユーザー、デバイス、ワークロードを支えなければなりません。同時に、セキュリティチームには、ますます分散する環境全体にわたって、より明確な可視性とより強力なポリシー制御が必要です。

Logicalis と Cisco は、AI の時代に向けて Secure Networking のマネージドサービスを進化させています。これは Cisco Cloud Control を基盤とし、Cisco IQ（これらのサービスが提供されている地域）および Cisco Data Fabric によって強化されています。このサービスは、顧客により高い可視性と洞察を提供するとともに、インフラの近代化、レジリエンスの強化、リスク管理、AI 対応環境の構築を支援します。

Logicalis のグローバルアライアンス担当 VP である Anita Swann は次のように述べました。「このスペシャリゼーションは、Cisco との長年の関係の強さと、お客様が必要とするスキル、プラットフォーム、サービスに対して私たちが継続して行っている投資を反映しています。ネットワーキングとセキュリティを変革的なマネージドサービスモデルの中で統合することで、組織が複雑さを減らし、レジリエンスを強化し、AI に必要な安全な基盤を構築できるよう支援できます。」

グローバルな提供と Cisco の専門性

Logicalis は、すべての主要地域にある Network Operations Centres と Security Operations Centres を通じて顧客を支援しています。これらのチームは、ネットワーキングとセキュリティの環境を監視・管理し、グローバルな提供体制と確立された Cisco の専門性を組み合わせています。

Cisco Secure Networking Specialisation は、Logicalis の専門性と、複雑なネットワーク環境全体で一貫したセキュリティ制御を適用する能力に対する、独立した検証を提供します。

「Cisco のパートナーエコシステムは、顧客が技術革新を測定可能な成果に変えるうえで中心的な存在です」と、Cisco の SVP、Cisco Global Partner Program GTM である Elisabeth De Dobbeleer は述べました。「Logicalis が 5 か国で Cisco の Secure Networking Specialisation を取得したこと、そして大規模にマネージドサービスを提供する能力を併せ持つことは、当社の最も強力なパートナーを特徴づける専門性、革新性、顧客重視の姿勢を示しています。グローバルな能力とローカルな専門性の組み合わせは、顧客がインフラを近代化し、運用を簡素化し、AI の時代に向けて安全に備えることを助けます。」

Logicalis と Cisco は共同で、顧客が環境を評価し、近代化の優先順位を付け、より自動化されたポリシー駆動型の運用を採用することを支援します。Cisco IQ と Cloud Control は、このプロセス全体を通じて、可視性、ライフサイクル管理、運用の一貫性を向上させます。

デジタルトランスフォーメーションの次の段階を可能にする

セキュアなネットワーキングは、変化する事業要件とともに進化できる基盤を組織に提供します。ネットワーキング、セキュリティ、自動化、運用インサイトを統合することで、Logicalis は顧客が管理を簡素化し、時間の経過とともにインフラを適応させることを支援します。

このスペシャリゼーションは、Logicalis が従来のインフラ管理を超えて、継続的な改善を支えるマネージドサービスへと移行していることを補強するものです。これにより、顧客は既存の環境を近代化し、運用を簡素化し、より確信をもって技術投資の判断を下すことができます。
